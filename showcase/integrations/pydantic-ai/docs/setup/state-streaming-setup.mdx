<Callout type="info" title="Pydantic AI streams state per tool call, not per token">
  Pydantic AI has no mapping from a streaming tool argument to a state key. A
  tool that returns a `StateSnapshotEvent` sends the state when it returns, so
  the UI updates once per tool call while the run continues.
</Callout>

<Steps>
  <Step>
    ### Report progress from a tool

    Give the model a tool that writes its progress to `ctx.deps.state` and
    returns a snapshot:

    ```python title="agent.py"
    from ag_ui.core import EventType, StateSnapshotEvent
    from pydantic import BaseModel
    from pydantic_ai import Agent, RunContext
    from pydantic_ai.ui import StateDeps
    from pydantic_ai.ui.ag_ui import AGUIAdapter
    from starlette.applications import Starlette
    from starlette.requests import Request
    from starlette.responses import Response
    from starlette.routing import Route


    class AgentState(BaseModel):
        """State for the agent."""
        observed_steps: list[str] = []


    agent = Agent(
        "openai:gpt-6-luna",
        deps_type=StateDeps[AgentState],
        system_prompt="You are a task performer. After each step, report all completed steps with step_progress.",
    )


    @agent.tool
    async def step_progress(
        ctx: RunContext[StateDeps[AgentState]], steps: list[str]
    ) -> StateSnapshotEvent:
        """Report the steps completed so far."""
        ctx.deps.state.observed_steps = steps
        return StateSnapshotEvent(
            type=EventType.STATE_SNAPSHOT,
            snapshot=ctx.deps.state.model_dump(),
        )


    async def run_agent(request: Request) -> Response:
        # Build the deps fresh on every request, so concurrent users do not
        # share state.
        return await AGUIAdapter.dispatch_request(
            request, agent=agent, deps=StateDeps(AgentState())
        )


    app = Starlette(routes=[Route("/", run_agent, methods=["POST"])])
    ```

  </Step>
  <Step>
    ### Keep `deps.state` the source of truth

    When the run ends, **the state in `deps.state` becomes the single source of
    truth**. Snapshots are live feedback only. Write every change you want to
    keep to `ctx.deps.state`, or it is overwritten when the run completes.

  </Step>
</Steps>
