<Steps>
  <Step>
    ### Install the Cloudflare Agents AG-UI adapter

    ```bash
    npm install agents @ag-ui/cloudflare-agents ai
    ```

  </Step>
  <Step>
    ### Wire the agent once, and chat and code share it

    `copilotkit.runAgent`, `agent.subscribe` and `agent.addMessage` drive runs
    against the same AG-UI endpoint your chat UI posts to, so there is no
    second backend to set up. Serve the `withAGUI` agent the way any chat demo
    does, and every entry point sees the same model, tools and instructions.

    <DemoCode file="src/agent/agents.ts" region="agent-run" />

    Every run carries the thread's messages from the client, and the thread
    id picks the Durable Object. A headless run on the same thread continues
    it, with the state that thread's Durable Object kept, and a fresh
    `threadId` starts a new one.

  </Step>
</Steps>

<Callout type="info" title="Headless interrupts come from tool approvals">
  The headless interrupt-resolver pattern (read the interrupt off the agent,
  answer it with a `resume`) works with a server tool under the AI SDK's tool
  approval (`toolApproval` in AI SDK v7, `needsApproval` in v6). The run ends
  with an interrupt for the call, and a `resume` of `{ "approved": true }`
  runs it (see the human-in-the-loop setup). To ask the user from code
  without a backend tool, use the frontend-tool Promise pattern: register the
  tool with `useFrontendTool` and an `async` handler, and resolve its promise
  when your own UI has the answer.
</Callout>
