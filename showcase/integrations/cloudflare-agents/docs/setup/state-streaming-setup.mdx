The adapter streams a tool call's arguments as `TOOL_CALL_ARGS` events while
the model writes them, but it does not copy them into state. To fill the state
while the model is still writing, update it from the tool's own AI SDK input
callbacks:

- `onInputStart` runs when the call starts. Reset a buffer there.
- `onInputDelta` runs with each new chunk of the arguments' JSON. Append it to
  the buffer, parse the buffer with the AI SDK's `parsePartialJson` (the JSON
  is unfinished until the call ends), and write the field you want with
  `this.setState()`.
- `execute` runs once the arguments are complete. Write the final value if it
  differs.

Every `this.setState()` during a run streams a `STATE_SNAPSHOT` to the page at
once, so the page sees the document grow chunk by chunk, and the Durable
Object keeps the final value. The showcase's `write_document` tool does this
for its `document` argument. Stream the tool's arguments from the model: the
showcase's chat agents call OpenAI through the Chat Completions API
(`openai.chat(...)`) for that.
