Follow the [Cloudflare Agents quickstart](/cloudflare-agents/quickstart) to
create the Worker, then keep it running:

```bash title="Agent application"
npx wrangler dev --port 8000
```

Point Channels at the agent you want to drive. The quickstart's `Assistant`
agent is served at `/agents/assistant`:

```dotenv title=".env"
AGENT_URL=http://localhost:8000/agents/assistant
```

Install the HTTP adapter in the Channels process:

```bash title="Terminal"
npm install @ag-ui/client@0.0.59
```

Create a new HTTP adapter for every channel thread. The Worker's
`toThreadRequest` moves the thread id into the path, so each channel thread
gets its own Durable Object:

```ts title="agent.ts"
import { HttpAgent } from "@ag-ui/client";

export function makeAgent(threadId: string) {
  const agent = new HttpAgent({ url: process.env.AGENT_URL! });
  agent.threadId = threadId;
  return agent;
}
```
