  <Step>
    ### Pass the backend tools to the agent

    Backend tools are AI SDK `tool()`s with an `execute` function. Pass them
    as `tools` to `run.streamTextOptions()`, which puts them after the page's
    tools, and the AI SDK runs each call in the Worker when the model asks for
    it. The adapter streams every call to the browser as `TOOL_CALL_START`,
    `TOOL_CALL_ARGS` and `TOOL_CALL_END`, then `TOOL_CALL_RESULT` with the
    returned value, so a frontend renderer registered under the same name
    paints the card.

  </Step>
