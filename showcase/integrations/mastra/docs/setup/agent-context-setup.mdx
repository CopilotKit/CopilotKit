    ### Read the context in your Mastra agent

    The AG-UI Mastra adapter puts the `useAgentContext` entries on Mastra's
    `RequestContext`, under the `ag-ui` key. It does **not** add them to the
    prompt. An agent that never reads them answers as if they were not there,
    and nothing reports an error. Read them in a dynamic `instructions`
    function.

    A `value` that you passed as an object or an array arrives as a JSON
    string. Parse it with `JSON.parse`. Do not stringify it again.

    ```ts title="src/mastra/agents/colleagues-agent.ts"
    import { openai } from "@ai-sdk/openai";
    import { Agent } from "@mastra/core/agent";

    export const colleaguesContactAgent = new Agent({
      id: "colleague-agent",
      name: "Colleagues contact Agent",
      model: openai("gpt-4o"),
      // Read the context that CopilotKit put on the request context
      // [!code highlight:13]
      instructions: ({ requestContext }) => {
        const aguiContext = requestContext.get("ag-ui")?.context;
        const colleaguesContextItem = aguiContext?.find(
          (contextItem) => contextItem.description === "The current user's colleagues",
        );

        // The value is already a JSON string, so parse it instead of stringifying it
        const colleagues = colleaguesContextItem ? JSON.parse(colleaguesContextItem.value) : [];
        const colleagueList = colleagues.map((c) => `${c.name} (${c.role})`).join(", ");

        return `You are a helpful assistant that can help emailing colleagues.
    The user's colleagues are: ${colleagueList}`;
      },
    });
    ```

    The `description` you match on must be the same string that the frontend
    passes to `useAgentContext`. See Mastra's
    [runtime context guide](https://mastra.ai/en/docs/agents/runtime-context)
    for more about `RequestContext`.
