<Steps>
  <Step>
    ### Declare the tool as an external tool

    Agno's AG-UI interface does not forward the request's tool definitions to
    the model. The model only sees tools declared on the `Agent`. A tool you
    register with `useHumanInTheLoop` therefore needs a matching declaration
    on the agent, marked `external_execution=True`, with an empty body. Agno
    pauses the run, the browser renders your component, and the run resumes
    with the user's answer.

    The name and the arguments must match the `useHumanInTheLoop`
    registration exactly. The docstring is what the model reads, so describe
    when to call the tool there.

    ```python title="tools/frontend.py"
    from agno.tools import tool

    @tool(external_execution=True)
    def offerOptions(option_1: str, option_2: str):
        """
        Give the user a choice between two options and have them select one.

        Args:
            option_1: str: The first option
            option_2: str: The second option
        """
    ```

    Register the tool on the agent:

    ```python title="main.py"
    from agno.agent import Agent
    from agno.db.sqlite import SqliteDb
    from agno.models.openai import OpenAIChat
    from agno.os import AgentOS
    from agno.os.interfaces.agui import AGUI
    from tools.frontend import offerOptions

    db = SqliteDb(db_file="tmp/agno.db")

    agent = Agent(
        model=OpenAIChat(reasoning_effort="none", id="gpt-6-luna"),
        tools=[offerOptions],
        db=db,
        description="A helpful assistant that can answer questions and provide information.",
        instructions="Be helpful and friendly. Format your responses using markdown where appropriate.",
    )

    agent_os = AgentOS(agents=[agent], interfaces=[AGUI(agent=agent)])
    app = agent_os.get_app()

    if __name__ == "__main__":
        agent_os.serve(app="main:app", port=8000, reload=True)
    ```

  </Step>
  <Step>
    ### Give the agent somewhere to store the paused run

    Agno stores the paused run before the browser can return the user's
    answer, so the `Agent` that owns the external tool needs a database. An
    agent with an external tool and no `db` cannot resume after the user
    answers.

    `SqliteDb` needs `sqlalchemy` installed:

    ```bash
    pip install sqlalchemy
    ```

    A project-relative SQLite file, as above, is fine for local development.
    For production, use durable shared storage such as `PgDb`. An ephemeral
    container file cannot resume a run on another instance.

  </Step>
</Steps>
