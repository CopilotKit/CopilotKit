<Steps>
  <Step>
    ### Declare the component as an external tool

    Agno's AG-UI interface does not forward the request's tool definitions to
    the model. The model only sees tools declared on the `Agent`, so every
    frontend tool needs a matching declaration. Mark it
    `external_execution=True`: Agno pauses the run, the frontend handles
    the tool call, and Agno resumes with the result.

    The name and the arguments have to match the frontend registration
    exactly. The docstring is what the model reads, so describe when to call
    it there.

    For a chart registered with `useComponent`, declare `render_bar_chart`:

    ```python title="src/agents/chart_agent.py"
    from agno.agent import Agent
    from agno.models.openai import OpenAIChat
    from agno.tools import tool


    @tool(external_execution=True)
    def render_bar_chart(title: str, data: list[dict]):
        """
        Render a bar chart in the chat.

        Call this whenever the user asks for a chart or a comparison.

        Args:
            title (str): A concise chart title.
            data (list[dict]): Items shaped `{label, value}`.
        """


    agent = Agent(
        model=OpenAIChat(id="gpt-6-luna"),
        db=db,
        tools=[render_bar_chart],
        instructions=SYSTEM_PROMPT,
    )
    ```

    For the React Native `useFrontendTool` task filter example, declare
    `filter_tasks` instead of `render_bar_chart`:

    ```python title="src/agents/tasks_agent.py"
    from typing import Literal

    from agno.tools import tool


    @tool(external_execution=True)
    def filter_tasks(status: Literal["all", "open", "done"]):
        """Filter the visible task list by status."""
    ```

    Pass `tools=[filter_tasks]` to the `Agent` for this example. The frontend
    handler applies the filter and returns its result.

  </Step>
  <Step>
    ### Give the agent somewhere to store the paused run

    Agno stores the paused run before the frontend can return its result, so
    the `Agent` that owns the external tool needs a database. An agent with an
    external tool and no `db` cannot resume after the frontend answers.

    ```python title="src/agents/chart_agent.py"
    from agno.db.sqlite import SqliteDb

    db = SqliteDb(db_file="tmp/agno.db")
    ```

    `SqliteDb` needs `sqlalchemy` installed. For production use durable shared
    storage such as `PgDb`, because an ephemeral container file cannot resume a
    run on another instance.

  </Step>
</Steps>
