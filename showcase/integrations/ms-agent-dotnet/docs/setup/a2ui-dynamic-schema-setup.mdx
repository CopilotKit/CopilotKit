    ### Bind your own `generate_a2ui` and turn off injection

    A .NET agent binds its own `generate_a2ui` function tool, which calls a
    second model and returns an `a2ui_operations` container. For a working agent,
    see [`DeclarativeGenUiAgent.cs`](https://github.com/CopilotKit/CopilotKit/blob/main/showcase/integrations/ms-agent-dotnet/agent/DeclarativeGenUiAgent.cs).

    The agent writes A2UI v0.9, so set `a2uiVersion: "0.9"` on the runtime.
    When the provider sends a catalog, the runtime then injects `render_a2ui`
    by default. Your agent already owns its tool, so set
    `injectA2UITool: false`. The runtime still converts the operations that
    your tool returns to A2UI 1.0:

    ```typescript title="app/api/copilotkit/route.ts"
    const runtime = new CopilotRuntime({
      agents: { default: myAgent },
      generativeUI: {
        a2uiVersion: "0.9",
        injectA2UITool: false,
        defaultCatalogId: "declarative-gen-ui-catalog",
      },
    });
    ```

    Pin `defaultCatalogId` to the `id` of the UI that your page passes to the
    provider. Models often leave out `catalogId`, and the surface then names a
    catalog that the page does not have.
