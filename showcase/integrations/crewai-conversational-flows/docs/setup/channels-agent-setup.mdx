<Callout type="warn" title="CrewAI 1.15.11 or later is required">
  Conversational Flows use CrewAI's `stream_turn` and ordered StreamFrame
  runtime. Install CrewAI 1.15.11 or later; earlier versions are not compatible
  with this execution path. The showcase pins `crewai==1.15.11` with
  `ag-ui-crewai==0.2.2a1` for reproducible alpha testing.
</Callout>

Expose your CrewAI Crew through an AG-UI server. The
[CopilotKit CrewAI Conversational Flows showcase](https://github.com/CopilotKit/CopilotKit/tree/main/showcase/integrations/crewai-conversational-flows)
includes a reference server; from that integration directory, run:

```bash title="Agent application"
PYTHONPATH=src python -m uvicorn agent_server:app --host 0.0.0.0 --port 8000 --reload
```

The shared crew is mounted at the server root:

```dotenv title=".env"
AGENT_URL=http://localhost:8000/
```

Install the HTTP adapter in the Channels process:

```bash title="Terminal"
npm install @ag-ui/client@0.0.57
```

Create a new HTTP adapter for every channel thread:

```ts title="agent.ts"
import { HttpAgent } from "@ag-ui/client";

export function makeAgent(threadId: string) {
  const agent = new HttpAgent({ url: process.env.AGENT_URL! });
  agent.threadId = threadId;
  return agent;
}
```
