    ```python title="src/agents/shared_state_streaming.py"
        document: str = ""
    ```

  <Step>
    ### Map the tool argument to the state key

    Call `copilotkit_predict_state` with one `StateItem` before the model
    call. While the model streams `write_document`, CopilotKit copies the
    partial `document` argument into the `document` state key. Wrap the call
    in `copilotkit_stream`, or nothing streams until the turn ends.

    ```python title="src/agents/shared_state_streaming.py"
    from crewai.flow.flow import Flow, start
    from litellm import acompletion

    from ag_ui_crewai import StateItem, copilotkit_predict_state, copilotkit_stream


    class SharedStateStreamingFlow(Flow[SharedStateStreamingState]):
        @start()
        async def write(self) -> None:
            await copilotkit_predict_state(
                [
                    StateItem(
                        state_key="document",
                        tool="write_document",
                        tool_argument="document",
                    )
                ]
            )
            tools = [*self.state.copilotkit.actions, WRITE_DOCUMENT_TOOL]
            response = await copilotkit_stream(
                await acompletion(
                    model="openai/gpt-5.4",
                    messages=[
                        {"role": "system", "content": SYSTEM_PROMPT},
                        *self.state.messages,
                    ],
                    tools=tools,
                    parallel_tool_calls=False,
                    stream=True,
                )
            )
    ```

    `WRITE_DOCUMENT_TOOL` is a plain OpenAI-format tool schema with one
    required `document` string argument.

  </Step>
  <Step>
    ### Persist the final value

    When a Flow method finishes, **its state becomes the single source of
    truth**. The streamed predictions are not written to `self.state`, so
    assign the final value yourself. Otherwise it is overwritten when the
    method completes.

    ```python title="src/agents/shared_state_streaming.py"
            # Still inside write(), after the model call (needs `import json`)
            message = response.choices[0].message
            self.state.messages.append(message)
            calls = message.get("tool_calls") or []
            write_call = next(
                (
                    call
                    for call in calls
                    if call.get("function", {}).get("name") == "write_document"
                ),
                None,
            )
            if write_call is None:
                return

            arguments = json.loads(
                write_call.get("function", {}).get("arguments") or "{}"
            )
            document = arguments.get("document")
            self.state.document = document if isinstance(document, str) else ""
    ```

    The showcase Flow then appends a `role: "tool"` message, calls
    `copilotkit_emit_tool_result`, and asks the model for a one-line
    confirmation. See `src/agents/shared_state_streaming.py`.

  </Step>

<Callout title="Emit progress without a tool argument">
  To show progress that is not a tool argument, assign the value and call
  `copilotkit_emit_state` after each sub-step:

  ```python title="agent.py"
  from ag_ui_crewai import copilotkit_emit_state

  for step in steps:
      self.state.observed_steps = [*self.state.observed_steps, step]
      await copilotkit_emit_state(self.state)
      await asyncio.sleep(1)
  ```
</Callout>
