  <Step>
    ### Serve the Strands agent over AG-UI

    Programmatic control (`agent.addMessage`, `copilotkit.runAgent`,
    `agent.subscribe`) drives the same agent your chat UI uses, so a
    headless UI needs no extra backend code. Install the AG-UI Strands
    adapter, wrap your Strands `Agent` in `StrandsAgent`, and serve it with
    `create_strands_app`:

    ```bash
    uv add ag-ui-strands
    ```

    <DemoCode
      file="src/agent_server.py"
      region="strands-app-endpoint"
      title="src/agent_server.py"
    />

    Here `agui_agent` is the `StrandsAgent` that `build_showcase_agent()`
    returns.

  </Step>
  <Step>
