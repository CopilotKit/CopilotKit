The Built-in Agent runs in the same Node.js process as Channels, so it does
not need an `AGENT_URL` or a second server. Follow the
[Built-in Agent quickstart](/quickstart) to configure your model provider.
Then install `@tanstack/ai` and the adapter for your provider, for example
`@tanstack/ai-openai`. The Channels runner already installed the Runtime package.

Create a new agent for each channel thread:

```ts title="agent.ts"
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { openaiText } from "@tanstack/ai-openai";

export function makeAgent(threadId: string) {
  const agent = tanstackAIAgent({
    adapter: () => openaiText("gpt-5.4-mini"),
  });
  agent.threadId = threadId;
  return agent;
}
```
