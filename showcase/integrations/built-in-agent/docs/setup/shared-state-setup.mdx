<Steps>
  <Step>
    ### No backend setup in config mode

    A `BuiltInAgent` built from configuration gets two state tools on every
    run, `AGUISendStateSnapshot` and `AGUISendStateDelta`. When the model
    calls one, the runtime sends the update to the frontend, and `useAgent`
    re-renders. You declare nothing on the agent:

    ```ts title="app/api/copilotkit/[[...slug]]/route.ts"
    import { BuiltInAgent } from "@copilotkit/runtime/v2";

    const builtInAgent = new BuiltInAgent({
      model: "openai:gpt-5.4-mini",
      prompt: SYSTEM_PROMPT,
    });
    ```

    A factory owns its model call and its tool list, so in factory mode the
    agent does not add these state tools for you.

  </Step>
  <Step>
    ### Seed the state so the model sees its shape

    The agent adds the current state to its system prompt only when the
    state is not empty. Set a starting value from the UI, so the model knows
    the keys and the shape of each item before its first update:

    ```tsx title="app/page.tsx"
    import { useEffect } from "react";
    import { useAgent } from "@copilotkit/react-core/v2";

    function TodoApp() {
      const { agent } = useAgent();

      // Seed the state, so the agent sees the shape of a todo in its prompt
      useEffect(() => {
        if (!agent.state.todos) {
          agent.setState({ todos: [{ text: "Try the agent", done: false }] });
        }
      }, [agent]);

      // ...
    }
    ```

  </Step>
