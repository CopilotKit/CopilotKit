    ### Build the sub-agent tools for each run

    The factory builds the sub-agent tools on every run and passes them to
    the model with its other server tools. Each tool shares the run's
    `AbortController`, so stopping the supervisor also stops any sub-agent
    call in flight:

  <Step>
    ### Publish each delegation to shared state

    The runtime has no per-agent state schema, so the factory's stream
    converter writes the delegation log itself. When a sub-agent tool
    returns, it adds an entry keyed by the tool call id and emits the run's
    whole `delegations` list as a `STATE_DELTA`:
