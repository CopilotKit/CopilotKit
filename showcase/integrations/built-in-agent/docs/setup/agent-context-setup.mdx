    ### Pass them to the model call

    A factory owns the model call, so the context reaches the model only if
    you forward those prompts. The Showcase factory appends them after its
    own per-demo prompts on every run:

    <DemoCode
      file="src/lib/factory/tanstack-factory.ts"

      title="src/lib/factory/tanstack-factory.ts — chat() options"
    />

    The read-only context demo registers the default factory with no extra
    options. The context arrives with each run and the agent has no tool to
    change it.
