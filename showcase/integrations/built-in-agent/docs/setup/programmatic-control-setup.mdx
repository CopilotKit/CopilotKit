    The Built-in Agent runs in-process inside your CopilotKit runtime route,
    so there is no agent server to start. `useAgent({ agentId })` and
    `copilotkit.runAgent({ agent })` send the run to that route, and the
    runtime runs the agent registered under the same id:

    tools your components register (`useComponent`, `useFrontendTool`,
    `useHumanInTheLoop`) into client-executed tool declarations, so a
    headless UI's tools reach the model with no backend changes:
