---
title: "useWebmcpTools"
description: "Vue composable that imports page WebMCP tools so a CopilotKit agent can call them"
---

## Overview

The page already registered tools on `document.modelContext`. `useWebmcpTools` imports those tools as CopilotKit frontend tools. When the agent calls one, CopilotKit runs `document.modelContext.executeTool` with the `RegisteredTool` object from `getTools()`.

With no filters, every same-origin tool is imported. Filter order is allow, then deny, then `name`. Tools this app already published with `useFrontendTool({ webmcp: true })` are skipped. Missing `document.modelContext` is a no-op.

<Callout type="info">
  Import from the `/v2` subpath: `@copilotkit/vue/v2`. Call `useWebmcpTools` from
  a component under [`CopilotKitProvider`](/reference/vue/components/CopilotKitProvider).
</Callout>

## Signature

```ts
import { useWebmcpTools } from "@copilotkit/vue/v2";

function useWebmcpTools(options?: {
  agentId?: string;
  allow?: string[];
  deny?: string[];
  name?: string | RegExp;
}): void;
```

## Parameters

<PropertyReference name="options" type="WebMCPToolsOptions">
  Optional filters and agent scope. Omit the object to import every same-origin page tool.

  <PropertyReference name="agentId" type="string">
    Scope imported tools to this agent. Omit it to register them as global tools.
  </PropertyReference>

  <PropertyReference name="allow" type="string[]">
    If set, only these tool names are imported.
  </PropertyReference>

  <PropertyReference name="deny" type="string[]">
    These tool names are never imported. Deny wins if a name is also in `allow`.
  </PropertyReference>

  <PropertyReference name="name" type="string | RegExp">
    Keep an exact tool name, or names that match this regular expression. Applied after allow and deny.
  </PropertyReference>
</PropertyReference>

## Usage

```ts
import { useWebmcpTools } from "@copilotkit/vue/v2";

useWebmcpTools({
  agentId: "support",
  allow: ["searchOrders", "getOrder"],
  deny: ["deleteOrder"],
});
```

## Behavior

- **Same-origin only.** `getTools()` is called with no `fromOrigins`.
- **Live updates.** The composable listens for `toolchange` and re-syncs.
- **Collisions.** If a CopilotKit frontend tool already uses the name, the page tool is skipped and a warning is logged.
- **Cleanup.** Scope dispose removes only tools this composable added.
- **No return value.** The composable returns `void`.
