---
title: "ToolCallStatus"
description: "Lifecycle states of a tool call as it streams in and executes."
---

## Overview

`ToolCallStatus` describes where a tool call is in its lifecycle, from arguments still streaming in to a fully executed result. You receive it as the `status` prop of a tool call render component, for example in [`useRenderTool`](/reference/hooks/useRenderTool) or the `render` option of [`useFrontendTool`](/reference/hooks/useFrontendTool).

## Import

```ts
import { ToolCallStatus } from "@copilotkit/core";
```

## Definition

```ts
enum ToolCallStatus {
  InProgress = "inProgress",
  Executing = "executing",
  Complete = "complete",
}
```

## Members

<PropertyReference name="InProgress" type="inProgress">
  The call has no result yet and no frontend handler is running. The arguments can still be streaming, or a backend tool can be waiting for its result.
</PropertyReference>

<PropertyReference name="Executing" type="executing">
  Arguments have fully arrived and the tool handler is running.
</PropertyReference>

<PropertyReference name="Complete" type="complete">
  The handler has finished and a result is available.
</PropertyReference>

## Usage

```ts
import { ToolCallStatus } from "@copilotkit/core";

function renderToolCall(status: ToolCallStatus) {
  switch (status) {
    case ToolCallStatus.InProgress:
      return "Receiving arguments…";
    case ToolCallStatus.Executing:
      return "Running…";
    case ToolCallStatus.Complete:
      return "Done";
  }
}
```
