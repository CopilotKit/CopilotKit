## Overview

`CopilotMarkdown` renders a Markdown string with sensible React Native styling. It uses the React Native renderer of [`@copilotkit/markdown`](/reference/packages/markdown), which `@copilotkit/react-native` installs for you, so it needs no extra peer dependency. It renders incomplete (streaming) Markdown incrementally as content arrives, which makes it ideal for assistant messages. [`AssistantMessage`](/reference/react-native/components/AssistantMessage) renders its content with this component.

It renders GitHub Flavored Markdown: headings, lists, block quotes, fenced code, tables, strikethrough, and links. It does not render math or highlight code. Fenced code shows as plain code.

## Import

```tsx
import { CopilotMarkdown, defaultMarkdownStyles } from "@copilotkit/react-native/components";
```

## Props

<PropertyReference name="content" type="string" required>
  The Markdown string to render.
</PropertyReference>

<PropertyReference name="style" type="MarkdownStyle">
  Optional style overrides merged on top of the defaults. A map of Markdown
  element names (e.g. `paragraph`, `h1`, `link`, `code`) to style objects, so
  you pass only the elements you change. A key you pass replaces the whole
  default style of that element.
</PropertyReference>

<PropertyReference name="streamingAnimation" type="boolean" default="false">
  Kept for backward compatibility. It has no visual effect: the React Native
  renderer does not animate tokens as they arrive.
</PropertyReference>

## `defaultMarkdownStyles`

The default style map. The component merges `style` over these defaults one element at a time. To change one property of an element, spread the default for that element:

```tsx
import { CopilotMarkdown, defaultMarkdownStyles } from "@copilotkit/react-native/components";

const styles = {
  h1: { ...defaultMarkdownStyles.h1, fontSize: 28, fontWeight: "800" },
};

<CopilotMarkdown content={"# Hello\nThis is **bold**."} style={styles} />;
```

## Usage

```tsx
import { CopilotMarkdown } from "@copilotkit/react-native/components";

<CopilotMarkdown content="**Hello** from CopilotKit!" />;
```
