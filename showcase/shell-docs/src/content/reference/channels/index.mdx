---
title: Channels SDK
description: API reference for managed Slack and Microsoft Teams agents built with @copilotkit/channels.
---

The Channels SDK connects an agent to Slack or Microsoft Teams through a
long-running `@copilotkit/channels` process. CopilotKit Intelligence owns the
provider connection, while your process owns the agent, tools, approvals,
state, and deployment.

```sh
npm install @copilotkit/channels@0.3.0 @copilotkit/runtime@1.64.0
```
