<Step>
  ### Create your AG2 agent

  You need Python 3.11+, [`uv`](https://docs.astral.sh/uv/) and an OpenAI API key. The agent gets its own folder next to your app. From your app folder:

  ```bash
  cd ..
  uv init my-agent
  cd my-agent
  uv add "ag2[ag-ui,openai]>=1.1.2" fastapi uvicorn
  ```

  The `ag-ui` extra adds `AGUIStream`, which serves an AG2 agent over AG-UI, the protocol that Copilot Runtime speaks.

  Replace the contents of `main.py` with a small agent. If you already have an AG2 agent, wrap it in `AGUIStream` and use this as a reference:

  ```python title="main.py"
  from fastapi import FastAPI

  from ag2 import Agent
  from ag2.ag_ui import AGUIStream
  from ag2.config import OpenAIResponsesConfig

  agent = Agent(
      name="assistant",
      prompt="You are a helpful assistant.",
      config=OpenAIResponsesConfig(model="gpt-6-luna"),
  )

  stream = AGUIStream(agent)
  app = FastAPI()
  app.mount("/chat", stream.build_asgi())
  ```

  Put your OpenAI key in `.env`:

  ```plaintext title=".env"
  OPENAI_API_KEY=your_openai_api_key
  ```
</Step>

<Step>
  ### Start the agent

  ```bash
  uv run --env-file .env uvicorn main:app --port 8000
  ```

  Keep this terminal open. The agent listens on `http://localhost:8000/chat/`. `--env-file .env` loads `OPENAI_API_KEY` into the agent.
</Step>

<Step>
  ### Create the Copilot Runtime

  Open a new terminal in your app folder. The runtime reaches the agent with `HttpAgent` from `@ag-ui/client`:

  ```bash
  npm install @ag-ui/client
  ```

  `@ag-ui/client` must be the same version that `@copilotkit/runtime` uses. Run `npm ls @ag-ui/client`. The top-level copy must be the version that `@copilotkit/runtime` lists as `deduped`.

  Add `server.ts`, a small Node server that hosts Copilot Runtime at `/api/copilotkit` and registers your agent as the `default` agent:

  ```ts title="server.ts"
  import { createServer } from "node:http";
  import { HttpAgent } from "@ag-ui/client";
  import { CopilotRuntime } from "@copilotkit/runtime/v2";
  import { createCopilotNodeListener } from "@copilotkit/runtime/v2/node";

  const runtime = new CopilotRuntime({
    agents: {
      // [!code highlight:3]
      default: new HttpAgent({
        url: process.env.AGENT_URL ?? "http://localhost:8000/chat/",
      }),
    },
  });

  const port = Number(process.env.PORT ?? 8200);

  createServer(
    createCopilotNodeListener({
      runtime,
      basePath: "/api/copilotkit",
      cors: true,
    }),
  ).listen(port, () => {
    console.log(
      `Copilot Runtime listening at http://localhost:${port}/api/copilotkit`,
    );
  });
  ```

  Keep the trailing slash in the agent URL. Without it, the agent answers each run with a redirect first.

  `cors: true` lets the app's dev server, on another port, call the runtime. The model key stays with the agent, so the runtime needs none.
</Step>
