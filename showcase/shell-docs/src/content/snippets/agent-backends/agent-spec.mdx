<Step>
  ### Create your Agent Spec agent

  You need [`uv`](https://docs.astral.sh/uv/) and an OpenAI API key. The agent gets its own folder next to your app. From your app folder:

  ```bash
  cd ..
  uv init --python 3.13 my-agent
  cd my-agent
  uv add "ag-ui-agent-spec[langgraph]" uvicorn
  ```

  `ag-ui-agent-spec` runs an Agent Spec agent and serves it over AG-UI, the protocol that Copilot Runtime speaks. The `langgraph` extra runs the agent on LangGraph. The package supports Python 3.10 to 3.13.

  Replace the contents of `main.py` with a small agent. If you already have an Agent Spec config (JSON or YAML), pass that string as `agent_spec_config` and use this as a reference:

  ```python title="main.py"
  import os

  from ag_ui_agentspec.agent import AgentSpecAgent
  from ag_ui_agentspec.endpoint import add_agentspec_fastapi_endpoint
  from fastapi import FastAPI
  from pyagentspec.agent import Agent
  from pyagentspec.llms import OpenAiCompatibleConfig
  from pyagentspec.serialization import AgentSpecSerializer

  agentspec_agent = Agent(
      name="AgentSpecAgent",
      description="A starter agent.",
      system_prompt="You are a helpful assistant.",
      llm_config=OpenAiCompatibleConfig(
          name="my-llm",
          model_id=os.getenv("OPENAI_MODEL", "gpt-6-luna"),
          url=os.getenv("OPENAI_BASE_URL", "https://api.openai.com/v1"),
      ),
  )

  agent_spec_config = AgentSpecSerializer().to_json(agentspec_agent)

  app = FastAPI()
  agent = AgentSpecAgent(agent_spec_config=agent_spec_config, runtime="langgraph")
  add_agentspec_fastapi_endpoint(app, agentspec_agent=agent, path="/")
  ```

  Put your OpenAI key in `.env`:

  ```plaintext title=".env"
  OPENAI_API_KEY=your_openai_api_key
  OPENAI_MODEL=gpt-6-luna
  ```

  To use another OpenAI-compatible provider, also set `OPENAI_BASE_URL` to its endpoint.
</Step>

<Step>
  ### Start the agent

  ```bash
  uv run --env-file .env uvicorn main:app --port 8000
  ```

  Keep this terminal open. The agent listens on `http://localhost:8000`. `--env-file .env` loads your key into the agent.
</Step>

<Step>
  ### Create the Copilot Runtime

  Open a new terminal in your app folder. The runtime reaches the agent with `HttpAgent` from `@ag-ui/client`:

  ```bash
  npm install @ag-ui/client
  ```

  `@ag-ui/client` must be the same version that `@copilotkit/runtime` uses. Run `npm ls @ag-ui/client`. The top-level copy must be the version that `@copilotkit/runtime` lists as `deduped`.

  Add `server.ts`, a small Node server that hosts Copilot Runtime at `/api/copilotkit` and registers your agent as the `default` agent:

  ```ts title="server.ts"
  import { createServer } from "node:http";
  import { HttpAgent } from "@ag-ui/client";
  import { CopilotRuntime } from "@copilotkit/runtime/v2";
  import { createCopilotNodeListener } from "@copilotkit/runtime/v2/node";

  const runtime = new CopilotRuntime({
    agents: {
      // [!code highlight:3]
      default: new HttpAgent({
        url: process.env.AGENT_URL ?? "http://localhost:8000/",
      }),
    },
  });

  const port = Number(process.env.PORT ?? 8200);

  createServer(
    createCopilotNodeListener({
      runtime,
      basePath: "/api/copilotkit",
      cors: true,
    }),
  ).listen(port, () => {
    console.log(
      `Copilot Runtime listening at http://localhost:${port}/api/copilotkit`,
    );
  });
  ```

  `cors: true` lets the app's dev server, on another port, call the runtime. The model key stays with the agent, so the runtime needs none.
</Step>
