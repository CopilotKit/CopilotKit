<Step>
  ### Create your Strands agent

  You need an OpenAI API key. The agent gets its own folder next to your app. From your app folder:

  ```bash
  cd ..
  mkdir my-agent && cd my-agent
  npm init -y
  npm pkg set type=module
  npm install @ag-ui/aws-strands @strands-agents/sdk express openai
  npm install -D tsx typescript @types/node @types/express
  ```

  `@ag-ui/aws-strands` serves a Strands agent over AG-UI, the protocol that Copilot Runtime speaks. Strands' `OpenAIModel` loads the `openai` package.

  Create `main.ts` with a small agent. If you already have a Strands agent, pass it to `StrandsAgent` and use this as a reference:

  ```ts title="main.ts"
  import { Agent } from "@strands-agents/sdk";
  import { OpenAIModel } from "@strands-agents/sdk/models/openai";
  import { StrandsAgent } from "@ag-ui/aws-strands";
  import { createStrandsApp } from "@ag-ui/aws-strands/server";

  const model = new OpenAIModel({
    apiKey: process.env.OPENAI_API_KEY ?? "",
    modelId: "gpt-6-luna",
  });

  const agent = new Agent({
    model,
    systemPrompt: "You are a helpful AI assistant.",
  });

  await agent.initialize();

  const aguiAgent = new StrandsAgent({
    agent,
    name: "strands_agent",
  });

  const app = await createStrandsApp(aguiAgent, { path: "/" });

  const port = Number(process.env.PORT ?? 8000);

  app.listen(port, () => {
    console.log(`Agent listening on http://localhost:${port}`);
  });
  ```

  Put your OpenAI key in `.env`:

  ```plaintext title=".env"
  OPENAI_API_KEY=your_openai_api_key
  ```
</Step>

<Step>
  ### Start the agent

  ```bash
  npx tsx --env-file=.env main.ts
  ```

  Keep this terminal open. The agent listens on `http://localhost:8000`. `--env-file=.env` loads `OPENAI_API_KEY` into the agent. Without it, the agent stops at once with `OpenAI API key is required`.
</Step>

<Step>
  ### Create the Copilot Runtime

  Open a new terminal in your app folder. The runtime reaches the agent with `HttpAgent` from `@ag-ui/client`:

  ```bash
  npm install @ag-ui/client
  ```

  `@ag-ui/client` must be the same version that `@copilotkit/runtime` uses. Run `npm ls @ag-ui/client`. The top-level copy must be the version that `@copilotkit/runtime` lists as `deduped`.

  Add `server.ts`, a small Node server that hosts Copilot Runtime at `/api/copilotkit` and registers your agent as the `default` agent:

  ```ts title="server.ts"
  import { createServer } from "node:http";
  import { HttpAgent } from "@ag-ui/client";
  import { CopilotRuntime } from "@copilotkit/runtime/v2";
  import { createCopilotNodeListener } from "@copilotkit/runtime/v2/node";

  const runtime = new CopilotRuntime({
    agents: {
      // [!code highlight:3]
      default: new HttpAgent({
        url: process.env.AGENT_URL ?? "http://localhost:8000/",
      }),
    },
  });

  const port = Number(process.env.PORT ?? 8200);

  createServer(
    createCopilotNodeListener({
      runtime,
      basePath: "/api/copilotkit",
      cors: true,
    }),
  ).listen(port, () => {
    console.log(
      `Copilot Runtime listening at http://localhost:${port}/api/copilotkit`,
    );
  });
  ```

  `cors: true` lets the app's dev server, on another port, call the runtime. The model key stays with the agent, so the runtime needs none.
</Step>
