<Step>
  ### Create your Pydantic AI agent

  You need Python 3.12+, [`uv`](https://docs.astral.sh/uv/) and an OpenAI API key. The agent gets its own folder next to your app. From your app folder:

  ```bash
  cd ..
  uv init my-agent
  cd my-agent
  uv add 'pydantic-ai-slim[ag-ui,openai]>=2,<3' 'starlette>=0.46.2' uvicorn
  ```

  The `ag-ui` extra serves a Pydantic AI agent over AG-UI, the protocol that Copilot Runtime speaks.

  Replace the contents of `main.py` with a small agent. If you already have a Pydantic AI agent, pass it to `AGUIAdapter.dispatch_request` and use this as a reference:

  ```python title="main.py"
  from pydantic_ai import Agent
  from pydantic_ai.ui.ag_ui import AGUIAdapter
  from starlette.applications import Starlette
  from starlette.requests import Request
  from starlette.responses import Response
  from starlette.routing import Route

  agent = Agent("openai:gpt-6-luna", instructions="Be fun!")


  async def run_agent(request: Request) -> Response:
      return await AGUIAdapter.dispatch_request(request, agent=agent)


  app = Starlette(routes=[Route("/", run_agent, methods=["POST"])])
  ```

  Put your OpenAI key in `.env`:

  ```plaintext title=".env"
  OPENAI_API_KEY=your_openai_api_key
  ```
</Step>

<Step>
  ### Start the agent

  ```bash
  uv run --env-file .env uvicorn main:app --port 8000
  ```

  Keep this terminal open. The agent listens on `http://localhost:8000`. `--env-file .env` loads `OPENAI_API_KEY` into the agent. Without the key, the agent does not start.
</Step>

<Step>
  ### Create the Copilot Runtime

  Open a new terminal in your app folder. The runtime reaches the agent with `HttpAgent` from `@ag-ui/client`:

  ```bash
  npm install @ag-ui/client
  ```

  `@ag-ui/client` must be the same version that `@copilotkit/runtime` uses. Run `npm ls @ag-ui/client`. The top-level copy must be the version that `@copilotkit/runtime` lists as `deduped`.

  Add `server.ts`, a small Node server that hosts Copilot Runtime at `/api/copilotkit` and registers your agent as the `default` agent:

  ```ts title="server.ts"
  import { createServer } from "node:http";
  import { HttpAgent } from "@ag-ui/client";
  import { CopilotRuntime } from "@copilotkit/runtime/v2";
  import { createCopilotNodeListener } from "@copilotkit/runtime/v2/node";

  const runtime = new CopilotRuntime({
    agents: {
      // [!code highlight:3]
      default: new HttpAgent({
        url: process.env.AGENT_URL ?? "http://localhost:8000/",
      }),
    },
  });

  const port = Number(process.env.PORT ?? 8200);

  createServer(
    createCopilotNodeListener({
      runtime,
      basePath: "/api/copilotkit",
      cors: true,
    }),
  ).listen(port, () => {
    console.log(
      `Copilot Runtime listening at http://localhost:${port}/api/copilotkit`,
    );
  });
  ```

  `cors: true` lets the app's dev server, on another port, call the runtime. The model key stays with the agent, so the runtime needs none.
</Step>
