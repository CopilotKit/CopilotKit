<Step>
  ### Create your Google Antigravity agent

  You need Python 3.10+, [`uv`](https://docs.astral.sh/uv/) and a Gemini API key. The agent gets its own folder next to your app. From your app folder:

  ```bash
  cd ..
  uv init my-agent
  cd my-agent
  uv add google-antigravity ag-ui-antigravity fastapi uvicorn
  ```

  `ag-ui-antigravity` serves an Antigravity agent over AG-UI, the protocol that Copilot Runtime speaks.

  Replace the contents of `main.py` with a small agent. If you already have an Antigravity agent, pass its model, instructions and `tools` to `AntigravityAgent`:

  ```python title="main.py"
  import os

  from ag_ui_antigravity import AntigravityAgent, create_antigravity_app

  agent = AntigravityAgent(
      model="gemini-2.5-flash",
      api_key=os.environ["GEMINI_API_KEY"],
      system_instructions="You are a helpful assistant.",
      # The harness does file and shell work only in these folders.
      # Keep the path short and stable.
      workspaces=[os.path.expanduser("~/agent-workspace")],
  )

  app = create_antigravity_app(agent, path="/")
  ```

  Put your Gemini key in `.env`. The name must be `GEMINI_API_KEY`, not `GOOGLE_API_KEY`:

  ```plaintext title=".env"
  GEMINI_API_KEY=your_gemini_api_key
  ```
</Step>

<Step>
  ### Start the agent

  ```bash
  uv run --env-file .env uvicorn main:app --port 8000
  ```

  Keep this terminal open. The agent listens on `http://localhost:8000`. `--env-file .env` loads `GEMINI_API_KEY` into the agent. Without it, `main.py` stops with `KeyError: 'GEMINI_API_KEY'`.
</Step>

<Step>
  ### Create the Copilot Runtime

  Open a new terminal in your app folder. The runtime reaches the agent with `HttpAgent` from `@ag-ui/client`:

  ```bash
  npm install @ag-ui/client
  ```

  `@ag-ui/client` must be the same version that `@copilotkit/runtime` uses. Run `npm ls @ag-ui/client`. The top-level copy must be the version that `@copilotkit/runtime` lists as `deduped`.

  Add `server.ts`, a small Node server that hosts Copilot Runtime at `/api/copilotkit` and registers your agent as the `default` agent:

  ```ts title="server.ts"
  import { createServer } from "node:http";
  import { HttpAgent } from "@ag-ui/client";
  import { CopilotRuntime } from "@copilotkit/runtime/v2";
  import { createCopilotNodeListener } from "@copilotkit/runtime/v2/node";

  const runtime = new CopilotRuntime({
    agents: {
      // [!code highlight:3]
      default: new HttpAgent({
        url: process.env.AGENT_URL ?? "http://localhost:8000",
      }),
    },
  });

  const port = Number(process.env.PORT ?? 8200);

  createServer(
    createCopilotNodeListener({
      runtime,
      basePath: "/api/copilotkit",
      cors: true,
    }),
  ).listen(port, () => {
    console.log(
      `Copilot Runtime listening at http://localhost:${port}/api/copilotkit`,
    );
  });
  ```

  `cors: true` lets the app's dev server, on another port, call the runtime. The model key stays with the agent, so the runtime needs none.
</Step>
