
To connect a FastAPI server to Copilot Cloud, you use a concept called "Remote Endpoints"
which allow CopilotKit runtime to connect to various backends.

1. Open a tunnel to your FastAPI server:

   ```sh
   npx copilotkit@latest dev --port <port_number>
   ```

   <Callout title="No tunnel?">
     If your FastAPI server is hosted, skip this step. In step 4, use the address of your hosted server.
   </Callout>

2. <LinkToCopilotCloud asButton={false}>Navigate to Copilot Cloud</LinkToCopilotCloud>. Under **Remote Endpoints**, click **+ Add New**.
3. Select **CopilotKit Remote Endpoint**.
4. In **Remote Endpoint Base URL**, enter the tunnel URL plus the path of your CopilotKit endpoint, for example `https://<tunnel-url>/copilotkit`.
5. Click **Test Endpoint**. When the test passes, click **Save Remote Endpoint**.

Your CopilotKit runtime appears in the list of available agents in CopilotKit.
