The Copilot Runtime serves your agents to the frontend. In this example it runs a
built-in agent (`tanstackAIAgent`) on an OpenAI model. To use a different provider,
swap the adapter (for example `anthropicText("claude-sonnet-4-6")` from `@tanstack/ai-anthropic`).

### Install the runtime package

```npm
npm install @copilotkit/runtime @tanstack/ai @tanstack/ai-openai
```

### Add your API key

Next, add your API key to the `.env` file in the root of your project:

```plaintext title=".env"
OPENAI_API_KEY=your_api_key_here
```

### Setup the Runtime Endpoint

<Callout type="warn">
    ### Serverless Function Timeouts

    When deploying to serverless platforms (Vercel, AWS Lambda, etc.), be aware that default function timeouts may be too short for CopilotKit's streaming responses:

    - Vercel defaults: 10s (Hobby), 15s (Pro)
    - AWS Lambda default: 3s

    **Solution options:**
    1. Increase function timeout:
        ```json
        // vercel.json
        {
          "functions": {
            "api/copilotkit/**/*": {
              "maxDuration": 60
            }
          }
        }
        ```
    2. Use [Copilot Cloud](https://dashboard.operations.copilotkit.ai/) to avoid timeout issues entirely
</Callout>

    {/* Next.js App Router */}
    <Tab value="Next.js App Router">
        Create a catch-all route to handle the `/api/copilotkit` endpoint. `createCopilotRuntimeHandler` takes a Fetch `Request` and returns a `Response`, so you can export it directly.

        ```ts title="app/api/copilotkit/[[...slug]]/route.ts"
        import {
          CopilotRuntime,
          createCopilotRuntimeHandler,
        } from "@copilotkit/runtime";
        import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
        import { openaiText } from "@tanstack/ai-openai";

        const runtime = new CopilotRuntime({
          agents: { default: tanstackAIAgent({ adapter: () => openaiText("gpt-5.5") }) },
        });

        const handler = createCopilotRuntimeHandler({
          runtime,
          basePath: "/api/copilotkit",
        });

        export const GET = handler;
        export const POST = handler;
        ```

        Your Copilot Runtime endpoint should be available at `http://localhost:3000/api/copilotkit`.
    </Tab>

    {/* Next.js Pages Router */}
    <Tab value="Next.js Pages Router">
        Create a catch-all API route to handle the `/api/copilotkit` endpoint. `createCopilotNodeListener` returns a Node `(req, res)` listener, which Next.js accepts as an API route handler:

        ```ts title="pages/api/copilotkit/[[...slug]].ts"
        import { CopilotRuntime } from "@copilotkit/runtime";
        import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
        import { openaiText } from "@tanstack/ai-openai";
        import { createCopilotNodeListener } from "@copilotkit/runtime/node";

        const runtime = new CopilotRuntime({
          agents: { default: tanstackAIAgent({ adapter: () => openaiText("gpt-5.5") }) },
        });

        export default createCopilotNodeListener({
          runtime,
          basePath: "/api/copilotkit",
        });
        ```

        Your Copilot Runtime endpoint should be available at `http://localhost:3000/api/copilotkit`.
    </Tab>

    {/* Node.js Express */}
    <Tab value="Node.js Express">
        Create a new Express.js app and mount the Copilot Runtime listener. Express strips the mount prefix from `req.url`, so the listener's `basePath` is `/`:

        ```ts title="server.ts"
        import express from "express";
        import { CopilotRuntime } from "@copilotkit/runtime";
        import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
        import { openaiText } from "@tanstack/ai-openai";
        import { createCopilotNodeListener } from "@copilotkit/runtime/node";

        const app = express();

        const runtime = new CopilotRuntime({
          agents: { default: tanstackAIAgent({ adapter: () => openaiText("gpt-5.5") }) },
        });

        app.use(
          "/copilotkit",
          createCopilotNodeListener({ runtime, basePath: "/" }),
        );

        app.listen(4000, () => {
          console.log("Listening at http://localhost:4000/copilotkit");
        });
        ```

        Your Copilot Runtime endpoint should be available at `http://localhost:4000/copilotkit`.

        <Callout type="warn">
            Remember to point your `runtimeUrl` to the correct endpoint in your client-side code, e.g. `http://localhost:PORT/copilotkit`.
        </Callout>
    </Tab>

    {/* Node.js HTTP */}
    <Tab value="Node.js HTTP">
        Set up a simple Node.js HTTP server and use the Copilot Runtime listener to handle requests:

        ```ts title="server.ts"
        import { createServer } from "node:http";
        import { CopilotRuntime } from "@copilotkit/runtime";
        import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
        import { openaiText } from "@tanstack/ai-openai";
        import { createCopilotNodeListener } from "@copilotkit/runtime/node";

        const runtime = new CopilotRuntime({
          agents: { default: tanstackAIAgent({ adapter: () => openaiText("gpt-5.5") }) },
        });

        const listener = createCopilotNodeListener({
          runtime,
          basePath: "/copilotkit",
        });

        createServer(listener).listen(4000, () => {
          console.log("Listening at http://localhost:4000/copilotkit");
        });
        ```

        Your Copilot Runtime endpoint should be available at `http://localhost:4000/copilotkit`.

        <Callout type="warn">
            Remember to point your `runtimeUrl` to the correct endpoint in your client-side code, e.g. `http://localhost:PORT/copilotkit`.
        </Callout>
    </Tab>

    {/* NestJS */}
    <Tab value="NestJS">
        Set up a controller in NestJS that passes the `/copilotkit` routes to the Copilot Runtime listener:

        ```ts title="copilotkit.controller.ts"
        import type { IncomingMessage, ServerResponse } from "node:http";
        import { All, Controller, Req, Res } from "@nestjs/common";
        import { CopilotRuntime } from "@copilotkit/runtime";
        import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
        import { openaiText } from "@tanstack/ai-openai";
        import { createCopilotNodeListener } from "@copilotkit/runtime/node";

        const runtime = new CopilotRuntime({
          agents: { default: tanstackAIAgent({ adapter: () => openaiText("gpt-5.5") }) },
        });

        const listener = createCopilotNodeListener({
          runtime,
          basePath: "/copilotkit",
        });

        @Controller("copilotkit")
        export class CopilotKitController {
          @All(["", "*path"])
          copilotkit(@Req() req: IncomingMessage, @Res() res: ServerResponse) {
            return listener(req, res);
          }
        }
        ```

        Your Copilot Runtime endpoint should be available at `http://localhost:3000/copilotkit`.

        <Callout type="warn">
            Remember to point your `runtimeUrl` to the correct endpoint in your client-side code, e.g. `http://localhost:PORT/copilotkit`.
        </Callout>
