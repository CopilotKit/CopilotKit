Follow the [Agent Spec quickstart](/agent-spec/quickstart) to configure your
agent. Both of its paths serve the agent over AG-UI at the server root, on port
8000. For the **Use an existing agent** path, start `main.py`:

```bash title="Agent application"
python main.py
```

If you chose the starter instead, keep its `npm run dev` process running.

Point the Channels process at the agent:

```dotenv title=".env"
AGENT_URL=http://localhost:8000/
```

Install the HTTP adapter in the Channels process:

```bash title="Terminal"
npm install @ag-ui/client@0.0.59
```

Create a new HTTP adapter for every channel thread:

```ts title="agent.ts"
import { HttpAgent } from "@ag-ui/client";

export function makeAgent(threadId: string) {
  const agent = new HttpAgent({ url: process.env.AGENT_URL! });
  agent.threadId = threadId;
  return agent;
}
```
