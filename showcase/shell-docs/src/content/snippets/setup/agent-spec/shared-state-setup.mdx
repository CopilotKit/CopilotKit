<Callout type="warn" title="Shared state on Agent Spec">
  Agent Spec agentic chat streams text and tool events. It has no shared-state
  sync, so the `useAgent` state patterns on this page are not available for
  Agent Spec. For shared-state patterns, mirror what you surface as messages
  or tool calls. See the
  [Agent Spec reference sheet](https://oracle.github.io/agent-spec/development/misc/reference_sheet.html)
  for the event formats.
</Callout>
