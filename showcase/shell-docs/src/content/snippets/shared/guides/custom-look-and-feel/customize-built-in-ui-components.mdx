## CSS Variables (Easiest)

The easiest way to change the colors using in the Copilot UI components is to override CopilotKit CSS variables.

<Callout type="info">
  Hover over the interactive UI elements below to see the available CSS
  variables.
</Callout>

<CopilotKitCSS />
<InteractiveCSSInspector />

Once you've found the right variable, override it on the `[data-copilotkit]` element, which is the root of every CopilotKit component. Put a `.dark` ancestor around it to set the dark-mode values.

```css title="globals.css"
[data-copilotkit] {
  --primary: oklch(0.55 0.22 264);
  --primary-foreground: oklch(0.99 0 0);
}

.dark [data-copilotkit] {
  --background: oklch(0.145 0 0);
  --foreground: oklch(0.985 0 0);
}
```

### Reference

| CSS Variable           | Description                                       |
| ---------------------- | ------------------------------------------------- |
| `--primary`            | Main brand/action color for buttons and controls  |
| `--primary-foreground` | Text color on primary elements                    |
| `--background`         | Main container background color                   |
| `--foreground`         | Primary text color                                |
| `--secondary`          | Secondary background for cards and panels         |
| `--muted`              | Subtle backgrounds and disabled/inactive states   |
| `--muted-foreground`   | Secondary text color                              |
| `--border`             | Border color for dividers and containers          |
| `--radius`             | Global corner radius                              |

## Custom CSS

In addition to customizing the colors, the CopilotKit CSS is structured to easily allow customization via CSS classes.

```css title="globals.css"
.copilotKitButton {
  border-radius: 0;
}

.copilotKitMessages {
  padding: 2rem;
}

.copilotKitUserMessage {
  background: #007aff;
}
```

### Reference

<Callout>
  For the full stylesheet, see
  [`globals.css`](https://github.com/CopilotKit/CopilotKit/blob/main/packages/react-core/src/styles/globals.css).
</Callout>

| CSS Class                     | Description                                         |
| ----------------------------- | --------------------------------------------------- |
| `.copilotKitChat`             | Base chat layout container                          |
| `.copilotKitWindow`           | Root container of the popup and sidebar windows     |
| `.copilotKitPopup`            | Popup chat window                                   |
| `.copilotKitSidebar`          | Sidebar chat window                                 |
| `.copilotKitHeader`           | Top bar of the popup and sidebar windows            |
| `.copilotKitMessages`         | Container for all chat messages                     |
| `.copilotKitMessage`          | Base styling for all chat messages                  |
| `.copilotKitUserMessage`      | User messages                                       |
| `.copilotKitAssistantMessage` | AI responses                                        |
| `.copilotKitInput`            | Text input container with typing area and buttons   |
| `.copilotKitButton`           | Chat toggle button of the popup and sidebar         |

## Custom Fonts

You can customize the fonts by updating the `fontFamily` property in the various CSS classes that are used in the CopilotKit.

```css title="globals.css"
.copilotKitMessages {
  font-family: "Arial, sans-serif";
}

.copilotKitInput {
  font-family: "Arial, sans-serif";
}
```

### Reference

You can update the main content classes to change the font family for the various components.

| CSS Class                     | Description                        |
| ----------------------------- | ---------------------------------- |
| `.copilotKitMessages`         | Main container for all messages    |
| `.copilotKitInput`            | The input field                    |
| `.copilotKitMessage`          | Base styling for all chat messages |
| `.copilotKitUserMessage`      | User messages                      |
| `.copilotKitAssistantMessage` | AI responses                       |

## Custom Icons

`CopilotPopup` and `CopilotSidebar` take a `toggleButton` slot. Pass your own icon components as its `openIcon` and `closeIcon`. Each icon receives SVG props, including the default `className`.

```tsx
import type { SVGProps } from "react";
import { CopilotPopup } from "@copilotkit/react-core";

function OpenIcon(props: SVGProps<SVGSVGElement>) {
  return (
    <svg viewBox="0 0 24 24" fill="currentColor" {...props}>
      <circle cx="12" cy="12" r="10" />
    </svg>
  );
}

function CloseIcon(props: SVGProps<SVGSVGElement>) {
  return (
    <svg viewBox="0 0 24 24" stroke="currentColor" {...props}>
      <path d="M6 6l12 12M18 6L6 18" />
    </svg>
  );
}

export function Chat() {
  return <CopilotPopup toggleButton={{ openIcon: OpenIcon, closeIcon: CloseIcon }} />;
}
```

### Reference

| `toggleButton` slot | Description                                   |
| ------------------- | --------------------------------------------- |
| `openIcon`          | The icon shown on the button when chat is closed |
| `closeIcon`         | The icon shown on the button when chat is open   |

For other icons (send, stop, copy, and so on), replace the sub-component that renders them with a [slot](/custom-look-and-feel/slots).

## Custom Labels

To customize labels, pass the `labels` property to the `CopilotSidebar`, `CopilotPopup` or `CopilotChat` component.

```tsx
import { CopilotChat } from "@copilotkit/react-core";

export function Chat() {
  return (
    <CopilotChat
      labels={{
        welcomeMessageText: "Hello! How can I help you today?",
        modalHeaderTitle: "My Copilot",
        chatInputPlaceholder: "Ask me anything!",
        chatInputToolbarStopButtonLabel: "Stop",
        assistantMessageToolbarRegenerateLabel: "Regenerate",
      }}
    />
  );
}
```

### Reference

| Label                                    | Description                                   |
| ---------------------------------------- | --------------------------------------------- |
| `welcomeMessageText`                     | The welcome message shown in an empty chat    |
| `modalHeaderTitle`                       | The title to display in the header            |
| `chatInputPlaceholder`                   | The placeholder to display in the input       |
| `chatInputToolbarStopButtonLabel`        | The label of the stop button                  |
| `assistantMessageToolbarRegenerateLabel` | The label of the regenerate button            |

See `CopilotChatLabels` for the full list.
