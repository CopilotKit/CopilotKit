Some tool calls have no renderer of their own, such as MCP tools. To show them in the chat, register a catch-all renderer with `useDefaultRenderTool`. It renders **any tool** that has no renderer registered with `useRenderTool`. This is useful for:

- Displaying all tool calls during development
- Rendering MCP (Model Context Protocol) tools
- Providing a generic fallback UI for unexpected tools

```tsx title="app/page.tsx"
import { useDefaultRenderTool } from "@copilotkit/react-core"; // [!code highlight]
// ...

const YourMainContent = () => {
  // ...
  // [!code highlight:15]
  useDefaultRenderTool({
    render: ({ name, status, result }) => {
      return (
        <div style={{ color: "black" }}>
          <span>
            {status === "complete" ? "✓" : "⏳"}
            {name}
          </span>
          {status === "complete" && result && (
            <pre>{result}</pre>
          )}
        </div>
      );
    },
  });
  // ...
};
```

<Callout type="info">
  Unlike [`useRenderTool`](/reference/hooks/useRenderTool) with a `name`,
  which targets one tool,
  [`useDefaultRenderTool`](/reference/hooks/useDefaultRenderTool) catches
  **all** tools that have no renderer of their own.
</Callout>
