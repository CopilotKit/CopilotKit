`useDefaultRenderTool()` registers CopilotKit's built-in catch-all card for
every tool without a dedicated `useRenderTool` renderer. Use it when you want
tool names, status, arguments, and results to remain visible before you build
a custom card.

<Callout type="info">
  For a branded fallback, use [`useDefaultRenderTool`](/reference/hooks/useDefaultRenderTool).
  For a named renderer with a typed `parameters` schema, use
  [`useRenderTool`](/reference/hooks/useRenderTool).
</Callout>
