Install these two packages at matching versions. `@copilotkit/runtime` 1.88.0
is built against `@copilotkit/channels` 0.12.0. Keep exact versions in your
lockfile, and upgrade both packages together.

```bash title="Terminal"
npm install --save-exact @copilotkit/channels@0.12.0 @copilotkit/runtime@1.88.0
```
