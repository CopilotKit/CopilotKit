## Overview

Headless UI uses the `useAgent` and `useCopilotKit` hooks. You build the chat UI. CopilotKit still runs threads, generative UI, suggestions, and human-in-the-loop.

<Callout type="info">
  For the full composition (reasoning messages, activity messages, and custom
  message slots), see [Headless UI](/built-in-agent/custom-look-and-feel/headless-ui).
</Callout>

<Steps>
<Step>
### Create a new application

Scaffold a CopilotKit project:

```bash
npx copilotkit@latest create
```
</Step>

<Step>
### Wire your CopilotKit provider

Wrap your root layout with `CopilotKitProvider` and point it at your runtime:

```tsx title="src/app/layout.tsx"
import type { ReactNode } from "react";
import { CopilotKitProvider } from "@copilotkit/react-core";

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="en">
      <body>
        <CopilotKitProvider runtimeUrl="/api/copilotkit">
          {children}
        </CopilotKitProvider>
      </body>
    </html>
  );
}
```
</Step>

<Step>
### Build a headless chat component

Use `useAgent` to read the messages and running state, and `useCopilotKit` to run the agent. Then wire them to your own UI:

```tsx title="src/app/page.tsx"
"use client";
import { useState } from "react";
import { useAgent, useCopilotKit } from "@copilotkit/react-core";
import { randomUUID } from "@copilotkit/shared";

export default function Home() {
  const { agent } = useAgent();
  const { copilotkit } = useCopilotKit();
  const [input, setInput] = useState("");

  const handleSend = async () => {
    if (!input.trim()) return;
    agent.addMessage({ id: randomUUID(), role: "user", content: input });
    setInput("");
    await copilotkit.runAgent({ agent });
  };

  return (
    <div>
      <h1>My Headless Chat</h1>

      <div>
        {agent.messages.map((message) => (
          <div key={message.id}>
            <strong>{message.role === "user" ? "You" : "Assistant"}:</strong>
            {typeof message.content === "string" && <p>{message.content}</p>}
          </div>
        ))}
        {agent.isRunning && <p>Assistant is typing...</p>}
      </div>

      <div>
        <input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          onKeyDown={(e) => e.key === "Enter" && handleSend()}
          placeholder="Type your message here..."
        />
        <button onClick={handleSend} disabled={agent.isRunning}>
          Send
        </button>
      </div>
    </div>
  );
}
```

A message's `content` is a string for text. Other messages can carry content
parts or no content, so the example renders only string content.
</Step>
</Steps>

## Working with generative UI

You can render generative UI either via `useFrontendTool` / `useComponent`, or by reading tool calls and rendering them directly.

<video
  src="https://cdn.copilotkit.ai/docs/copilotkit/videos/gen-ui.mp4"
  className="rounded-xl shadow-lg border"
  loop
  playsInline
  autoPlay
  muted
/>

### With `useFrontendTool`

Register a frontend tool and attach a render function. `useRenderToolCall` returns a function that paints the registered renderer for a tool call, so call it for each tool call in the message stream:

```tsx title="src/app/components/chat.tsx"
import {
  useAgent,
  useFrontendTool,
  useRenderToolCall,
  type ToolMessage,
} from "@copilotkit/react-core";

export const Chat = () => {
  const { agent } = useAgent();
  const renderToolCall = useRenderToolCall();

  useFrontendTool({
    name: "showCustomComponent",
    description: "Show a custom component in the chat.",
    handler: async () => "Foo, Bar, Baz",
    render: ({ result, args, status }) => (
      <div
        style={{
          backgroundColor: "red",
          padding: "10px",
          borderRadius: "5px",
        }}
      >
        <p>Custom component</p>
        <p>Result: {result}</p>
        <p>Args: {JSON.stringify(args)}</p>
        <p>Status: {status}</p>
      </div>
    ),
  });

  return (
    <div>
      {agent.messages.map((message) => (
        <div key={message.id}>
          {message.role === "user" ? "User: " : "Assistant: "}
          {typeof message.content === "string" && message.content}
          {message.role === "assistant" &&
            message.toolCalls?.map((toolCall) => {
              const toolMessage = agent.messages.find(
                (m): m is ToolMessage =>
                  m.role === "tool" && m.toolCallId === toolCall.id,
              );
              return (
                <div key={toolCall.id}>
                  {renderToolCall({ toolCall, toolMessage })}
                </div>
              );
            })}
        </div>
      ))}
    </div>
  );
};
```

### With raw tool-call data

If you don't want to use a renderer, render the raw data directly:

```tsx title="src/app/components/chat.tsx"
import { useAgent } from "@copilotkit/react-core";

export const Chat = () => {
  const { agent } = useAgent();

  return (
    <div>
      {agent.messages.map((message) => (
        <div key={message.id}>
          {message.role === "assistant" &&
            message.toolCalls?.map((toolCall) => (
              <p key={toolCall.id}>
                {toolCall.function.name}: {toolCall.function.arguments}
              </p>
            ))}
        </div>
      ))}
    </div>
  );
};
```

## Working with suggestions

CopilotKit's suggestions give users a list of generated or static prompts. In a headless UI, `useConfigureSuggestions` sets them up and `useSuggestions` reads them.

<video
  src="https://cdn.copilotkit.ai/docs/copilotkit/videos/suggestions.mp4"
  className="rounded-xl shadow-lg border"
  loop
  playsInline
  autoPlay
  muted
/>

### Generating suggestions

Give `useConfigureSuggestions` instructions to generate suggestions, and display them with `useSuggestions`:

```tsx title="src/app/components/chat.tsx"
import {
  useAgent,
  useConfigureSuggestions,
  useCopilotKit,
  useSuggestions,
} from "@copilotkit/react-core";
import { randomUUID } from "@copilotkit/shared";

export const Chat = () => {
  const { agent } = useAgent();
  const { copilotkit } = useCopilotKit();

  useConfigureSuggestions({
    instructions:
      "Suggest 5 interesting activities for programmers to do on their next vacation",
    maxSuggestions: 5,
    available: "always",
  });

  const { suggestions, reloadSuggestions } = useSuggestions();

  const send = async (message: string) => {
    agent.addMessage({ id: randomUUID(), role: "user", content: message });
    await copilotkit.runAgent({ agent });
  };

  return (
    <div>
      {suggestions.map((suggestion) => (
        <button
          key={suggestion.title}
          disabled={suggestion.isLoading}
          onClick={() => send(suggestion.message)}
        >
          {suggestion.title}
        </button>
      ))}
      <button onClick={reloadSuggestions}>Refresh suggestions</button>
    </div>
  );
};
```

### Static suggestions

If you want deterministic control, pass the suggestions yourself:

```tsx
import { useConfigureSuggestions } from "@copilotkit/react-core";

export function StaticSuggestions() {
  useConfigureSuggestions({
    suggestions: [
      { title: "Suggestion 1", message: "The actual message for suggestion 1" },
      { title: "Suggestion 2", message: "The actual message for suggestion 2" },
    ],
  });

  return null;
}
```

## Working with human-in-the-loop

Human-in-the-loop (HITL) pauses the chat and waits for the user's input. It comes in two flavors: **tool-based** and **interrupt-based** (certain frameworks only).

<video
  src="https://cdn.copilotkit.ai/docs/copilotkit/videos/hitl.mp4"
  className="rounded-xl shadow-lg border"
  loop
  playsInline
  autoPlay
  muted
/>

### Tool-based

Tool-based HITL pauses tool execution until the user responds. The response becomes the tool's result. Register the tool with `useHumanInTheLoop`, and render it in your message list with `useRenderToolCall` as in [With `useFrontendTool`](#with-usefrontendtool):

```tsx title="src/app/components/name-tool.tsx"
import { useState } from "react";
import { useHumanInTheLoop } from "@copilotkit/react-core";
import { z } from "zod";

function NameForm({
  defaultName,
  onSubmit,
}: {
  defaultName?: string;
  onSubmit: (name: string) => void;
}) {
  const [name, setName] = useState(defaultName ?? "");

  return (
    <div>
      <input
        value={name}
        onChange={(e) => setName(e.target.value)}
        placeholder="Enter your name"
      />
      <button onClick={() => onSubmit(name)}>Submit</button>
    </div>
  );
}

export function NameTool() {
  useHumanInTheLoop({
    name: "getName",
    description: "Ask the user for their name.",
    parameters: z.object({ name: z.string().optional() }),
    render: ({ respond, args, result }) => {
      if (result !== undefined) return <div>Name retrieved…</div>;
      // `respond` is set only while the tool waits for the user. It resolves
      // the pending tool call, so call it only on submit: editing the field
      // must not complete the turn on the first keystroke.
      if (!respond) return <div>Loading…</div>;
      return <NameForm defaultName={args.name} onSubmit={respond} />;
    },
  });

  return null;
}
```
