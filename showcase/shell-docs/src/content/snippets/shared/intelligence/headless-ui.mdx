## Overview

For current apps, start with [Fully Headless UI](/built-in-agent/custom-look-and-feel/headless-ui),
which uses v2 primitives to build a custom interface. This page documents the
legacy `useCopilotChatHeadless_c` hook for applications that already use a
licensed legacy provider.

CopilotKit offers **fully headless UI** through the `useCopilotChatHeadless_c` hook. By using this hook, you can build your own chat interfaces from the ground up while still utilizing CopilotKit's core features and ease-of-use.

<Callout type="warn">
  **This guide applies to self-hosted and OSS projects only.**
  `useCopilotChatHeadless_c` checks for a `publicLicenseKey` on the provider and
  returns a non-functional fallback without one. Managed Intelligence projects
  are issued a project-scoped `CPK_INTELLIGENCE_API_KEY` and no license key, so
  this hook is not available to them. If the CopilotKit CLI created your
  project, build your headless UI on the ungated v2 primitives described in
  [Fully Headless UI](/built-in-agent/custom-look-and-feel/headless-ui) instead.
</Callout>

These steps need a `publicLicenseKey`. `npx copilotkit@latest create` creates a
**managed** project, which receives `CPK_INTELLIGENCE_API_KEY` and no license
key, so do not follow this section for a CLI-scaffolded project. Use
[Fully Headless UI](/built-in-agent/custom-look-and-feel/headless-ui) instead.

<Steps>
<Step>
### Start from your existing legacy application

Use an application with a working CopilotKit runtime, the legacy `CopilotKit`
provider, and a valid public license key. The project API key used by a managed
Intelligence runtime is a different credential and does not unlock this hook.

If you are starting a new app, follow the current
[Fully Headless UI](/built-in-agent/custom-look-and-feel/headless-ui) guide instead.
</Step>

<Step>
### Wire your CopilotKit provider with a license key

Add the public license key to your existing `CopilotKit` provider, keeping its runtime endpoint:

```tsx title="src/app/layout.tsx"
<CopilotKit runtimeUrl="/api/copilotkit" publicLicenseKey="your-free-public-license-key">
  {children}
</CopilotKit>
```
</Step>

<Step>
### Build a headless chat component

Use `useCopilotChatHeadless_c` to access messages, a send function, and loading state, then wire them to your own UI:

```tsx title="src/app/page.tsx"
"use client";
import { useState } from "react";
import { useCopilotChatHeadless_c } from "@copilotkit/react-core";

export default function Home() {
  const { messages, sendMessage, isLoading } = useCopilotChatHeadless_c();
  const [input, setInput] = useState("");

  const handleSend = () => {
    if (input.trim()) {
      sendMessage({
        id: Date.now().toString(),
        role: "user",
        content: input,
      });
      setInput("");
    }
  };

  return (
    <div>
      <h1>My Headless Chat</h1>

      <div>
        {messages.map((message) => (
          <div key={message.id}>
            <strong>{message.role === "user" ? "You" : "Assistant"}:</strong>
            <p>{message.content}</p>
          </div>
        ))}
        {isLoading && <p>Assistant is typing...</p>}
      </div>

      <div>
        <input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          onKeyDown={(e) => e.key === "Enter" && handleSend()}
          placeholder="Type your message here..."
        />
        <button onClick={handleSend} disabled={isLoading}>
          Send
        </button>
      </div>
    </div>
  );
}
```
</Step>
</Steps>

## Working with generative UI

You can render generative UI either via `useFrontendTool` / `useComponent`, or by reading tools and rendering them directly.

<video
  src="https://cdn.copilotkit.ai/docs/copilotkit/videos/gen-ui.mp4"
  className="rounded-xl shadow-lg border"
  loop
  playsInline
  autoPlay
  muted
/>

### With `useFrontendTool`

Register a frontend tool and attach a render function. CopilotKit inserts your component wherever that tool call appears in the message stream:

```tsx title="src/app/components/chat.tsx"
"use client";

import { useCopilotChatHeadless_c } from "@copilotkit/react-core";
import { useFrontendTool } from "@copilotkit/react-core/v2";

export const Chat = () => {
  const { messages } = useCopilotChatHeadless_c();

  useFrontendTool({
    name: "showCustomComponent",
    handler: async () => "Foo, Bar, Baz",
    render: ({ result, args, status }) => (
      <div
        style={{
          backgroundColor: "red",
          padding: "10px",
          borderRadius: "5px",
        }}
      >
        <p>Custom component</p>
        <p>Result: {result}</p>
        <p>Args: {JSON.stringify(args)}</p>
        <p>Status: {status}</p>
      </div>
    ),
  });

  return (
    <div>
      {messages.map((message) => (
        <div key={message.id}>
          {message.role === "user" ? "User: " : "Assistant: "}
          {message.content}
          {message.role === "assistant" && message.generativeUI?.()}
        </div>
      ))}
    </div>
  );
};
```

### With raw tool-call data

If you don't want to use `useFrontendTool`, render the raw data directly:

```tsx title="src/app/components/chat.tsx"
"use client";

import { useCopilotChatHeadless_c } from "@copilotkit/react-core";

export const Chat = () => {
  const { messages } = useCopilotChatHeadless_c();

  return (
    <div>
      {messages.map((message) => (
        <div key={message.id}>
          {message.role === "assistant" &&
            message.toolCalls?.map((toolCall) => (
              <p key={toolCall.id}>
                {toolCall.function.name}: {toolCall.function.arguments}
              </p>
            ))}
        </div>
      ))}
    </div>
  );
};
```

## Working with suggestions

CopilotKit's suggestions give users a list of generated or static prompts. The headless hook exposes full control over the lifecycle.

<video
  src="https://cdn.copilotkit.ai/docs/copilotkit/videos/suggestions.mp4"
  className="rounded-xl shadow-lg border"
  loop
  playsInline
  autoPlay
  muted
/>

### Generating suggestions

Use `useCopilotChatSuggestions` to generate and display prompt suggestions in your headless UI:

```tsx title="src/app/components/chat.tsx"
"use client";

import {
  useCopilotChatHeadless_c,
  useCopilotChatSuggestions,
} from "@copilotkit/react-core";
import { useEffect } from "react";

export const Chat = () => {
  useCopilotChatSuggestions({
    instructions:
      "Suggest 5 interesting activities for programmers to do on their next vacation",
    maxSuggestions: 5,
  });

  const { suggestions, generateSuggestions, sendMessage } =
    useCopilotChatHeadless_c();

  useEffect(() => {
    generateSuggestions();
  }, []);

  return (
    <div>
      {suggestions.map((s, i) => (
        <button
          key={i}
          onClick={() =>
            sendMessage({
              id: Date.now().toString(),
              role: "user",
              content: s.message,
            })
          }
        >
          {s.title}
        </button>
      ))}
    </div>
  );
};
```

### Programmatic suggestions

If you want deterministic control, set suggestions manually:

```tsx
const { suggestions, setSuggestions } = useCopilotChatHeadless_c();

useEffect(() => {
  setSuggestions([
    { title: "Suggestion 1", message: "The actual message for suggestion 1" },
    { title: "Suggestion 2", message: "The actual message for suggestion 2" },
  ]);
}, []);
```

## Working with human-in-the-loop

Human-in-the-loop (HITL) pauses the chat and waits for the user's input. It comes in two flavors: **tool-based** and **interrupt-based** (certain frameworks only).

<video
  src="https://cdn.copilotkit.ai/docs/copilotkit/videos/hitl.mp4"
  className="rounded-xl shadow-lg border"
  loop
  playsInline
  autoPlay
  muted
/>

### Tool-based

Tool-based HITL pauses tool execution until the user responds. The response becomes the tool's result.

```tsx title="src/app/components/chat.tsx"
"use client";

import { useState } from "react";
import { useCopilotChatHeadless_c } from "@copilotkit/react-core";
import { useHumanInTheLoop } from "@copilotkit/react-core/v2";
import { z } from "zod";

const NameForm = ({ defaultName, onSubmit }: {
  defaultName?: string;
  onSubmit: (name: string) => Promise<void>;
}) => {
  const [name, setName] = useState(defaultName || "");

  return (
    <div>
      <input
        value={name}
        onChange={(e) => setName(e.target.value)}
        placeholder="Enter your name"
      />
      <button onClick={() => void onSubmit(name)}>Submit</button>
    </div>
  );
};

export const Chat = () => {
  const { messages } = useCopilotChatHeadless_c();

  useHumanInTheLoop({
    name: "getName",
    parameters: z.object({ name: z.string().optional() }),
    render: ({ respond, args, status }) => {
      if (status === "complete") return <div>Name retrieved…</div>;
      if (status !== "executing") return <div>Preparing the form…</div>;

      // `respond` resolves the pending tool call, so call it only on submit.
      // Editing the field must not complete the turn on the first keystroke.
      return <NameForm defaultName={args.name} onSubmit={respond} />;
    },
  });

  return (
    <>
      {messages.map((message) => (
        <div key={message.id}>
          {message.role === "user" ? "User: " : "Assistant: "}
          {message.content}
          {message.role === "assistant" && message.generativeUI?.()}
        </div>
      ))}
    </>
  );
};
```
