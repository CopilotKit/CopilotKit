
# A2UI - Google's Generative UI Spec

Your agent can return [A2UI](https://a2ui.org/), Google's spec for declarative UI. Turn it on in your runtime, and the chat renders it. To compare A2UI with the other specs, see the [Generative UI specs overview](/concepts/generative-ui-overview).

## Setup with CopilotKit

### Backend

Enable A2UI in `CopilotRuntime` by passing `a2ui: {}`:

```ts title="app/api/copilotkit/route.ts"
import {
  CopilotRuntime,
  createCopilotRuntimeHandler,
} from "@copilotkit/runtime/v2";

const runtime = new CopilotRuntime({
  agents: { default: myAgent },
  a2ui: {},
});

// Single-route: only POST needed, no catch-all [...path] required
const handler = createCopilotRuntimeHandler({
  runtime,
  basePath: "/api/copilotkit",
  mode: "single-route",
});

export { handler as POST };
```

This automatically applies `A2UIMiddleware` to all registered agents. The middleware turns A2UI output into [AG-UI](/agentic-protocols/ag-ui) events that your app renders. To scope it to specific agents, you can specify agents with the `agents` property: `a2ui: { agents: ["my-agent"] }`.

The `CopilotRuntime` from `@copilotkit/runtime`, used with `copilotRuntimeNextJSAppRouterEndpoint`, also accepts `a2ui`. To host the runtime elsewhere, see [Deploy to any runtime](/runtime-server-adapter).

Once configured, any A2UI output returned from your agent will automatically be rendered in the chat interface. No additional frontend code is required.

### Frontend

The A2UI renderer activates automatically. The frontend needs no extra configuration. Optionally, pass a custom theme:

```tsx
import { CopilotKit, type A2UITheme } from "@copilotkit/react-core/v2";

// Your own theme object — the renderer reads the keys it understands.
// Leave the `a2ui` prop off entirely to keep the built-in theme.
const myCustomTheme: A2UITheme = {
  // ...your theme keys
};

<CopilotKit runtimeUrl="/api/copilotkit" a2ui={{ theme: myCustomTheme }}>
  {children}
</CopilotKit>;
```

The `a2ui` prop on `<CopilotKit>` is only needed if you want to override the default theme provided.
