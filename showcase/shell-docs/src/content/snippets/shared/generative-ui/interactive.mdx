## What is this?

Some agent actions need a person to say yes first, such as running a command. `useHumanInTheLoop` shows your approval UI in the chat and sends the user's answer back to the agent.

## Create a frontend human-in-the-loop tool

This example asks the user to approve a command before the agent runs it. Use the `useHumanInTheLoop` hook to create a tool that prompts the user for approval.

```tsx title="page.tsx"
import { useHumanInTheLoop } from "@copilotkit/react-core/v2"; // [!code highlight]
import { z } from "zod";

export function Page() {
  // ...

  // [!code highlight:16]
  useHumanInTheLoop({
    name: "humanApprovedCommand",
    description: "Ask human for approval to run a command.",
    parameters: z.object({
      command: z.string().describe("The command to run"),
    }),
    render: ({ args, respond, status }) => {
      if (status !== "executing") return <></>;
      return (
        <div>
          <pre>{args.command}</pre>
          {/* [!code highlight:2] */}
          <button onClick={() => respond?.(`Tell the user the command ran`)}>
            Approve
          </button>
          <button
            onClick={() => respond?.(`Tell the user the command wasn't run`)}
          >
            Deny
          </button>
        </div>
      );
    },
  });

  // ...
}
```

Ask the agent to run `ls`. An **Approve** and a **Deny** button appear in the chat. Click **Approve**, and the agent says that the command ran.
