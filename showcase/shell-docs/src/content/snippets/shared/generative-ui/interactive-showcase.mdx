## Let users answer before the agent continues

Use Human-in-the-loop when the agent needs a choice, confirmation, or a
piece of information from the person using the app. The Showcase example
asks the user to choose a time, renders the choice in chat, and continues
the same conversation with their answer.

Register the picker with
[`useHumanInTheLoop`](/reference/hooks/useHumanInTheLoop). The callback
returns the selected value to the agent as the tool result.
