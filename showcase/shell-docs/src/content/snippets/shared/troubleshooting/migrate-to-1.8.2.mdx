
## What's changed?

### New Look and Feel

CopilotKit 1.8.2 introduces a new default look and feel. This includes new use of theming variables, new components, and generally a fresh look.

**Open the preview below to see the new look and feel in action.**

### Thumbs Up/Down Handlers

The chat components now have `onThumbsUp` and `onThumbsDown` handlers. When you set them, each message shows feedback icons
on hover.

```tsx
<CopilotChat
  onThumbsUp={(message) => console.log(message)}
  onThumbsDown={(message) => console.log(message)}
/>
```

Use these handlers to record user feedback.

### ResponseButton prop removed

The `ResponseButton` prop has been removed. This was a prop that was used to customize the button that appears after a response was generated
in the chat.

In its place, we now place buttons below each message for:

- Thumbs up
- Thumbs down
- Copy
- Regenerate

Use `onRegenerate`, `onCopy`, `onThumbsUp`, and `onThumbsDown` on the chat component for the button actions. Change the icons with `icons.regenerateIcon`, `icons.copyIcon`, `icons.thumbsUpIcon`, and `icons.thumbsDownIcon`.

You can customize the behavior, icons, and styling of each button. See the [look and feel guides](/custom-look-and-feel/slots) for more details.

### Out-of-the-box dark mode support

CopilotKit now supports dark mode by default. The `.dark` class (Tailwind) and the
`color-scheme` CSS selector control it.

To make a custom theme, see the [custom look and feel](/custom-look-and-feel/slots) guides.
