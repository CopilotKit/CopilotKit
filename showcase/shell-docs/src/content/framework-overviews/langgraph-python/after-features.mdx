## Already have LangGraph conversations?

When you add a user-facing app to an existing LangGraph agent, your users may need to open and continue conversations they already started. [CopilotKit Intelligence](/intelligence/overview) can import supported LangGraph history as threads so your app does not start with an empty thread list.

The importer reads LangGraph Server, LangGraph Platform, or LangSmith Deployment thread and run APIs. For a FastAPI app with a durable checkpointer, export the threads first, then import the file. It does not import standalone LangChain message stores or LangSmith traces.

Import the history once. After that, runs that go through CopilotKit sync to Intelligence. LangGraph also keeps saving them, if your durable checkpointer or Platform deployment stays configured. This is not a continuous mirror of runs made outside CopilotKit.

[Import and synchronize LangGraph threads](/langgraph-python/threads-import) for source setup, agent mapping, and thread continuity.
