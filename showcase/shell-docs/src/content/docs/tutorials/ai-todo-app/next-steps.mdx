## What's next?

For next steps, here are some ideas:

- Add suggestions to your copilot, using the [`useConfigureSuggestions`](/reference/hooks/useConfigureSuggestions) hook.
- Customize the labels and the look of your chat window (for more info, check the documentation for [`<CopilotPopup />`](/reference/components/CopilotPopup)).
- Dive deeper into the [`useAgent`](/reference/hooks/useAgent) hook, which gives you the agent's messages and state, and lets you add messages and run the agent.

We have more tutorials coming soon.
