The Built-in Agent is the simplest agent backend CopilotKit ships. Instead of proxying to an external framework process (LangGraph, Mastra, etc.), it instantiates `BuiltInAgent({ model, tools, prompt })` inside your runtime and runs the agent loop in-process. You do not run a separate agent server or install an agent framework. The agent connects directly to OpenAI, Anthropic, Google, or any AI SDK model, and it supports tools, generative UI, and shared state.
