You want to see what happened in one conversation. Open the thread in your [cloud-hosted project](/intelligence/managed-intelligence-platform).

![A cloud-hosted thread with its event timeline.](/images/cloud-hosted/cloud-hosted-thread-detail.png)

The thread page shows the agent, the app user, the status, the last update time, and the event timeline. Open an event when you need the raw payload.

The actions on that page match the thread API in your app:

- **Rename** changes the display name.
- **Archive** hides the thread from the active list and keeps the history.
- **Delete** removes the thread.

Read [Threads](/threads) for how a thread works in your app. This page is only the cloud-hosted view of a thread that is already stored.
