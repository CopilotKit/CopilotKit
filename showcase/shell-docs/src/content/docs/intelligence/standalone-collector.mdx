## Overview

`@copilotkit/learning` captures clicks, form edits, page changes, and network requests as AG-UI `CUSTOM` events. This collector is part of the Trajectories early access feature.

The standalone collector sends batches to a sink you provide. It does not authenticate with CopilotKit Intelligence or automatically save events there. To capture directly into Intelligence, use the [React provider](/intelligence/capture-interactions) or [Docker guide](/intelligence/trajectories-docker).

Capture retains browser-visible text, values, headers, bounded body snapshots, and URLs by default. Recognized credential fields are redacted. See [Captured data](/intelligence/captured-data) for redaction limits and controls.

When you are done, your app sends batches of events to your own endpoint. You can also add events for the outcomes that matter to you.

## Capture events

<Steps>
  <Step>
    ### Install the package

    ```bash
    npm install @copilotkit/learning
    ```

  </Step>
  <Step>
    ### Prepare your receiving endpoint

    Create an endpoint that accepts JSON batches with `trajectoryId`, `events`, and `dropped`. The optional `learningContainerIds` field contains application-supplied IDs. Your endpoint owns authentication and storage.

    The example uses `/api/learning-events`. Replace this path with your endpoint.

  </Step>
  <Step>
    ### Create a collector and start it

    ```ts title="src/capture.ts"
    import { createCollector, httpSink } from "@copilotkit/learning";

    export const collector = createCollector({
      sink: httpSink("/api/learning-events"),
    });

    collector.start({ trajectoryId: crypto.randomUUID() });
    ```

    Before `start()`, the collector installs nothing. Connect `start()` and `stop()` to your application's capture control.

  </Step>
  <Step>
    ### Add events for outcomes

    Clicks show what a person did. They do not show whether it worked. After an operation succeeds, emit its outcome:

    ```ts
    collector.emit("report.exported", { format: "csv", rows: 120 });
    ```

    Use your own names. Built-in names such as `click` are reserved. Your application controls the payload. Automatic credential redaction does not inspect developer events.

  </Step>
  <Step>
    ### Stop when the session ends

    ```ts
    collector.stop();
    ```

    `stop()` removes every listener and patch, then sends queued events once. It does not wait for delivery or retry a failed send.

  </Step>
</Steps>

Your endpoint receives batches such as `{ "trajectoryId": "...", "events": [...], "dropped": 0 }`. Click a control and check your endpoint for the event after two seconds. The collector does not create an Intelligence Trajectory through this endpoint.

## Send events somewhere else

A sink is a function that receives each batch. Use it to forward events to your own service:

```ts
import { createCollector } from "@copilotkit/learning";
import type { LearningBatch } from "@copilotkit/learning";

const collector = createCollector({
  sink: async (batch: LearningBatch) => {
    const response = await fetch("https://events.example.com/ingest", {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify(batch),
    });
    if (!response.ok) throw new Error(`Capture endpoint returned ${response.status}`);
  },
  ignoreUrls: ["https://events.example.com/"],
});
```

Add your sink's URL to `ignoreUrls`, so the collector does not record its own requests. `httpSink` does this for you.

## Add context to clicks

`enrich` adds fields to each click from the element that was clicked:

```ts
const collector = createCollector({
  sink: httpSink("/api/learning-events"),
  enrich: (element) => ({
    section: element.closest("[data-section]")?.getAttribute("data-section") ?? null,
  }),
});
```

Capture already includes element text, attributes, and live control values. Use `enrich` for additional app context. Use `beforeSend`, capture flags, or `data-copilotkit-ignore` to exclude data.

For every field and control, see [Captured data](/intelligence/captured-data). With CopilotKit, use the [`learning` prop](/intelligence/capture-interactions) instead.
