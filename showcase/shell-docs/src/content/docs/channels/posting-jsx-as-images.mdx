---
title: Posting JSX as images
description: Post static JSX snapshots to managed Slack and Teams while keeping native channel messages interactive.
icon: "lucide/Component"
---

Managed Slack and Teams can post static JSX cards as PNGs with `thread.post(<MrrCard />)`. The SDK uses Takumi to render fonts and compiled CSS without a browser, then uploads through the existing managed file path. Existing native channel components continue to render as Block Kit or Adaptive Cards.

<Callout type="warn" title="Install react first">
  The image path renders through React, which is an **optional peer dependency** of `@copilotkit/channels` (your app owns its React version). It is not pulled in automatically. Takumi, the rasterizer, ships with the package, so you do not install it. Add React first:

  ```bash
  pnpm add react
  ```

  Without it, posting arbitrary JSX fails with a module-not-found error.
</Callout>

<Steps>
  <Step>
    ### How it's routed

    `thread.post` expands component functions once per operation and classifies their output:

    - Channel components such as `<Message>`, `<Header>`, and `<Button>` stay native, including when wrapped in your own component or a React fragment.
    - Host markup such as `<div>`, `<span>`, and `<svg>` becomes a PNG through [Takumi](https://github.com/takumi-rs/takumi).
    - To combine a snapshot with native text or buttons, put the snapshot inside `<Render>`.

    ```tsx
    await thread.post(
      <Message>
        <Header>Deploy complete</Header>
        <Section>Shipped v2.4.0 to production.</Section>
      </Message>,
    );

    await thread.post(<MrrCard value="$48,200" delta={12} />);
    ```

    Use pure presentational components. Top-level component functions are expanded outside React's hook dispatcher, so hooks, browser APIs, and effects are unsupported. A reused native element renders again on each post or update; its output is not cached.

    <Callout type="info" title="Image is URL-only">
      `<Image url>` is a public URL image. It does not take children. To put a React snapshot inside native text, buttons, or a carousel, wrap it in `<Render>`. See [Render and carousel](/channels/render-and-carousel).
    </Callout>
  </Step>
  <Step>
    ### Configure fonts and styling once

    Takumi is a static, browser-free rasterizer with no system fonts, only a built-in Latin (Geist) fallback. Register your fonts and compiled CSS once on `createChannel({ render })`, and every image post picks them up:

    ```ts title="bot.ts"
    import { createChannel } from "@copilotkit/channels";
    import { readFileSync } from "node:fs";

    const bot = createChannel({
      name: "support", // managed channel configured in Intelligence
      agent: (threadId) => /* ... */,
      render: {
        fonts: [
          { name: "Inter", data: readFileSync("./fonts/Inter-Regular.woff2"), weight: 400 },
          { name: "Inter", data: readFileSync("./fonts/Inter-SemiBold.woff2"), weight: 600 },
        ],
        stylesheets: [readFileSync("./styles/global.css", "utf8")], // compiled Tailwind
        width: 720, // default canvas width; height defaults to 480
      },
    });
    ```

    `stylesheets` takes your compiled CSS as plain strings; class selectors, `var()`, and `@media` resolve. This example loads it with `node:fs` so it runs as-is under Node or tsx. If your build already emits the CSS as an importable string (Vite's `?inline` suffix, say), that is a bundler-only variant and will not run under plain `tsx`/`node`:

    ```ts title="bot.ts (bundler-only variant, e.g. Vite)"
    import appCss from "./styles/global.css?inline"; // compiled Tailwind, resolved by the bundler

    // ...same createChannel call as above, with stylesheets: [appCss]
    ```

    <Callout type="warn" title="No fonts configured means Latin-only">
      Takumi cannot detect missing glyphs before render, so the SDK warns once when no `fonts` are configured, and non-Latin text drops from the image. Any other Takumi render error is surfaced, not swallowed, so a broken font or stylesheet fails loudly.
    </Callout>
  </Step>
  <Step>
    ### Control what the renderer may fetch

    The rasterizer fetches remote resources your JSX references, `<img src>`, CSS `url()`, emoji sheets. Channel JSX is often built from model or user data, so an ungated fetcher running inside your infrastructure is an SSRF sink: an `<img src="http://169.254.169.254/latest/meta-data/">` would have the renderer read your cloud instance metadata.

    By default, `render` denies non-HTTP(S) schemes and hosts that are literally private, loopback, link-local, or an internal zone (cloud metadata endpoints included), and allows the rest. Override it with `allowImageUrl`:

    ```ts title="bot.ts"
    const bot = createChannel({
      // ...
      render: {
        // Only this CDN, nothing else.
        allowImageUrl: (url) => new URL(url).origin === "https://cdn.example.com",
        // Or block every remote fetch:
        // allowImageUrl: () => false,
      },
    });
    ```

    <Callout type="warn" title="The default check cannot resolve DNS">
      The hook Takumi exposes is synchronous, so the default policy matches on the URL's literal host. A public hostname that resolves to a private address (DNS rebinding) is **not** caught. If your JSX can carry untrusted URLs, pass an explicit `allowImageUrl` allowlist rather than relying on the default. `allowImageUrl` is channel-wide only, deliberately, a per-post override is exactly the knob a prompt-injected tool argument would reach for.
    </Callout>
  </Step>
  <Step>
    ### Override per post

    Canvas dimensions, fonts, and stylesheets can be overridden for a single post, handy for a wider dashboard, a taller card, or an extra font just for that message:

    ```tsx
    await thread.post(<WideDashboard data={rows} />, { width: 1200 });
    await thread.post(<CjkReport data={rows} />, { fonts: [notoSansJP] });
    await thread.post(<MrrCard value="$48,200" delta={12} />, {
      filename: "mrr.png",
      title: "MRR",
      altText: "Monthly recurring revenue card",
    });
    ```

    `filename`, `title`, and `altText` are upload metadata passed straight through to `postFile`. They do not affect rendering.
  </Step>
  <Step>
    ### Author cards with plain JSX

    Write host tags (`<div>`, `<span>`, `<svg>`) and app or chart components (`<Sparkline/>`, `<BarChart/>`, your own components) as plain JSX. No `createElement` needed. The channels JSX runtime compiles the whole tree to nodes, and the image renderer materializes it back to React for Takumi.

    A component nested inside a host card is resolved for you, so you can compose freely:

    ```tsx
    function Kpi({ label, value }: { label: string; value: string }) {
      return (
        <div className="flex flex-col gap-1.5 p-4 bg-card border rounded-xl">
          <span className="text-sm text-muted-foreground">{label}</span>
          <span className="text-3xl font-bold">{value}</span>
        </div>
      );
    }

    await thread.post(
      <div className="flex gap-3 p-6 bg-background">
        <Kpi label="Stars" value="22.4k" />
        <Kpi label="Downloads" value="118k" />
      </div>,
    );
    ```

  </Step>
  <Step>
    ### Know the limits

    Takumi is a static SSR rasterizer. It calls your components with server-render semantics, not a real browser. Keep this in mind:

    - **No runtime-JS chart or diagram libraries.** Recharts, Chart.js, and Mermaid measure or paint the live DOM (`useEffect`, canvas, layout measurement), and none of that runs under Takumi. Use your own pure presentational markup instead.
    - **`update()` and `postEphemeral()` do not accept arbitrary JSX.** An uploaded image cannot be edited in place, so both reject host image markup; React wrappers that return native channel components remain supported. Post a new image instead.
    - **Managed image uploads do not return an addressable message reference.** A successful image post currently returns `{ id: "" }` and warns once. Do not pass this reference to `update()`, `delete()`, or `react()`. Native messages, including messages containing `<Render>`, keep their normal references.
    - **The canvas has a fixed size.** It defaults to 720 by 480. Pass `width`/`height` globally via `render`, or per post, for anything else.
  </Step>
</Steps>

The new image feature targets managed Slack and Teams. Direct adapters and the other integrations are unchanged.

## See it end to end

The [`examples/slack`](https://github.com/CopilotKit/CopilotKit/tree/main/examples/slack) app (`app/showcase/`) uses this for three "run it in your own Slack" features. Each one is a CopilotKit-branded card, and each is triggerable both by a slash command and by prompt (the agent calls the matching `render_*` tool; both share one `render*` fn):

- **PR review radar** (`/prs`): a card of the oldest open PRs with age-colored badges, from GitHub's public API (no token).
- **Weekly OSS pulse** (`/pulse`): a KPI card (stars, npm downloads, open issues) from GitHub and npm.
- **Linear cycle standup** (`/standup`): a per-team progress card (one labelled bar per team) from Linear.

The brand look is a compiled Tailwind stylesheet (`pnpm build:css`) plus Plus Jakarta Sans, fed once via `render.stylesheets` and `render.fonts`. Cards are authored with Tailwind classes and Takumi resolves them. Each feature reads live data and falls back to labelled sample data so it always runs. It is a concrete template for wiring your own dashboards.
