description: Mix native channel UI with React snapshots in one message using Render and Carousel.

You want native text plus React cards in one message. A header, a sale note, and a Buy button sit next to a product card that your app already draws in React.

Wrap each snapshot in `<Render alt>`. Group the slides in `<Carousel>`. The SDK draws each snapshot to a PNG and keeps the rest as native channel UI.

```tsx
<Message>
  <Header>This week</Header>
  <Carousel>
    <CarouselCard>
      <Header>Shoes</Header>
      <Render alt="Red shoes" width={400}>
        <ProductCard product={shoes} />
      </Render>
      <Section>On sale</Section>
      <Button value="buy-shoes">Buy</Button>
    </CarouselCard>
    <Render alt="Hat">
      <ProductCard product={hat} />
    </Render>
  </Carousel>
</Message>
```

`alt` is required on `<Render>`. Slack and other platforms need that text.

`<Image url>` is still a public URL image. It does not take children.

<Callout type="warn" title="No Channels Button inside Render">
  A Channels `<Button>` inside `<Render>` throws. A host HTML button is fine. The snapshot is a PNG, so that HTML button does not receive clicks.
</Callout>

Set fonts and styles once on `createChannel({ render })`. See [Posting JSX as images](/channels/posting-jsx-as-images).

The Slack example posts this mix with `/carousel` or by asking the bot to show a carousel (`render_carousel` in `examples/slack`).

## Where it lands

| Platform | What you get |
| --- | --- |
| Slack | Native carousel |
| Teams | Adaptive Card carousel |
| Discord | Media Gallery |
| Telegram | Album, or a photo plus a keyboard |
| WhatsApp | Native carousel, or stacked images |
