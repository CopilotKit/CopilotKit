## What is this?

Human-in-the-loop (HITL) lets an agent ask for input, confirmation, or a
choice before it continues. The agent requests a choice, the UI renders it, and
the answer returns as the tool result.

## When should I use this?

Use HITL when you need:

- **Quality control** — a human gate at high-stakes decision points
- **Edge cases** — graceful fallbacks when the agent's confidence is low
- **Expert input** — lean on the user for domain knowledge the model lacks
- **Reliability** — a more robust loop for real-world, production traffic

## Tool-based approval — `useHumanInTheLoop`

The agent registers a HITL tool on the client with
[`useHumanInTheLoop`](/reference/hooks/useHumanInTheLoop).
When the LLM calls that tool, CopilotKit routes the call through your
`render` function, which shows a custom component and calls `respond`
with the user's answer. The agent sees the answer as the tool result and
continues from there.

## Native graph interrupts are a different capability

LangGraph can enforce a graph checkpoint with `interrupt(...)` and render that
AG-UI interrupt through `useInterrupt`. Google ADK has no equivalent native
interrupt primitive, so `useInterrupt` and the [headless interrupts
guide](/human-in-the-loop/headless) do not apply to the ADK route. Use the
tool-based approval above for the same in-chat decision experience.
