## What is this?

Every CopilotKit chat component is built from composable **slots**, named sub-components you can override individually. The slot system gives you three levels of customization without needing to rebuild the entire UI:

1. **Tailwind classes**: pass a string to add/override CSS classes
2. **Props override**: pass an object to override specific props on the default component
3. **Custom component**: pass your own React component to fully replace a slot

Slots are recursive: you can drill into nested sub-components at any depth.

## What it looks like in code

The demo above overrides many slots on `<CopilotChat>` and outlines each one.
The example below replaces three of them. Each slot is a prop:

- `welcomeScreen` replaces the empty-state view shown before the first message.
  This one shows a gradient card and still renders the default `input` and
  `suggestionView` it receives.
- `messageView={{ assistantMessage: ... }}` wraps every assistant response.
  This one adds a tinted card around the default component.
- `input={{ disclaimer: ... }}` replaces the small text below the input. It
  shows on the welcome screen and after the first message.

Put slot overrides in a Client Component (`"use client"`), because you pass
functions to the chat:

```tsx title="app/page.tsx"
"use client";

import {
  CopilotChat,
  CopilotChatAssistantMessage,
  CopilotChatView,
  type CopilotChatAssistantMessageProps,
} from "@copilotkit/react-core/v2";

type WelcomeScreenProps = React.ComponentProps<
  typeof CopilotChatView.WelcomeScreen
>;

function MyWelcome({ input, suggestionView }: WelcomeScreenProps) {
  return (
    <div className="flex flex-1 flex-col items-center justify-center gap-4 px-4">
      <div className="rounded-2xl bg-gradient-to-br from-indigo-500 to-pink-500 p-6 text-white">
        What do you want to build today?
      </div>
      <div className="w-full max-w-2xl">{input}</div>
      {suggestionView}
    </div>
  );
}

function MyAssistantMessage(props: CopilotChatAssistantMessageProps) {
  return (
    <div className="rounded-xl bg-indigo-50 p-2">
      <CopilotChatAssistantMessage {...props} />
    </div>
  );
}

function MyDisclaimer(props: React.HTMLAttributes<HTMLDivElement>) {
  return (
    <div {...props} className="py-1 text-center text-xs text-gray-500">
      Answers come from an AI agent. Check important facts.
    </div>
  );
}

export default function Page() {
  return (
    <CopilotChat
      welcomeScreen={MyWelcome}
      messageView={{
        assistantMessage:
          MyAssistantMessage as typeof CopilotChatAssistantMessage,
      }}
      input={{ disclaimer: MyDisclaimer }}
    />
  );
}
```

Reload the page. The gradient card shows, with the input and your disclaimer
below it. Send a message: the reply sits in a tinted card, and your disclaimer
stays below the input.

## Tailwind Classes

Pass a Tailwind class string. CopilotKit merges it with the classes of the default component.

```tsx title="page.tsx"
import { CopilotChat } from "@copilotkit/react-core/v2";

export function Chat() {
  return (
    <CopilotChat
      messageView="bg-gray-50 dark:bg-gray-900 p-4"
      input="border-2 border-blue-400 rounded-xl"
    />
  );
}
```

Reload the page. The message list has a gray background. The `input` string
goes on the outer input container, so the blue border frames the whole bottom
area, including the disclaimer. To style the text box itself, pass a class
string to its sub-slot: `input={{ textArea: "..." }}`.

## Props Override

Pass an object to override specific props on the default component. This is useful for adding `className`, event handlers, or any other prop the default component accepts.

```tsx title="page.tsx"
<CopilotChat
  messageView={{
    className: "my-custom-messages",
  }}
  input={{ autoFocus: true }}
/>
```

## Custom Components

For full control, pass your own React component. It receives all the same props as the default component. The slot type is the default component, so cast your component to that type.

```tsx title="page.tsx"
import {
  CopilotChat,
  CopilotChatMessageView,
  type CopilotChatMessageViewProps,
} from "@copilotkit/react-core/v2";

const CustomMessageView = ({ messages, isRunning }: CopilotChatMessageViewProps) => (
  <div className="space-y-4 p-6">
    {messages?.map((msg) => (
      <div key={msg.id} className={msg.role === "user" ? "text-right" : "text-left"}>
        {typeof msg.content === "string" ? msg.content : null}
      </div>
    ))}
    {isRunning && <div className="animate-pulse">Thinking...</div>}
  </div>
);

export function Chat() {
  return <CopilotChat messageView={CustomMessageView as typeof CopilotChatMessageView} />;
}
```

## Nested Slots (Drill-Down)

Slots are recursive. You can customize sub-components at any depth by nesting objects.

### Two levels deep

Override the assistant message's toolbar within the message view:

```tsx title="page.tsx"
import {
  CopilotChat,
  CopilotChatUserMessage,
  type CopilotChatUserMessageProps,
} from "@copilotkit/react-core/v2";

const CustomToolbar = (props: React.HTMLAttributes<HTMLDivElement>) => (
  <div {...props} className="mt-1 flex gap-2 border-t pt-1" />
);

const CustomCopyButton = ({
  onClick,
}: React.ButtonHTMLAttributes<HTMLButtonElement>) => (
  <button onClick={onClick}>Copy</button>
);

const CustomUserMessage = ((props: CopilotChatUserMessageProps) => (
  <div className="rounded-lg bg-blue-50">
    <CopilotChatUserMessage {...props} />
  </div>
)) as typeof CopilotChatUserMessage;

<CopilotChat
  messageView={{
    assistantMessage: {
      toolbar: CustomToolbar,
      copyButton: CustomCopyButton,
    },
    userMessage: CustomUserMessage,
  }}
/>
```

### One toolbar button

Override a specific button inside the assistant message toolbar:

```tsx title="page.tsx"
<CopilotChat
  messageView={{
    assistantMessage: {
      copyButton: ({ onClick }) => (
        <button onClick={onClick}>Copy</button>
      ),
    },
  }}
/>
```

### Tool calls

The `assistantMessage` slot holds `toolCallsView`, which renders the tool calls
of one assistant message. Wrap the default `CopilotChatToolCallsView` to change
the container while keeping your registered tool renderers:

```tsx title="page.tsx"
import {
  CopilotChat,
  CopilotChatToolCallsView,
  type CopilotChatToolCallsViewProps,
} from "@copilotkit/react-core/v2";

const CustomToolCallsView = (props: CopilotChatToolCallsViewProps) => (
  <div className="rounded-lg border border-dashed p-2">
    <CopilotChatToolCallsView {...props} />
  </div>
);

export function Chat() {
  return (
    <CopilotChat
      messageView={{
        assistantMessage: { toolCallsView: CustomToolCallsView },
      }}
    />
  );
}
```

To see `CopilotChatToolCallsView` in progress, complete, expanded, and failed
states, open the
[`CopilotChatToolCallsView` stories](https://github.com/CopilotKit/CopilotKit/blob/main/examples/v2/react/storybook/stories/CopilotChatToolCallsView.stories.tsx)
in the React Storybook.

To change how calls are grouped (a card, a line of text, a stack, or one
summary per turn) without writing a component, set `toolCallDisplay` on the
message view. See [Grouping tool calls](/generative-ui/tool-rendering#grouping-tool-calls).

The `assistantMessage` slot also holds `markdownRenderer`, which controls how
assistant markdown is rendered. It has its own guide:
[Markdown Rendering](/custom-look-and-feel/markdown).

## Labels

Customize any text string in the UI via the `labels` prop. This is a separate convenience prop on `CopilotChat`, `CopilotSidebar`, and `CopilotPopup`, not part of the slot system.

```tsx title="page.tsx"
<CopilotChat
  labels={{
    chatInputPlaceholder: "Ask your agent anything...",
    welcomeMessageText: "How can I help you today?",
    chatDisclaimerText: "AI responses may be inaccurate.",
  }}
/>
```

## Available Slots

### `CopilotChat` / `CopilotSidebar` / `CopilotPopup`

These are the root-level slot props available on all chat components:

| Slot | Description |
|------|-------------|
| `messageView` | The message list container. |
| `scrollView` | The scroll container with auto-scroll behavior. |
| `input` | The text input area with send/transcribe controls. |
| `suggestionView` | The suggestion pills shown below messages. |
| `welcomeScreen` | The initial empty-state screen (pass `false` to disable). |

`CopilotSidebar` and `CopilotPopup` also have:

| Slot | Description |
|------|-------------|
| `header` | The modal header bar. |
| `toggleButton` | The open/close toggle button. |
