## What is this?

Sub-agents are the canonical multi-agent pattern: a top-level
**supervisor** LLM orchestrates one or more specialized **sub-agents**
by exposing each of them as a tool. The supervisor decides what to
delegate, the sub-agents do their narrow job, and their results flow
back up to the supervisor's next step.

This is fundamentally the same shape as tool-calling, but each "tool"
is itself a full-blown agent with its own system prompt and (often) its
own tools, memory, and model.

## When should I use this?

Reach for sub-agents when a task has distinct specialized sub-tasks
that each benefit from their own focus:

- **Research → Write → Critique** pipelines, where each stage needs a
  different system prompt and temperature.
- **Router + specialists**, where one agent classifies the request and
  dispatches to the right expert.
- **Divide-and-conquer**, for any problem that fits cleanly into parallel
  or sequential sub-problems.

The example below uses the Research → Write → Critique shape as the
canonical example.

## Setting up sub-agents

Define one agent per role, each with its own system prompt:

<Snippet region="subagent-setup" title="Three sub-agents" />

Each sub-agent is an isolated agent call with its own model, system
prompt, and optional tools. They don't share memory or tools with the
supervisor; the supervisor only ever sees what the sub-agent returns.

Keep sub-agent system prompts narrow and focused. The point of this pattern
is that each one does one thing well. If a sub-agent needs to know
the whole user context to do its job, that's a signal the boundary is
wrong.

## Exposing sub-agents as tools

The supervisor delegates by calling tools. Each delegation tool is a thin
wrapper around a specialized agent call that:

1. Runs the sub-agent on the supplied `task` string.
2. Records the delegation into a `delegations` slot in [shared agent
   state](/shared-state) (so the UI can render a live log). In the Built-in Agent
   example, the tool code below does not write this entry. The agent
   loop writes it: after each delegation tool result, the loop emits a
   `STATE_DELTA` event that sets `/delegations`.
3. Returns the sub-agent's final message as the tool result, which the
   supervisor sees on its next turn.

The Built-in Agent excerpt stops at the tools. To run it in your own app, make these changes.

1. Install the packages:

   ```npm
   npm install @tanstack/ai @tanstack/ai-openai "zod@^4.2"
   ```

2. In `subagent-tools.ts`, import `openaiText` from `@tanstack/ai-openai` instead of the showcase helper `../openai-text`.

3. Give each sub-agent call the parent run's `threadId`. `chat()` from `@tanstack/ai` throws `chat() needs a threadId` without it, and the supervisor receives that error as the tool result. With `stream: false`, `chat()` returns `{ text, chunks }`, so read `text` from it:

   ```ts title="src/lib/factory/subagent-tools.ts"
   export function buildSubagentTools(
     parentAbortController: AbortController,
     ids: { threadId: string; runId: string }, // [!code highlight]
   ) {
     // ...
         const { text } = await chat({ // [!code highlight]
           adapter: openaiText("gpt-6-luna"),
           messages: [{ role: "user", content: task }],
           systemPrompts: [role.systemPrompt],
           abortController: parentAbortController,
           threadId: ids.threadId, // [!code highlight]
           runId: `${ids.runId}-${role.id}`, // [!code highlight]
           stream: false,
         });
     // ...
   }
   ```

4. Add the supervisor. It runs the tools, then writes each delegation into `delegations` with a `STATE_DELTA` event:

   ```ts title="src/lib/factory/supervisor.ts"
   import {
     BuiltInAgent,
     convertInputToTanStackAI,
     convertTanStackStream,
   } from "@copilotkit/runtime/v2";
   import { EventType, type BaseEvent } from "@ag-ui/client";
   import { chat } from "@tanstack/ai";
   import { openaiText } from "@tanstack/ai-openai";
   import { buildSubagentTools } from "./subagent-tools";

   const SUB_AGENTS = new Set(["research_agent", "writing_agent", "critique_agent"]);

   type Delegation = {
     id: string;
     sub_agent: string;
     task: string;
     status: "completed";
     result: string;
   };

   function parse(value: string | undefined): Record<string, unknown> {
     try {
       return JSON.parse(value ?? "{}");
     } catch {
       return {};
     }
   }

   export const supervisor = new BuiltInAgent({
     type: "custom",
     factory: async function* ({ input, abortController }): AsyncGenerator<BaseEvent> {
       const { messages, systemPrompts, tools } = convertInputToTanStackAI(input);
       const stream = chat({
         adapter: openaiText("gpt-6-luna"),
         messages,
         systemPrompts: [
           "You are a supervisor. Delegate research, writing, and critique to your sub-agents, then summarize the result.",
           ...systemPrompts,
         ],
         tools: [
           ...tools,
           ...buildSubagentTools(abortController, { threadId: input.threadId, runId: input.runId }),
         ],
         threadId: input.threadId,
         runId: input.runId,
         abortController,
       });

       // Keep the entries the client sent back, and merge new ones by id.
       const state = (input.state ?? {}) as { delegations?: Delegation[] };
       const delegations: Delegation[] = [...(state.delegations ?? [])];
       const calls = new Map<string, { name: string; args: string }>();

       for await (const event of convertTanStackStream(stream, abortController.signal)) {
         yield event;
         if (event.type === EventType.TOOL_CALL_START) {
           const e = event as BaseEvent & { toolCallId: string; toolCallName: string };
           calls.set(e.toolCallId, { name: e.toolCallName, args: "" });
         } else if (event.type === EventType.TOOL_CALL_ARGS) {
           const e = event as BaseEvent & { toolCallId: string; delta: string };
           const call = calls.get(e.toolCallId);
           if (call) call.args += e.delta;
         } else if (event.type === EventType.TOOL_CALL_RESULT) {
           const e = event as BaseEvent & { toolCallId: string; content: string };
           const call = calls.get(e.toolCallId);
           if (!call || !SUB_AGENTS.has(call.name)) continue;
           if (delegations.some((d) => d.id === e.toolCallId)) continue;
           delegations.push({
             id: e.toolCallId,
             sub_agent: call.name,
             task: String(parse(call.args).task ?? ""),
             status: "completed",
             result: String(parse(e.content).text ?? e.content),
           });
           yield {
             type: EventType.STATE_DELTA,
             delta: [{ op: "add", path: "/delegations", value: [...delegations] }],
           } as BaseEvent;
         }
       }
     },
   });
   ```

5. Register it in your Copilot Runtime route. The showcase registers this agent as `subagents`. This example uses `default`, so the prebuilt chat picks it up with no `agent` prop:

   ```ts title="app/api/copilotkit/[[...slug]]/route.ts"
   import {
     CopilotRuntime,
     createCopilotRuntimeHandler,
     InMemoryAgentRunner,
   } from "@copilotkit/runtime/v2";
   import { supervisor } from "@/src/lib/factory/supervisor";

   const runtime = new CopilotRuntime({
     agents: { default: supervisor },
     runner: new InMemoryAgentRunner(),
   });

   const handler = createCopilotRuntimeHandler({ runtime, basePath: "/api/copilotkit" });

   export const GET = handler;
   export const POST = handler;
   ```

This is where CopilotKit's shared-state channel helps: the
supervisor's tool calls mutate `delegations` as they happen, and the
frontend renders every new entry live.

<Callout type="warn">
  Give every delegation a stable `id` and merge new entries by that `id`. The
  client sends its copy of shared state back as run input on every run. A slot
  that appends everything it receives, such as a LangGraph
  `Annotated[list, operator.add]` reducer, adds those entries again. Then the
  log doubles when a thread continues. If your framework appends to the slot
  (for example a LangGraph `Annotated[list, operator.add]` reducer), write a
  reducer that merges by `id`.
</Callout>

## Rendering a live delegation log

On the frontend, the delegation log is a reactive render of the
`delegations` slot.

<FrontendOnly frontend="react">
Subscribe with `useAgent({ updates:
[UseAgentUpdate.OnStateChanged, UseAgentUpdate.OnRunStatusChanged] })`,
read `agent.state.delegations`, and render one card per entry.

The component below uses these types and styles. Put them at the top of the same file:

```tsx title="app/subagents/delegation-log.tsx"
"use client";

import React from "react";

export type SubAgentName = "research_agent" | "writing_agent" | "critique_agent";

export interface Delegation {
  id: string;
  sub_agent: SubAgentName;
  task: string;
  status: "completed";
  result: string;
}

export interface DelegationLogProps {
  delegations: Delegation[];
  /** True while the supervisor is actively running. */
  isRunning: boolean;
}

const SUB_AGENT_STYLE: Record<SubAgentName, { label: string; color: string; emoji: string }> = {
  research_agent: { label: "Research", color: "bg-indigo-50 border-indigo-300", emoji: "🔎" },
  writing_agent: { label: "Writing", color: "bg-emerald-50 border-emerald-300", emoji: "✍️" },
  critique_agent: { label: "Critique", color: "bg-amber-50 border-amber-300", emoji: "🧐" },
};
```

<Snippet region="delegation-log-frontend" title="app/subagents/delegation-log.tsx: live log component" />

Then render the log next to the chat on a page:

```tsx title="app/subagents/page.tsx"
"use client";

import { CopilotChat, useAgent, UseAgentUpdate } from "@copilotkit/react-core/v2";
import { DelegationLog, type Delegation } from "./delegation-log";

export default function SubagentsPage() {
  const { agent } = useAgent({
    updates: [UseAgentUpdate.OnStateChanged, UseAgentUpdate.OnRunStatusChanged],
  });
  const delegations = (agent.state?.delegations ?? []) as Delegation[];

  return (
    <main style={{ display: "flex", gap: 16, height: "100vh" }}>
      <div style={{ flex: 1 }}>
        <DelegationLog delegations={delegations} isRunning={agent.isRunning} />
      </div>
      <div style={{ flex: 1 }}>
        <CopilotChat />
      </div>
    </main>
  );
}
```
</FrontendOnly>
