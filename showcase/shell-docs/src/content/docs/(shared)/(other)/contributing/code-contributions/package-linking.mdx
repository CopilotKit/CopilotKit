Link your local CopilotKit packages into your own project. Then `pnpm run dev` in the monorepo updates your project as you edit.

## Global Package Linking With `pnpm`

Use pnpm's [link command](https://pnpm.io/cli/link) to link the CopilotKit packages to your own project. The commands below are for pnpm 10.

<Steps>
  <Step>
  ### In The CopilotKit Monorepo
  First, set up and build the monorepo with the [code contribution guide](/contributing/code-contributions).

Global linking needs pnpm's global bin directory. Create it once, then open a new terminal:

```bash
pnpm setup
```

In the CopilotKit monorepo, register the packages globally. Run the tasks one at a time (`--parallel=1`), because parallel runs overwrite each other's global links:

```bash
pnpm exec nx run-many -t link:global --parallel=1
```

These packages can be linked this way: `react-core`, `react-ui`, `react-textarea`, `runtime`, `runtime-client-gql`, `shared`, `sdk-js`, `react-native`, and `angular`.

Keep `pnpm run dev` running in the monorepo. It rebuilds the packages when you edit them, and your project picks up the new build.

  </Step>
  <Step>
  ### In Your Project
  In your project, make sure that you have pnpm configured. You can still use npm or yarn for other tasks, but global linking needs pnpm.

```bash
cd your-project
pnpm i
```

Next, link the desired package in your project:

<FrontendOnly frontend="react">
```bash
# For example, to link the @copilotkit/react-core package:
pnpm link @copilotkit/react-core
```
</FrontendOnly>

<FrontendOnly frontend="angular">
```bash
# Link the Angular package:
pnpm link @copilotkit/angular
```
</FrontendOnly>

Run this for each package you want to test. To check the link, resolve the package folder. It prints a path inside your CopilotKit monorepo, such as `.../CopilotKit/packages/react-core`:

```bash
readlink -f node_modules/@copilotkit/react-core
```

  </Step>
  <Step>
  ### Unlinking
  When you link a package, pnpm adds a line such as `'@copilotkit/react-core': link:...` under `overrides` in your project's `pnpm-workspace.yaml`. To undo the link:

1. In your project, delete those `@copilotkit/...` lines under `overrides` in `pnpm-workspace.yaml`.
2. Reinstall in your project:

   ```bash
   pnpm install --no-frozen-lockfile
   ```

3. Remove the global links. Run this for each package you linked:

   ```bash
   pnpm remove --global @copilotkit/react-core
   ```

Your project now uses its installed packages again.

  </Step>
</Steps>
