Link your local CopilotKit packages into your own project. Then `pnpm run dev` in the monorepo updates your project as you edit.

## Global Package Linking With `pnpm`

Use pnpm's [global linking feature](https://pnpm.io/cli/link#pnpm-link---global) to link the CopilotKit packages to your own project.

<Steps>
  <Step>
  ### In The CopilotKit Monorepo
  First, set up the monorepo with the [code contribution guide](/contributing/code-contributions).

Navigate to the CopilotKit monorepo and run the following command to link the packages globally:

```bash
pnpm exec nx run-many -t link:global
```

  </Step>
  <Step>
  ### In Your Project
  In your project, make sure that you have pnpm configured. You can still use npm or yarn for other tasks, but global linking needs pnpm.

```bash
cd your-project
pnpm i
```

Next, link the desired package in your project:

<FrontendOnly frontend="react">
```bash
# For example, to link the @copilotkit/react-core package:
pnpm link --global @copilotkit/react-core
```
</FrontendOnly>

<FrontendOnly frontend="angular">
```bash
# Link the Angular package:
pnpm link --global @copilotkit/angular
```
</FrontendOnly>

Run this for all packages, or only the ones you need. Your changes now sync to your project.

  </Step>
  <Step>
  ### Unlinking
  When you are done, undo the global linking. Run this command in the CopilotKit monorepo:

```bash
pnpm exec nx run-many -t unlink:global
```

And then in your project:

```bash
pnpm install
```

Your project now uses its installed packages again.

  </Step>
</Steps>
