The quickstart and reference guides for this frontend are ready. Some React features, such as A2UI rendering, are not in every frontend. The reference for this frontend lists what it exports.

Use these docs in three layers:

1. Start with the quickstart in this sidebar. It shows the install, provider, and first working connection for this frontend.
2. Use the Reference docs link in this sidebar for the most specific API surface available.
3. For broader product patterns, use the React docs as the complete feature map, then translate the implementation with the frontend-specific reference. Point your coding agent at both pages.
