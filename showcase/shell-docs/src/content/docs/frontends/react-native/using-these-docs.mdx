These docs follow the same outline as every app frontend. When React Native needs different code, a React Native version of the page takes the place of the React one. Pages about the runtime, agents, and Intelligence are shared by every frontend.

1. Start with the [React Native quickstart](/quickstart). It covers the install, the polyfills, Metro, the provider, and a first chat against your Copilot Runtime.
2. Pick your agent framework in the sidebar. The backend steps on each page change with it, and the React Native code stays the same.
3. Use the feature pages in the sidebar for [frontend tools](/frontend-tools), [generative UI](/generative-ui), [shared state](/shared-state), [human-in-the-loop](/human-in-the-loop), [attachments](/multimodal-attachments), [prebuilt components](/prebuilt-components), and [headless UI](/custom-look-and-feel/headless-ui).
4. Use the [React Native reference](/reference/react-native) for every component, hook, and prop.

The samples import from three entry points:

- `@copilotkit/react-native/headless`: the provider and the hooks, with no native peer dependencies. Most samples use it.
- `@copilotkit/react-native`: adds attachments (`useAttachments`), and the `CopilotPopup` and `CopilotSidebar` chrome. It needs `expo-document-picker` and `expo-file-system`.
- `@copilotkit/react-native/components`: the rendered chat (`CopilotChat`, `CopilotModal`, `CopilotMarkdown`). It needs `@gorhom/bottom-sheet`, `react-native-gesture-handler`, `react-native-reanimated`, and `react-native-streamdown`.

Some React features aren't available on React Native yet: CSS theming and chat slots, reasoning messages, the default tool card, the voice hooks, the threads drawer and headless threads, A2UI, MCP Apps, and Open Generative UI. Pages for those don't appear in this sidebar. The [quickstart](/quickstart#known-limitations) lists the limits and the workarounds.
