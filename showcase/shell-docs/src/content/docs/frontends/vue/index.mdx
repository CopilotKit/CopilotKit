## Getting started

<Steps>
    <Step>
        ### Create your Vue app

        If you don't have one already, create a TypeScript app. The `--ts` flag also skips the interactive prompts:

        ```bash
        npm create vue@latest my-copilot-app -- --ts
        cd my-copilot-app
        npm install
        ```
    </Step>
    <Step>
        ### Install CopilotKit

        Install the Vue frontend package and `@copilotkit/runtime` for your local Copilot Runtime server:

        <Tabs groupId="package-manager" items={['npm', 'pnpm', 'yarn']}>
            <Tab value="npm">
                ```bash
                npm install @copilotkit/vue @copilotkit/runtime
                npm install -D tsx typescript @types/node
                ```
            </Tab>
            <Tab value="pnpm">
                ```bash
                pnpm add @copilotkit/vue @copilotkit/runtime
                pnpm add -D tsx typescript @types/node
                ```
            </Tab>
            <Tab value="yarn">
                ```bash
                yarn add @copilotkit/vue @copilotkit/runtime
                yarn add -D tsx typescript @types/node
                ```
            </Tab>
        </Tabs>
    </Step>
    <WhenAgentBackend selected={false}>
    <Step>
        ### Create the Copilot Runtime

        Add a small runtime server that hosts Copilot Runtime at `/api/copilotkit` and registers a `default` Built-in Agent:

        <Callout type="warn" title="Already have an agent? Do not use BuiltInAgent">
          `BuiltInAgent` is CopilotKit's own agent. It calls the model directly,
          so registering it as `default` replaces your agent instead of
          connecting to it. Pick your agent's framework in the sidebar's
          **Agent framework** menu, and this step shows how to register your
          agent instead.
        </Callout>

        ```ts title="server.ts"
        import { createServer } from "node:http";
        import { BuiltInAgent, CopilotRuntime } from "@copilotkit/runtime/v2";
        import { createCopilotNodeListener } from "@copilotkit/runtime/v2/node";

        const runtime = new CopilotRuntime({
          agents: {
            default: new BuiltInAgent({
              model: "openai:gpt-6-luna",
              prompt: "You are a helpful assistant for a Vue app.",
            }),
          },
        });

        const port = Number(process.env.PORT ?? 8200);

        createServer(
          createCopilotNodeListener({
            runtime,
            basePath: "/api/copilotkit",
            cors: true,
          }),
        ).listen(port, () => {
          console.log(
            `Copilot Runtime listening at http://localhost:${port}/api/copilotkit`,
          );
        });
        ```

        <Callout type="info" title="Vite and Copilot Runtime run on separate origins">
          Vite serves the Vue app (usually on `http://localhost:5173`) while the runtime server runs on `http://localhost:8200`. Because the browser calls across those origins, `cors: true` is required for local development. `createCopilotNodeListener` does not enable CORS by default.
        </Callout>
    </Step>
    </WhenAgentBackend>
    <WhenAgentBackend selected>
      <AgentBackends />
    </WhenAgentBackend>
    <Step>
        ### Import the styles

        Import the package stylesheet once in your app entry. It's self-contained, so the chat renders without any other CSS. Replace `src/main.ts` with:

        ```ts title="src/main.ts"
        import { createApp } from "vue";
        import App from "./App.vue";
        import "@copilotkit/vue/styles.css"; // [!code highlight]

        createApp(App).mount("#app");
        ```

        This removes the scaffold's `./assets/main.css` import. Its `#app` grid layout squeezes the chat into a narrow column.
    </Step>
    <Step>
        ### Connect to Copilot Runtime

        Point `CopilotKitProvider` at the runtime endpoint and drop in `CopilotChat`. Because the runtime registers an agent named `default`, the chat picks it up automatically.

        ```vue title="src/App.vue"
        <script setup lang="ts">
        import { CopilotKitProvider, CopilotChat } from "@copilotkit/vue/v2"; // [!code highlight]
        </script>

        <template>
          <!-- [!code highlight:8] -->
          <CopilotKitProvider
            runtime-url="http://localhost:8200/api/copilotkit"
          >
            <div style="height: 100vh">
              <CopilotChat />
            </div>
          </CopilotKitProvider>
        </template>
        ```

        <Callout type="info" title="Pick your chat layout">
          `CopilotChat` is the full-height chat surface. Use `CopilotSidebar` for a fixed side panel with open/close behavior, or `CopilotPopup` for a floating panel with a toggle button. They share core agent and chat wiring, but each surface also has layout-specific props and behavior.
        </Callout>
    </Step>
    <WhenAgentBackend selected={false}>
    <Step>
        ### Run the runtime and app

        Start Copilot Runtime in one terminal:

        ```bash
        export OPENAI_API_KEY=sk-...
        npx tsx server.ts
        ```

        If you set `PORT`, change the `runtime-url` in `App.vue` to match.

        Start the Vue app in another terminal:

        ```bash
        npm run dev
        ```

        Open the dev server URL (Vite prints it, usually `http://localhost:5173`), send a message, and you'll see it stream back through Copilot Runtime.

        <Accordions className="mb-4">
            <Accordion title="Troubleshooting">
                - **Chat renders unstyled**: Make sure you imported `@copilotkit/vue/styles.css` in your app entry.
                - **No response from the agent**: Confirm the runtime server is running and `http://localhost:8200/api/copilotkit/info` returns agent information.
                - **CORS errors**: The Vite app and the runtime server use different origins. Keep `cors: true` in `createCopilotNodeListener` for local development. It is CORS-disabled by default. Configure an explicit allowed origin before deploying.
                - **Model auth errors**: Confirm `OPENAI_API_KEY` is set in the terminal running `npx tsx server.ts`.
            </Accordion>
        </Accordions>
    </Step>
    </WhenAgentBackend>
    <WhenAgentBackend selected>
    <Step>
        ### Run the runtime and app

        Keep the agent running. In your app folder, start Copilot Runtime:

        ```bash
        npx tsx server.ts
        ```

        Check that it found your agent: `http://localhost:8200/api/copilotkit/info` lists an agent named `default`.

        Start the Vue app in a third terminal:

        ```bash
        npm run dev
        ```

        Open the dev server URL (Vite prints it, usually `http://localhost:5173`) and send a message. It goes from Vue to Copilot Runtime to your agent, and the reply streams back.

        <Accordions className="mb-4">
            <Accordion title="Troubleshooting">
                - **Chat renders unstyled**: Make sure you imported `@copilotkit/vue/styles.css` in your app entry.
                - **`/info` lists no `default` agent, or the chat shows a connection error**: Check that the agent is still running, on the port `server.ts` points at.
                - **CORS errors**: Keep `cors: true` in `createCopilotNodeListener` for local development. Configure an explicit allowed origin before deploying.
                - **Model auth errors**: The agent calls the model, so its key goes in the agent's environment, not the runtime's.
            </Accordion>
        </Accordions>
    </Step>
    </WhenAgentBackend>
