CopilotKit provides three ready-made Vue chat layouts: `CopilotChat` for an embedded conversation, `CopilotSidebar` for a collapsible panel, and `CopilotPopup` for a floating entry point. They connect to the surrounding provider and agent configuration.

## Choose a layout

Use the component that fits the place where a conversation belongs in your product. Start with `CopilotChat` when the conversation is part of the page; use the sidebar or popup when it should stay available alongside the main workflow.

Import `@copilotkit/vue/styles.css` once at the application entry point, as in the [quickstart](/vue). Configure the runtime on `CopilotKitProvider`, then customize the selected surface with its props and [slots](/vue/custom-look-and-feel/slots).
