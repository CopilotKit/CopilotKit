Keep your existing Vue UI connected to your app Runtime while you add hosted Thread storage on the server. First confirm the frontend boundary below; then select the hosted project and update the Runtime.

## Confirm the Vue frontend points at your app Runtime

Keep the Vue provider pointed at your app Runtime's `/api/copilotkit` endpoint. Do not add the managed project key or either hosted URL to Vue configuration.

Vue exposes its own `useThreads` composable for a persistent thread list. Follow the [Vue `useThreads` reference](/reference/vue/hooks/useThreads) for its Vue refs, pagination, realtime updates, and mutation methods, then return here to verify persistence and user isolation.

Keep your current auth headers or cookie settings when you update the Runtime URL. The Vue client should authenticate only to your app Runtime.
