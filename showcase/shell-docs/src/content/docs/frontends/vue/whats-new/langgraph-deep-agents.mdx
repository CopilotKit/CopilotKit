## What are Deep Agents?

Deep Agents can plan multi-step workflows, manage file systems for context,
spawn subagents for specialized tasks, and maintain long-term memory across
sessions.

CopilotKit connects a Deep Agents backend to the frontend through AG-UI. A Vue
application can present the streamed conversation, reasoning, tool activity,
and shared state using the current Vue chat and composable surfaces.

<Callout type="info">
  Current Vue source and tests do not provide a dedicated UI for interacting
  with individual subagents as they spawn, so this Vue announcement does not
  promise that interaction.
</Callout>
