The Inspector is an in-app debugging surface for understanding what happens between the Vue client, Copilot Runtime, and connected agents.

## What it shows

| Area | What to inspect |
| --- | --- |
| AG-UI events | The event stream exchanged with the agent |
| Available agents | Agents discovered from the configured Runtime |
| Agent state | Current state as events update it |
| Frontend tools | Registered browser tools and schemas |
| Context | Values registered for the agent |

The provider's separate `debug` option controls event-pipeline logging. Use `true` for the standard event and lifecycle channels or an object to select `events`, `lifecycle`, and `verbose`.

Set `showDevConsole="auto"` to render the Inspector only on `localhost` or `127.0.0.1`, or `false` to disable it. Setting it to `true` is unconditional in the Vue provider, so do not rely on a production build to hide it automatically.

## Development and production guidance

Use the Inspector and targeted debug channels while diagnosing connection, event, state, tool, or context behavior. Prefer `auto` for local development and disable verbose logging and unconditional Inspector visibility in production configuration.

See [CopilotKitProvider](/reference/vue/components/CopilotKitProvider) for `showDevConsole`, `debug`, and Inspector anchoring.
