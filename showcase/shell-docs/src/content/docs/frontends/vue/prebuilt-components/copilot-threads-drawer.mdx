## What is this?

`CopilotThreadsDrawer` is a ready-made conversation sidebar. It lists, switches, starts, archives, unarchives, and deletes Rich Threads beside `CopilotChat` without requiring host-managed active-thread state.

Use it when you want a persistent, theme-aware, mobile-ready thread switcher. Rich Threads require Enterprise Intelligence; an unlicensed drawer displays its locked state instead of fetching the list.

If your product needs rename controls, a different permission model, or a fully custom layout, build on [`useThreads`](/reference/vue/hooks/useThreads) through [Headless Threads](/vue/headless-threads).

That shared configuration is the connection between the two surfaces. Selecting a row marks its `threadId` explicit so the chat replays history. Starting a new conversation mints a fresh, non-explicit ID and returns the chat to its empty state. Do not wrap the drawer and chat in separate configuration providers.

## Configuring the drawer

The drawer works with no props. Current optional controls include:

| Prop or slot | Purpose |
| --- | --- |
| `agentId` | Choose the agent whose threads are listed; otherwise inherit the shared chat configuration. |
| `label` | Set the accessible name for the drawer and list. |
| `recentLabel` | Change the heading above recent conversations. |
| `onThreadSelect` | Take over selection instead of shared configuration. |
| `onNewThread` | Take over new-conversation behavior. |
| `#row="{ thread }"` | Render custom content for every thread row. Defining the slot replaces the built-in content for all rows; there is no per-row fallback. |
| `limit` | Enable paginated loading at the requested page size. |

Callbacks are escape hatches. Omit them when the standard shared-configuration behavior is correct.

## Customization

The underlying drawer uses self-contained styles that inherit the application theme. Default-slot children can target its supported web-component slots, while the scoped `#row` slot is Vue's per-thread projection API. Once `#row` is defined, Vue projects custom content for every thread and the element does not fall back to its built-in row content for selected rows. Recreate any required row controls in the slot.

Use the drawer's supported CSS parts and `--cpk-drawer-*` variables for structural and token-level styling.

For broader chat customization, see [Slots](/vue/custom-look-and-feel/slots). For complete list ownership, see [Headless Threads](/vue/headless-threads).

## License
