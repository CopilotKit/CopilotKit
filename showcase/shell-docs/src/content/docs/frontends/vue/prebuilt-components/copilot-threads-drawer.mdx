## What is this?

`<CopilotThreadsDrawer>` gives your app a ready-made conversation sidebar. Users can list, switch, start, archive, and delete their threads, and you wire up **no active-thread state** to make it work. Drop it next to your chat and it connects automatically through a shared chat configuration.

If your project was created from a CopilotKit CLI starter, the Drawer and its shared configuration may already be included. Otherwise, use the setup below to add it to an existing Vue application.

Under the hood, the Vue component is an SSR-safe wrapper around the self-contained `copilotkit-threads-drawer` web component. It is fed by [`useThreads`](/reference/vue/hooks/useThreads) and the current chat configuration.

Prefer to build your own thread UI? The same data and actions are available through `useThreads`; see [Headless Threads](/headless-threads). Thread **rename** is one of those headless actions: the prebuilt drawer covers archive, unarchive, and delete, so use your own rows when rename is required.

## When should I use this?

Use the drawer when you want:

- A persistent thread switcher beside your chat
- Thread switching, new conversations, archive, and delete with zero wiring
- A self-contained, themeable UI that follows your app's light/dark theme
- A mobile-ready off-canvas drawer with its own launcher

It requires CopilotKit Intelligence because threads are stored and synchronized server-side. <SignupLink surface="docs_drawer">Get a free developer account</SignupLink> to set that up.

For multi-user applications, configure the runtime to [scope Rich Threads to the signed-in user](/threads-lifecycle#scope-rich-threads-to-the-signed-in-user).

## Set up the Threads Drawer

Place `<CopilotThreadsDrawer>` next to `<CopilotChat>` and wrap **both** in a shared `<CopilotChatConfigurationProvider>`. That shared configuration lets the Drawer drive the chat: selecting a row connects the chat to that thread and replays its history; the New Conversation row resets the chat to a fresh welcome screen.

```vue title="src/App.vue"
<script setup lang="ts">
import {
  CopilotChat,
  CopilotChatConfigurationProvider,
  CopilotKitProvider,
  CopilotThreadsDrawer,
} from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
</script>

<template>
  <CopilotKitProvider runtime-url="/api/copilotkit" public-license-key="ck_pub_...">
    <CopilotChatConfigurationProvider agent-id="support">
      <div style="display: flex; height: 100dvh">
        <CopilotThreadsDrawer />
        <CopilotChat />
      </div>
    </CopilotChatConfigurationProvider>
  </CopilotKitProvider>
</template>
```

That's the whole integration. A hand-built sidebar would track the active thread id and pass selection/new-thread handlers between the list and chat; the shared configuration owns that state for the Drawer.

## Configuring the drawer

`<CopilotThreadsDrawer>` works with zero props. Its optional props are:

| Prop | Description |
| --- | --- |
| `agentId` | Agent whose threads to list; defaults to the chat configuration's agent. |
| `label` | Accessible name for the drawer region and listbox; defaults to `"Threads"`. |
| `recentLabel` | Heading above the list; defaults to `"Recent Conversations"`. |
| `onThreadSelect` | Escape hatch to take over thread selection. |
| `onNewThread` | Escape hatch to handle the New Conversation row. |
| `onLicensed` | Callback after the user completes the licensing flow. |
| `licenseUrl` | Override for the licensing destination. |
| `collapsible` | Whether the expanded desktop drawer can collapse; defaults to `true`. |
| `limit` | Page size. The drawer shows Load more while another page exists. |

See the [Vue Threads Drawer reference](/reference/vue/components/CopilotThreadsDrawer) for the full prop and event types.

## Customization

The drawer renders in a shadow root with self-contained, theme-inheriting styles. Vue exposes bounded escape hatches:

- **Named web-component slots:** project children with a `slot` attribute such as `header`, `empty`, `footer`, `memories`, or `launcher-icon`.

  ```vue
  <CopilotThreadsDrawer>
    <span slot="header">My conversations</span>
  </CopilotThreadsDrawer>
  ```

- **Per-row content:** use the Vue `#row="{ thread }"` scoped slot. Defining it replaces every row's inner content, so reproduce the default markup inside the slot when you need a per-row fallback.

  ```vue
  <CopilotThreadsDrawer>
    <template #row="{ thread }">
      <strong>{{ thread.name ?? "New conversation" }}</strong>
    </template>
  </CopilotThreadsDrawer>
  ```

- **CSS parts and variables:** style the web component's structural `::part()` targets or override its `--cpk-drawer-*` custom properties. The reference lists the supported parts and tokens.
