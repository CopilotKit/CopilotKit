---

Frontend tools are functions an agent can call in the user's browser. They are useful for updating UI state, using browser APIs, or completing an action that belongs to the active client session.

<VueDocExample file="app-control/frontend-tools.vue" region="frontend-tool" />

Give each tool a stable name, clear description, explicit parameter schema, and an async handler. The return value becomes the tool result available to the agent. Keep authorization-sensitive work on your server rather than exposing it as a browser tool.

For user approval before continuing an agent run, use [Interactive generative UI](/vue/generative-ui/your-components/interactive).
