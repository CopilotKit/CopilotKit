## What is this?

`useComponent` registers a Vue component as a display-only tool. When the agent calls it, CopilotKit renders that component in the conversation with the tool arguments as props. There is no handler and no user decision to unblock the run.

## When should I use this?

Use display-only generative UI for cards, charts, tables, previews, status, or other structured information that communicates more clearly than plain text. Use [Interactive](/vue/generative-ui/your-components/interactive) when the component must collect a human response.

## Without parameters

Simple registrations may omit `parameters`. The component still declares the props it expects:

<VueDocExample file="generative-ui/GreetingCard.vue" region="display-only-greeting-card" />

The same registration fixture shows `showGreeting` without a schema. Prefer an explicit schema when the agent needs a structured contract or when the component depends on precise payload fields.

## Other backend-tool rendering options

`useComponent` creates a display-only frontend tool. To render an already defined backend tool, use [`useRenderTool`](/reference/vue/hooks/useRenderTool) or a `tool-call-{name}` slot instead; those observe an existing tool rather than registering a new display component.

Continue to [Interactive](/vue/generative-ui/your-components/interactive) for approval flows or [Tool Rendering](/vue/generative-ui/tool-rendering) for backend calls.
