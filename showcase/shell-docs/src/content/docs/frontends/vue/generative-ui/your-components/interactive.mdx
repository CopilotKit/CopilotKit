## What is this?

`useHumanInTheLoop` registers a frontend tool whose handler waits for your rendered Vue UI. CopilotKit pauses the agent until the component calls `respond`, then sends that result back to the agent and continues the run.

## When should I use this?

Use this journey for browser-owned approvals, confirmations, or form input that should appear as an interactive tool in chat. For a pause emitted by a backend agent through the standard AG-UI interrupt protocol, use [`useInterrupt`](/reference/vue/hooks/useInterrupt) instead.

## Create a frontend human-in-the-loop tool

The approval renderer uses the public status union:

<VueDocExample file="generative-ui/CommandApprovalCard.ts" region="interactive-approval-card" />

- `InProgress` can contain partial streamed arguments and has no response callback.
- `Executing` has complete arguments and a `respond` callback; this is the phase where approval buttons act.
- `Complete` exposes the serialized result and no longer accepts a response.

Register the component with a stable name, an explicit schema, and an agent scope when appropriate:

<VueDocExample file="generative-ui/interactive.vue" region="interactive-human-in-the-loop" />

The tool has no application-provided handler. `useHumanInTheLoop` owns the pending promise and resolves it when the user responds. Return a concise result that tells the agent what the person chose.

For a display that does not pause execution, use [Display-only](/vue/generative-ui/your-components/display-only). For backend tools, see [Tool Rendering](/vue/generative-ui/tool-rendering).
