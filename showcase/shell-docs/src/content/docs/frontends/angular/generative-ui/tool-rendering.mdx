## Render a tool result

A renderer is a standalone component with a required `toolCall` signal input.
Its status moves through `"in-progress"`, `"executing"`, and `"complete"`.

```ts title="src/app/weather-card.component.ts"
import { Component, input } from "@angular/core";
import {
  type AngularToolCall,
  type ToolRenderer,
} from "@copilotkit/angular";

type WeatherArgs = { city: string };

@Component({
  selector: "app-weather-card",
  template: `
    @let call = toolCall();
    @if (call.status === "complete") {
      <article>
        <strong>{{ call.args.city }}</strong>
        <p>{{ call.result }}</p>
      </article>
    } @else {
      <p>Loading weather for {{ call.args.city ?? "…" }}</p>
    }
  `,
})
export class WeatherCardComponent implements ToolRenderer<WeatherArgs> {
  readonly toolCall = input.required<AngularToolCall<WeatherArgs>>();
}
```

Then register the tool in one of two ways. Both run in an Angular injection
context, so call them in a component constructor. Install zod if your app does
not have it: `npm install zod`.

## The tool runs in the browser

Pass the class as `component` to `registerFrontendTool`:

```ts title="src/app/app.ts"
import { Component } from "@angular/core";
import { CopilotChat, registerFrontendTool } from "@copilotkit/angular";
import { z } from "zod";
import { WeatherCardComponent } from "./weather-card.component";

@Component({
  selector: "app-root",
  imports: [CopilotChat],
  template: `<div style="height: 100vh"><copilot-chat /></div>`,
})
export class App {
  constructor() {
    registerFrontendTool({
      name: "getWeather",
      description: "Get the current weather for a city",
      parameters: z.object({ city: z.string() }),
      component: WeatherCardComponent, // [!code highlight]
      handler: async ({ city }) => `Sunny, 22°C in ${city}`,
    });
  }
}
```

Replace the handler body with a call to your own weather API.

## The tool runs on the server

Define the tool on the agent in the quickstart's `server.ts`:

```ts title="server.ts"
import { BuiltInAgent, CopilotRuntime, defineTool } from "@copilotkit/runtime/v2";
import { z } from "zod";

const runtime = new CopilotRuntime({
  agents: {
    default: new BuiltInAgent({
      model: "openai:gpt-6-luna",
      prompt: "You are a helpful assistant for an Angular app.",
      // [!code highlight:8]
      tools: [
        defineTool({
          name: "getWeather",
          description: "Get the current weather for a city",
          parameters: z.object({ city: z.string() }),
          execute: async ({ city }) => `Sunny, 22°C in ${city}`,
        }),
      ],
    }),
  },
});
```

Then call `registerRenderToolCall` in the `App` constructor, in place of
`registerFrontendTool`. The browser only renders the call:

```ts title="src/app/app.ts"
import { registerRenderToolCall } from "@copilotkit/angular";

// in the App constructor:
registerRenderToolCall({
  name: "getWeather",
  args: z.object({ city: z.string() }),
  component: WeatherCardComponent,
});
```

For server tools, `call.result` is the serialized result, so a string shows
with quotes. Parse it with `JSON.parse` before you display it.

## Check the result

Ask the agent for the weather in Paris. The weather card shows "Loading
weather for Paris", then "Paris" and the tool result.
