Generative UI lets an agent show UI in chat, not only text. Angular supports
several paths. Pick the one that fits your agent, then follow its page.

## Choose a generative UI path

| Path | Best fit | Angular setup |
| --- | --- | --- |
| [Your components, display only](/angular/generative-ui/tool-based) | The agent should show a component and nothing else runs | `registerComponent` |
| [Your components](/angular/generative-ui/tool-rendering) | Known data shapes and application actions | `registerFrontendTool` or `registerRenderToolCall` with a component |
| [Native generative UI](/angular/generative-ui/native) | The agent composes a page from a catalog of your Angular components and the standard components | `provideGenerativeUI({ ui })` from `@copilotkit/angular/generative-ui` |
| [A2UI](/angular/generative-ui/a2ui) | A server emits A2UI operations or snapshots | Set `a2ui.catalog` in `provideCopilotKit` to turn on the built-in renderer; without a catalog A2UI stays off |
| [Open Generative UI](/angular/generative-ui/open-generative-ui) | The agent produces streamed HTML, CSS, and script expressions | Set `openGenerativeUI` in `provideCopilotKit` |
| [MCP Apps](/angular/generative-ui/mcp-apps) | An MCP server returns an interactive app resource | Add `provideMCPApps()` from `@copilotkit/angular/mcp-apps` |
