`CopilotChat` includes a microphone control. Voice input is transcribed through
Copilot Runtime and inserted into the composer as text.

## Accept voice input

No component option is required to display the microphone. The browser asks
for microphone permission, records the audio, and sends it to the Runtime
transcription endpoint. The resulting text remains editable before the user
sends it.

Serve production applications over HTTPS so browsers can grant microphone
access.

### Add a transcription service to the runtime

These steps change the `server.ts` from the [Angular quickstart](/angular).

1. Install the voice package and the OpenAI client:

   ```bash
   npm install @copilotkit/voice openai@^5.9.0
   ```

2. Pass a `transcriptionService` to `CopilotRuntime` in `server.ts`. The
   highlighted lines are new:

   ```ts title="server.ts"
   import { createServer } from "node:http";
   import { BuiltInAgent, CopilotRuntime } from "@copilotkit/runtime/v2";
   import { createCopilotNodeListener } from "@copilotkit/runtime/v2/node";
   import { TranscriptionServiceOpenAI } from "@copilotkit/voice"; // [!code highlight]
   import { OpenAI } from "openai"; // [!code highlight]

   const transcriptionKey = process.env["OPENAI_TRANSCRIPTION_API_KEY"]; // [!code highlight]

   const runtime = new CopilotRuntime({
     agents: {
       default: new BuiltInAgent({
         model: "openai:gpt-6-luna",
         prompt: "You are a helpful assistant for an Angular app.",
       }),
     },
     // [!code highlight:8]
     transcriptionService: transcriptionKey
       ? new TranscriptionServiceOpenAI({
           openai: new OpenAI({
             apiKey: transcriptionKey,
             baseURL: process.env["OPENAI_TRANSCRIPTION_BASE_URL"],
           }),
         })
       : undefined,
   });

   const port = Number(process.env["PORT"] ?? 8200);

   createServer(
     createCopilotNodeListener({
       runtime,
       basePath: "/api/copilotkit",
       cors: true,
     }),
   ).listen(port, () => {
     console.log(
       `Copilot Runtime listening at http://localhost:${port}/api/copilotkit`,
     );
   });
   ```

3. Set the speech-provider key in the terminal that runs the runtime, then
   restart it. Keep this key separate from the key the agent uses for chat:

   ```bash
   export OPENAI_TRANSCRIPTION_API_KEY=your-api-key
   # Optional: defaults to https://api.openai.com/v1
   export OPENAI_TRANSCRIPTION_BASE_URL=https://your-speech-provider.example.com/v1
   npx tsx server.ts
   ```

Without `OPENAI_TRANSCRIPTION_API_KEY`, the runtime has no
`transcriptionService`. It then reports `audioFileTranscriptionEnabled: false`
on `/info`, and the chat hides the mic. With the service, the browser sends
recorded audio to `{runtimeUrl}/transcribe`.

### Record a message

Open the chat. The composer shows a mic button labeled **Transcribe**. Click
it, allow microphone access, and speak. Then click **Finish** (or **Cancel** to
discard the recording). The text appears in the input for you to edit and send.

### Render tool calls from voice requests (optional)

Voice requests can call the same backend tools as typed requests. Register
renderers only for the exact tool names your backend exposes. Call
`registerRenderToolCall` from an Angular injection context:

```ts
registerRenderToolCall({
  name: "getWeather",
  args: z.object({ city: z.string() }),
  component: WeatherCardComponent,
});
```

`WeatherCardComponent` is the renderer from
[Render a tool result](/angular/generative-ui/tool-rendering#render-a-tool-result).

The renderer registration changes how matching tool calls are displayed, not
how speech is captured or transcribed.
