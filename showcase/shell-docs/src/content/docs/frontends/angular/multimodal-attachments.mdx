`CopilotChat` includes an attachment composer. Multimodal input sends image or
document content parts with the user's message.

## Enable attachments

Pass an `AttachmentsConfig` to `CopilotChat`. The built-in input supports the
file picker, drag and drop, and paste.

```ts title="src/app/media-chat.component.ts"
import { Component } from "@angular/core";
import {
  CopilotChat,
  type AttachmentsConfig,
} from "@copilotkit/angular";

@Component({
  selector: "app-media-chat",
  imports: [CopilotChat],
  template: `
    <copilot-chat [attachments]="attachments" />
  `,
})
export class MediaChatComponent {
  protected readonly attachments: AttachmentsConfig = {
    enabled: true,
    accept: "image/*,application/pdf",
    maxSize: 10 * 1024 * 1024,
    onUploadFailed: (error) => {
      console.error(error.reason, error.message);
    },
  };
}
```

Render `<app-media-chat />` in your root component (`src/app/app.ts`) in place
of `<copilot-chat />`, and add `MediaChatComponent` to its `imports`. The
composer now has an attach button, and you can also drag, drop, or paste files.

Without `onUpload`, files are read as base64. Supply `onUpload` to place large
files in your own storage and return a URL. The selected model and backend must
support each content type you allow.

The `accept` value filters the file picker and `maxSize` gives immediate client
feedback. They are not server-side security controls. Validate file type, size,
and content again wherever uploads are stored or processed.

## Send media programmatically

For a bundled sample or a custom uploader, add a user message whose `content`
holds AG-UI content parts, then run the agent. The message has a text part plus
an `image` part (for images) or a `document` part (for PDFs and other
documents).

1. Create `src/app/media-model.ts` with the two types the helper uses:

   ```ts title="src/app/media-model.ts"
   export interface SampleSpec {
     filename: string;
     mimeType: string;
     autoPrompt: string;
   }

   export interface MediaAgentMessage {
     id?: string;
     role: string;
     content?: readonly unknown[];
   }
   ```

2. Add this helper to the end of the same file. It builds the message from
   base64 file data:

   <AngularSnippet region="multimodal-message" />

3. Add the message to the agent and run it. This component sends a small red
   PNG when you click the button:

   ```ts title="src/app/send-sample.component.ts"
   import { Component, inject } from "@angular/core";
   import { CopilotKit, injectAgentStore } from "@copilotkit/angular";
   import { createMultimodalMessage } from "./media-model";

   const RED_SQUARE_PNG =
     "iVBORw0KGgoAAAANSUhEUgAAABAAAAAQCAIAAACQkWg2AAAAF0lEQVR4nGP4z8BAEiJN9aiGUQ1DSgMAkPn/Afnh+ngAAAAASUVORK5CYII=";

   @Component({
     selector: "app-send-sample",
     template: `<button type="button" (click)="send()">Send sample image</button>`,
   })
   export class SendSampleComponent {
     private readonly copilotKit = inject(CopilotKit);
     private readonly store = injectAgentStore("default");

     protected async send(): Promise<void> {
       const agent = this.store().agent;
       const message = createMultimodalMessage(
         {
           filename: "red.png",
           mimeType: "image/png",
           autoPrompt: "Describe this image",
         },
         RED_SQUARE_PNG,
         80,
         crypto.randomUUID(),
       );
       agent.addMessage(message as Parameters<typeof agent.addMessage>[0]);
       await this.copilotKit.core.runAgent({ agent });
     }
   }
   ```

4. Add `SendSampleComponent` to the root component's `imports` and render
   `<app-send-sample />` next to the chat.

Click **Send sample image**. The chat shows your prompt with the image, and the
agent replies about it. The chosen model and backend converter must support
each MIME type you send.

<Callout type="warn" title="TS2739 on `runAgent({ agent })`">
  `@copilotkit/angular` 0.6.0 pins `@ag-ui/client` 1.0.2, and the
  `@copilotkit/core` it installs pins 1.0.5. The two `AbstractAgent` types then
  differ, and `ng serve` fails with `TS2739` on the `runAgent` line. Make both
  use one version. Add this to `package.json` and run `npm install`:

  ```json title="package.json"
  "overrides": {
    "@ag-ui/client": "1.0.5",
    "@ag-ui/core": "1.0.5"
  }
  ```
</Callout>
