`@copilotkit/vue` provides Vue 3 components and composables for CopilotKit. This guide creates a Vue app with a chat UI backed by a separate local Copilot Runtime and a `default` Built-in Agent.

The runtime runs on your server, keeps model credentials out of the browser, and exposes the `default` agent that `CopilotChat` uses automatically.

## Prerequisites

- An OpenAI API key (or another model provider supported by [Model Selection](/vue/model-selection))
- Vue 3
- Node.js 20+

## Getting started

<Steps>
    <Step>
        ### Create your Vue app

        If you don't have one already:

        ```bash
        npm create vue@latest my-copilot-app
        cd my-copilot-app
        npm install
        ```
    </Step>
    <Step>
        ### Install CopilotKit

        Install the Vue frontend package and `@copilotkit/runtime` for your local Copilot Runtime server:

        <Tabs groupId="package-manager" items={['npm', 'pnpm', 'yarn']}>
            <Tab value="npm">
                ```bash
                npm install @copilotkit/vue @copilotkit/runtime
                npm install -D tsx typescript @types/node
                ```
            </Tab>
            <Tab value="pnpm">
                ```bash
                pnpm add @copilotkit/vue @copilotkit/runtime
                pnpm add -D tsx typescript @types/node
                ```
            </Tab>
            <Tab value="yarn">
                ```bash
                yarn add @copilotkit/vue @copilotkit/runtime
                yarn add -D tsx typescript @types/node
                ```
            </Tab>
        </Tabs>
    </Step>
    <Step>
        ### Create the Copilot Runtime

        Add a small Node server that registers a `default` agent and accepts requests at `http://localhost:4000/api/copilotkit`. CORS is enabled because the Vite or Nuxt app runs separately during local development.

        <VueDocExample file="quickstart/server.ts" region="runtime-server" />
    </Step>
    <Step>
        ### Import the styles

        Import the package stylesheet once in your app entry. It's self-contained, so the chat renders without any other CSS.

        <VueDocExample file="quickstart/main.ts" region="vite-entry-point" />
    </Step>
    <Step>
        ### Connect to Copilot Runtime

        Point `CopilotKitProvider` at the runtime endpoint and add `CopilotChat`. Because the runtime registers an agent named `default`, the chat selects it explicitly.

        <VueDocExample file="quickstart/App.vue" region="provider-chat-app" />

        <Callout type="info" title="Pick your chat layout">
          `CopilotChat` is a full-height chat. Swap it for `CopilotSidebar` (a collapsible side panel) or `CopilotPopup` (a floating widget) for a different layout. All three share the core chat props; the sidebar and popup add layout and open-state controls.
        </Callout>
    </Step>
    <Step>
        ### Run the runtime and app

        Start Copilot Runtime in one terminal:

        ```bash
        export OPENAI_API_KEY=sk-...
        npx tsx server.ts
        ```

        Start the Vue app in another terminal:

        ```bash
        npm run dev
        ```

        Open the dev server URL (Vite prints it, usually `http://localhost:5173`), send a message, and you'll see it stream back through Copilot Runtime.

        <Accordions className="mb-4">
            <Accordion title="Troubleshooting">
                - **Chat renders unstyled**: Make sure you imported `@copilotkit/vue/styles.css` in your app entry.
                - **No response from the agent**: Confirm the runtime server is running and `http://localhost:4000/api/copilotkit/info` returns agent information.
                - **CORS errors**: Keep `cors: true` in the local runtime server, or configure CORS to allow your Vue app's origin in production.
                - **Model auth errors**: Confirm `OPENAI_API_KEY` is set in the terminal running `npx tsx server.ts`.
            </Accordion>
        </Accordions>
    </Step>
</Steps>
