# Generative UI

Your agent can answer with UI in place of text. Pick the approach by who decides what renders.

## Controlled

You build the components. The agent's tool calls and state decide what they show.

- [Components as Tools](/generative-ui/tool-based): the agent calls your React components as tools.
- [Tool Rendering](/generative-ui/tool-rendering): render your agent's tool calls with your own UI.
- [State Rendering](/generative-ui/state-rendering): render UI from agent state.
- [Display Only](/generative-ui/display): the agent renders read-only components.
- [Interactive](/generative-ui/interactive): the agent pauses for a human decision in a component you build.

## Frontend-Driven

Your app, not the agent, decides to show a card.

- [Frontend-Driven Cards](/generative-ui/frontend-cards): insert a card into the chat from frontend code.

## Declarative

The agent writes a UI spec. Your app renders it from a catalog of allowed components.

- [Components and surfaces](/generative-ui/components): the agent renders your React components, in the chat and in areas of your page.
- [A2UI](/generative-ui/a2ui): render surfaces from the Agent-to-UI protocol.
- [JSON Render](/generative-ui/json-render): render a typed JSON spec through your component registry.
- [Hashbrown](/generative-ui/hashbrown): stream a dashboard through a Hashbrown UI kit.

## Open-Ended

The agent or an MCP server brings its own UI.

- [MCP Apps](/generative-ui/mcp-apps): render UI from MCP servers in the chat.
- [Open Generative UI](/generative-ui/open-generative-ui): the agent generates HTML, CSS, and JavaScript that streams into the chat.
