## What is this?

State rendering lets you build UI that reflects your agent's state in real-time. As your agent progresses through nodes and emits state updates, your frontend renders those changes, showing progress, drafts, or intermediate results.

## When should I use this?

Use state rendering when you want to:

- Show real-time progress (for example, "Researching... 2/5 complete")
- Display drafts that update as the agent works
- Build dashboards that reflect agent state
- Render structured output outside of the chat

## How it works in code

The example on this page renders a `document` key that the agent writes.
You do three things: set up shared state, make the agent write `document`,
and render `document` on the frontend.

### 3. Render the state on the frontend

Subscribe to the agent state with `useAgent`. Each time the state changes,
your component renders again with the latest value:

<Snippet region="frontend-use-coagent-state" title="frontend/src/app/page.tsx: agent state subscription" />

The demo registers its agent as `shared-state-streaming`. Replace that id with
the name you registered your agent under on Copilot Runtime, for example
`sample_agent`.

Then read the key from `agent.state` and render it. A complete page looks
like this:

```tsx title="app/page.tsx"
"use client";

import { CopilotChat, useAgent, UseAgentUpdate } from "@copilotkit/react-core/v2";

export default function Page() {
  const { agent } = useAgent({
    agentId: "sample_agent", // the name you registered on Copilot Runtime
    updates: [UseAgentUpdate.OnStateChanged, UseAgentUpdate.OnRunStatusChanged],
  });
  const document = (agent.state as { document?: string }).document ?? "";

  return (
    <main style={{ display: "flex", height: "100vh" }}>
      <pre style={{ flex: 1, padding: 16, whiteSpace: "pre-wrap" }}>{document}</pre>
      <div style={{ flex: 1 }}>
        <CopilotChat agentId="sample_agent" />
      </div>
    </main>
  );
}
```

The page must render inside your `CopilotKit` provider.

To check it, ask the agent to write a short poem. Your component renders the
poem each time the agent updates `document` in its state.

To render the state inside the chat instead, pass a `children` function to
the chat's `messageView` slot and add your UI next to the messages. For
example, to list the searches an agent keeps in a `searches` key:

```tsx
<CopilotChat
  agentId="sample_agent"
  messageView={{
    children: ({ messageElements, interruptElement }) => (
      <div>
        {messageElements}
        {state.searches?.map((search, index) => (
          <div key={index}>{search.done ? "✅" : "❌"} {search.query}</div>
        ))}
        {interruptElement}
      </div>
    ),
  }}
/>
```

Here `state` is `agent.state` from `useAgent`.
