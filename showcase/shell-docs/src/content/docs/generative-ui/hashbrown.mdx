Hashbrown renders a dashboard while the assistant streams JSON. The example below uses the Strands TypeScript showcase and its pinned `@hashbrownai/core` and `@hashbrownai/react` version, `0.5.0-beta.4`. Copy the complete files from the demo's **Code** tab, including the chart and metric components. If you install a different Hashbrown version, check its API before reusing this code.

```bash
npm install @hashbrownai/core@0.5.0-beta.4 @hashbrownai/react@0.5.0-beta.4
```

## When to use this

- **Streaming dashboards** that should appear before the full response arrives.
- **Agent-authored UI** constrained to components you expose in a UI kit.
- **Apps already using Hashbrown** for progressive JSON rendering.

For a validated `{ root, elements }` spec that renders as one tree, see [JSON Render](/generative-ui/json-render). Its agent output and React API are different from Hashbrown's.

## Backend

The agent sends **one JSON object** as the assistant message, without a Markdown fence or prose before it. Its top-level `ui` array contains component names from the kit. Each component has a `props` object matching its schema. For example:

```json title="example assistant message"
{
  "ui": [
    { "metric": { "props": { "label": "Total Revenue", "value": "$1.2M" } } },
    {
      "pieChart": {
        "props": {
          "title": "Revenue by Segment",
          "data": "[{\"label\":\"Enterprise\",\"value\":600000},{\"label\":\"SMB\",\"value\":400000},{\"label\":\"Startup\",\"value\":200000}]"
        }
      }
    }
  ]
}
```

The Strands TypeScript agent prompt defines this envelope and its component names. The parser can render finished parts of `ui` while the rest of the JSON is still streaming. The old `{ "type": "MetricCard" }` example is a different contract and cannot be passed to this UI kit.

## Comparing the two patterns

Hashbrown uses a `ui` array, `useJsonParser(content, kit.schema)`, and `kit.render(value)` for progressive rendering. [JSON Render](/generative-ui/json-render) uses a `{ root, elements }` spec and a separate catalog and registry. Use the contract for the library you chose.
