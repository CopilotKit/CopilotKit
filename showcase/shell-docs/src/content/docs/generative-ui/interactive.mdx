## What is this?

Interactive generative UI creates flows where the agent pauses execution and waits for user input before continuing. This enables approval workflows, confirmation dialogs, and any scenario where human judgment is needed mid-execution.

## When should I use this?

Use interactive generative UI when you need:

- Approval/rejection flows (e.g. "Run this command?")
- User decisions that the agent should know about
- Confirmation dialogs with structured responses
- Any flow where the agent pauses for human judgment

## How it works in code

<WhenFrameworkHas flag="interrupt_pattern" equals="native">

<FrameworkSetup concept="human-in-the-loop-setup" />

On the frontend, register an interrupt renderer with `useInterrupt`. When the
agent pauses, your component mounts inline in the chat, captures the user's
choice, and resumes the run with that input. The excerpt imports the demo's
`TimePickerCard`, its fallback slots, and its suggestions. Use your own picker
component in their place.

<Snippet region="frontend-useinterrupt-render" title="frontend/src/app/page.tsx — useInterrupt" />

On the backend, the agent calls into the interrupt primitive and waits for
the resumed response before continuing the graph.

<Snippet region="backend-interrupt-tool" title="backend — interrupt tool" />

Ask the agent to book a call, for example `Book an intro call with the sales
team to discuss pricing`. The time picker appears in the chat. Pick a slot,
and the agent confirms the booked time.

</WhenFrameworkHas>

<WhenFrameworkHas flag="interrupt_pattern" equals="promise-based">

<FrameworkSetup concept="human-in-the-loop-setup" />

This framework registers `schedule_meeting` as a frontend tool with
`useHumanInTheLoop`. The agent calls the tool, and the chat renders the picker.
The tool call resolves when the picker calls `respond(...)`, after the user
chooses a slot or cancels.

<Snippet region="frontend-useinterrupt-render" title="frontend/src/app/page.tsx — Promise-based frontend tool" />

<Snippet region="backend-tool-call" title="backend — agent instructed to call schedule_meeting" />

Ask the agent to book a call, for example `Book an intro call with the sales
team to discuss pricing`. The time picker appears in the chat. Pick a slot,
and the agent confirms the booked time.

</WhenFrameworkHas>
