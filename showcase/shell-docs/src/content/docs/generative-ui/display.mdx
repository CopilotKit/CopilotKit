## What is this?

A display component is a React component that your agent can call as a tool. When the agent calls the tool, CopilotKit renders your component directly in the chat with the tool's arguments as props. You do not write a handler, and the user does not need to do anything.

<Tabs items={['page.tsx', 'chart.tsx']}>
  <Tab value="page.tsx">
  `Chart` and `ChartProps` come from `chart.tsx`, in the next tab. In your app, import them with `import { Chart, ChartProps } from "./chart"`.

  ```tsx group=display-chart
  "use client";
  import { useComponent } from "@copilotkit/react-core";

  export function ChartTool() {
    useComponent({
      name: "showChart",
      description: "Populate data and show the user a chart",
      parameters: ChartProps,
      render: Chart,
    });
    return null;
  }
  ```
  </Tab>
  <Tab value="chart.tsx">
  ```tsx group=display-chart
  import { z } from "zod";
  import { Bar, BarChart, ResponsiveContainer, Tooltip, XAxis, YAxis } from "recharts";

  export const ChartProps = z.object({
    title: z.string(),
    data: z.array(z.object({ label: z.string(), value: z.number() })),
  });

  export function Chart({ title, data }: z.infer<typeof ChartProps>) {
    return (
      <div>
        <h3>{title}</h3>
        <ResponsiveContainer width="100%" height={300}>
          <BarChart data={data}>
            <XAxis dataKey="label" />
            <YAxis />
            <Tooltip />
            <Bar dataKey="value" fill="#6366f1" />
          </BarChart>
        </ResponsiveContainer>
      </div>
    );
  }
  ```
  </Tab>
</Tabs>

## When should I use this?

Use a display component when you want to:

- Display rich UI (cards, charts, tables) inline in the chat
- Show structured data from agent responses
- Render previews, status indicators, or visual feedback
- Let the agent present information beyond plain text

## Without parameters

For simple components that don't need typed parameters, leave out
`parameters`. The component then accepts any props:

```tsx
"use client";
import { useComponent } from "@copilotkit/react-core";

export function GreetingTool() {
  useComponent({
    name: "showGreeting",
    render: ({ message }: { message: string }) => (
      <div className="rounded border p-3 bg-blue-50">
        <p>{message}</p>
      </div>
    ),
  });
  return null;
}
```

## Scoping to an agent

In multi-agent setups, pass `agentId` to scope a component to one agent:

```tsx
"use client";
import { useComponent } from "@copilotkit/react-core";
import { z } from "zod";

function ProfileCard({ userId }: { userId: string }) {
  return <div className="rounded border p-3">Profile: {userId}</div>;
}

export function ProfileTool() {
  useComponent({
    name: "renderProfile",
    parameters: z.object({ userId: z.string() }),
    render: ProfileCard,
    agentId: "support-agent",
  });
  return null;
}
```
