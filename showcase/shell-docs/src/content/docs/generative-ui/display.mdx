## What is this?

A display component is a React component that your agent can call as a tool. When the agent calls the tool, CopilotKit renders your component directly in the chat with the tool's arguments as props. You do not write a handler, and the user does not need to do anything.

The chart in this example uses Recharts and Zod. Install them first:

```bash
npm install recharts zod
```

```tsx
"use client";

import { CopilotChat, useComponent } from "@copilotkit/react-core/v2";
import { Chart, ChartProps } from "./chart";

export default function Page() {
  useComponent({
    name: "showChart",
    description: "Populate data and show the user a chart",
    parameters: ChartProps,
    render: Chart,
  });

  return <CopilotChat />;
}
```

```tsx
import { z } from "zod";
import { ResponsiveContainer, BarChart, XAxis, YAxis, Tooltip, Bar } from "recharts";

export const ChartProps = z.object({
  title: z.string(),
  data: z.array(z.object({ label: z.string(), value: z.number() })),
});

export function Chart({ title, data }: z.infer<typeof ChartProps>) {
  return (
    <div>
      <h3>{title}</h3>
      <ResponsiveContainer width="100%" height={300}>
        <BarChart data={data}>
          <XAxis dataKey="label" /><YAxis /><Tooltip />
          <Bar dataKey="value" fill="#6366f1" />
        </BarChart>
      </ResponsiveContainer>
    </div>
  );
}
```

## When should I use this?

Use a display component when you want to:

- Display rich UI (cards, charts, tables) inline in the chat
- Show structured data from agent responses
- Render previews, status indicators, or visual feedback
- Let the agent present information beyond plain text

## Without parameters

For a component that needs no data from the agent, leave out `parameters`.
The tool then has an empty parameter schema, so the agent calls it with no
arguments and the component renders with no props:

```tsx
useComponent({
  name: "showGreeting",
  description: "Show a greeting banner to the user",
  render: () => (
    <div className="rounded border p-3 bg-blue-50">
      <p>Hello! How can I help?</p>
    </div>
  ),
});
```

If the component needs data, pass a `parameters` schema, as in the example at
the top of this page.

## Scoping to an agent

In multi-agent setups, pass `agentId` to scope a component to one agent:

```tsx
useComponent({
  name: "renderProfile",
  parameters: z.object({ userId: z.string() }),
  render: ProfileCard,
  agentId: "support-agent",
});
```
