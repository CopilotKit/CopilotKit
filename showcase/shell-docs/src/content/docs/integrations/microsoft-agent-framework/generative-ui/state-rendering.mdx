State rendering gives people visible progress while an agent works. The
Microsoft Agent Framework Showcase publishes a `steps` array and the React
chat renders that array as updates arrive.

## Keep the public key consistent

The frontend subscribes to the public runtime key `gen-ui-agent`. That key is
registered by the runtime and must match the `agentId` passed to `useAgent`.
The internal .NET and Python agent names may differ; they are not the frontend
contract.

## Try it

Ask the demo to create a short plan. As the agent publishes `steps`, the plan
card appears in the chat. For a UI-owned state value that the agent reads or
writes, see [Shared State](/shared-state).
