Dynamic-schema A2UI lets an agent choose a UI surface from the component catalog
registered by your app. Start with the [A2UI catalog guide](/generative-ui/a2ui/dynamic-schema)
to define that catalog. This guide shows the two Microsoft Agent Framework
Showcase policies that connect it to an agent.

## Choose one tool policy

Both demos register the same catalog with the runtime. They differ in who owns
`generate_a2ui`; do not combine the two approaches.

## What to verify

Ask the demo for a dashboard or comparison. The chat should produce a surface
from the registered catalog. If it does not, first check that the provider and
runtime use the same catalog identifier; then check that exactly one of the
policies above owns the A2UI tool.
