## Start with your coding agent

Use this prompt to connect your Microsoft Agent Framework agent to CopilotKit and verify a working conversation. Your coding agent will follow this guide in your project, or you can work through the manual steps below.

<PageAgentPrompt />

## Prerequisites

Before you begin, you'll need the following:

- An [OpenAI API key](https://platform.openai.com/api-keys), or an Azure OpenAI deployment for a Python agent
- .NET 9.0 SDK or later, for a .NET agent
- Python 3.12 or later and [uv](https://docs.astral.sh/uv/), for a Python agent
- Node.js 20+
- Your favorite package manager (npm, pnpm, yarn, or bun)

                ### Start your Microsoft Agent Framework agent

                Serve your agent over an AG-UI endpoint. This is a minimal example:

                <Tabs groupId="language_microsoft-agent-framework_agent" items={['.NET', 'Python']} persist>
                    <Tab value=".NET">
                        1. Create the project and add the packages:

                        ```bash
                        dotnet new web -n AGUIServer
                        cd AGUIServer
                        dotnet add package Microsoft.Agents.AI.Hosting.AGUI.AspNetCore --version 1.19.0-preview.260822.1
                        dotnet add package Microsoft.Agents.AI.OpenAI --version 1.19.0
                        dotnet user-secrets init
                        ```

                        2. Write `Program.cs`. It builds a minimal agent and serves it over AG-UI:

                        ```csharp title="Program.cs"
#pragma warning disable OPENAI001
using Microsoft.Extensions.AI;
                        using Microsoft.Agents.AI;
                        // [!code highlight:1]
                        using Microsoft.Agents.AI.Hosting.AGUI.AspNetCore;
                        using OpenAI;
                        using OpenAI.Chat;

                        var builder = WebApplication.CreateBuilder(args);
                        // [!code highlight:1]
                        builder.Services.AddAGUIServer();
                        var app = builder.Build();

                        var openAiApiKey = builder.Configuration["OPENAI_API_KEY"]
                            ?? throw new InvalidOperationException("Set OPENAI_API_KEY");
                        var openAI = new OpenAIClient(openAiApiKey);

                        var agent = openAI.GetChatClient("gpt-6-luna")
    .AsIChatClient().AsBuilder()
    .ConfigureOptions(options => options.RawRepresentationFactory = _ =>
        new OpenAI.Chat.ChatCompletionOptions { ReasoningEffortLevel = new("none") })
    .Build().AsAIAgent(
                            name: "MyAgent",
                            instructions: "You are a helpful assistant.");

                        // [!code highlight:1]
                        app.MapAGUIServer("/", agent);
                        app.Run("http://localhost:8000");
                        ```

                        3. Set the API key:

                        ```bash
                        dotnet user-secrets set OPENAI_API_KEY "<your-openai-api-key>"
                        ```

                        4. Run the agent:

                        ```bash
                        dotnet run
                        ```
                    </Tab>
                    <Tab value="Python">

                        1. Create the project and add the packages:

                        ```bash
                        uv init my-agent
                        cd my-agent
                        uv add agent-framework-ag-ui python-dotenv uvicorn agent-framework-openai azure-identity
                        ```

                        2. Replace the contents of `main.py` with this FastAPI server. It serves a Microsoft Agent Framework agent over AG-UI:

                        ```python title="main.py"
                        from __future__ import annotations
                        import os
                        import uvicorn
                        from agent_framework import Agent
                        from agent_framework.openai import OpenAIChatClient
                        from agent_framework.ag_ui import add_agent_framework_fastapi_endpoint
                        from azure.identity import DefaultAzureCredential
                        from dotenv import load_dotenv
                        from fastapi import FastAPI

                        load_dotenv()

                        def _build_chat_client():
                            if os.getenv("AZURE_OPENAI_ENDPOINT"):
                                azure_api_key = os.getenv("AZURE_OPENAI_API_KEY")
                                return OpenAIChatClient(
                                    model=os.getenv("AZURE_OPENAI_CHAT_DEPLOYMENT_NAME", "gpt-6-luna"),
                                    api_key=azure_api_key,
                                    credential=None if azure_api_key else DefaultAzureCredential(),
                                    azure_endpoint=os.getenv("AZURE_OPENAI_ENDPOINT"),
                                )
                            if os.getenv("OPENAI_API_KEY"):
                                return OpenAIChatClient(
                                    model=os.getenv("OPENAI_CHAT_MODEL_ID", "gpt-6-luna"),
                                    api_key=os.getenv("OPENAI_API_KEY"),
                                )
                            raise RuntimeError(
                                "Set AZURE_OPENAI_ENDPOINT (uses az login unless AZURE_OPENAI_API_KEY is set) or OPENAI_API_KEY."
                            )

                        chat_client = _build_chat_client()

                        agent = Agent(
                            name="MyAgent",
                            instructions="You are a helpful assistant.",
                            client=chat_client,
                        )

                        app = FastAPI(title="Microsoft Agent Framework - Quickstart")
                        # Local demo: one user, no sign-in.
                        add_agent_framework_fastapi_endpoint(app=app, agent=agent, path="/", single_user=True)

                        if __name__ == "__main__":
                            uvicorn.run("main:app", host="0.0.0.0", port=8000, reload=True)
                        ```

                        `single_user=True` declares that the endpoint has no sign-in. Without an authorization mode, the server stops at startup with `AG-UI endpoint authorization must be explicit`. For an app with sign-in, pass `authorization_scope_resolver` instead.

                        3. Create a `.env` file in `my-agent` with your OpenAI key:

                        ```plaintext title=".env"
                        OPENAI_API_KEY=sk-...your-openai-key-here...
                        OPENAI_CHAT_MODEL_ID=gpt-6-luna
                        ```

                        For Azure OpenAI, set `AZURE_OPENAI_ENDPOINT` and `AZURE_OPENAI_CHAT_DEPLOYMENT_NAME` instead. If you do not use `az login`, also set `AZURE_OPENAI_API_KEY`.

                        4. Run the agent:

                        ```bash
                        uv run main.py
                        ```

            <Step>
                ### Add the Copilot Runtime route

                CopilotKit needs a Copilot Runtime endpoint to talk to your agent safely. The endpoint can run
                anywhere that Node.js runs. This example serves it from Next.js.

                Create a new API route at `app/api/copilotkit/[[...slug]]/route.ts`:

                ```tsx title="app/api/copilotkit/[[...slug]]/route.ts" doctest="component"
                import {
                  CopilotRuntime,
                  createCopilotRuntimeHandler,
                } from "@copilotkit/runtime/v2";
                import { HttpAgent } from "@ag-ui/client";

                // [!code highlight:5]
                const runtime = new CopilotRuntime({
                  agents: {
                    my_agent: new HttpAgent({ url: "http://localhost:8000/" }),
                  },
                });

                const handler = createCopilotRuntimeHandler({
                  runtime,
                  basePath: "/api/copilotkit",
                });

                export const GET = handler;
                export const POST = handler;
                export const PATCH = handler;
                export const DELETE = handler;
                ```

                This route runs with an in-memory runner. Chat and the Inspector work without any key.

                <Accordions className="mb-4">
                    <Accordion title="Optional: connect CopilotKit Intelligence">
                        From this frontend app directory, sign in and select an Intelligence project:

                        ```bash title="Terminal"
                        npx copilotkit@latest login
                        npx copilotkit@latest project select
                        ```

                        `login` opens a browser sign-in. `project select` writes the server-side project API key to `.env`:

                        ```plaintext title=".env"
                        CPK_INTELLIGENCE_API_KEY=cpk-...
                        ```

                        Then add `CopilotKitIntelligence` to the imports and these two options to `new CopilotRuntime({ ... })`:

                        ```ts
                        intelligence: new CopilotKitIntelligence({
                          apiKey: process.env.CPK_INTELLIGENCE_API_KEY!,
                        }),
                        // Demo only: the browser sends no x-user-id header, so all visitors share
                        // one "anonymous" history. Before you deploy, return the verified session user.
                        identifyUser: (request) => ({
                          id: request.headers.get("x-user-id") ?? "anonymous",
                          name: request.headers.get("x-user-name") ?? "Anonymous",
                        }),
                        ```

                        Without the key, the route fails when it loads, with an error that the `CopilotKitIntelligence` `apiKey` is required. See [Connect your runtime to Intelligence](/intelligence/quickstart) to confirm the key is in use.
                    </Accordion>
                </Accordions>

            <Step>
                ### Configure CopilotKit Provider

                Next, wrap your application with the CopilotKit provider so that CopilotKit can take control across your application
                via the Microsoft Agent Framework agent.

                ```tsx title="app/providers.tsx"
                "use client";

                import { CopilotKit } from "@copilotkit/react-core/v2";

                export function Providers({ children }: { children: React.ReactNode }) {
                  return (
                    <CopilotKit runtimeUrl="/api/copilotkit" agent="my_agent" useSingleEndpoint={false}>
                      {children}
                    </CopilotKit>
                  );
                }
                ```

                Render `Providers` around your app in `app/layout.tsx`. Keep the generated file. Add the highlighted imports and wrap `{children}` in `<Providers>`:

                ```tsx title="app/layout.tsx"
                import { Suspense } from "react"; // [!code highlight]
                import { Providers } from "./providers"; // [!code highlight]
                import "@copilotkit/react-core/v2/styles.css"; // [!code highlight]
                import './globals.css';

                export default function RootLayout({ children }: {children: React.ReactNode}) {
                  return (
                    <html lang="en">
                      <body>
                        {/* [!code highlight:5] */}
                        <Suspense>
                          <Providers>
                            {children}
                          </Providers>
                        </Suspense>
                      </body>
                    </html>
                  );
                }
                ```

                `<Suspense>` keeps `npm run build` working when `next.config.ts` sets `cacheComponents: true`, the `create-next-app` default in Next.js 16. Without it, the build fails with `encountered the unstable value require('node:crypto').randomUUID()`.

                <Callout type="info" title="This relative runtimeUrl assumes Next.js serves the runtime">
                  `/api/copilotkit` resolves only because Next.js serves your app and the runtime from the
                  same origin. A client-only frontend has no shared origin, so it needs a standalone runtime
                  server of its own and an absolute `runtimeUrl` such as
                  `http://localhost:8200/api/copilotkit`. See the [React SPA](/react-spa), [Vue](/vue),
                  [Angular](/angular), and [React Native](/react-native) guides for that setup.
                </Callout>
            </Step>

            <Accordion title="Troubleshooting">
                **Agent Connection Issues**
                - If the assistant does not reply, check the terminal of `npm run dev` for `ECONNREFUSED` (the agent is not running on port 8000) or a 401 from the model provider (API key). Make sure:
                  - The agent is running on port 8000
                  - Your OpenAI API key is set: in .NET user secrets for a .NET agent, or in the `.env` file of a Python agent
                  - Both servers started successfully (check terminal output)

                **OpenAI API Key Issues**
                - If the .NET agent fails with "OPENAI_API_KEY not found":
                  ```bash
                  cd agent
                  dotnet user-secrets set OPENAI_API_KEY "<your-openai-api-key>"
                  ```

                **.NET SDK Issues**
                - Verify .NET SDK is installed:
                  ```bash
                  dotnet --version  # Should be 9.0.x or higher
                  ```
                - Restore packages manually if needed:
                  ```bash
                  cd agent
                  dotnet restore
                  dotnet run
                  ```

                **Port Conflicts**
                - If port 8000 is already in use, change the port in both the agent and the frontend.
                - Starter project:
                  - .NET agent: `agent/Properties/launchSettings.json` - Update `applicationUrl`
                  - Python agent: `agent/.env` - Set `AGENT_PORT`
                  - Frontend: `.env` - Set `AGENT_URL` to the new agent URL (read in `src/agent.ts`)
                - Existing agent:
                  - .NET agent: `app.Run("http://localhost:8000")` in `Program.cs`
                  - Python agent: `uvicorn.run(..., port=8000)` in `main.py`
                  - Frontend: the `url` of `HttpAgent` in `app/api/copilotkit/[[...slug]]/route.ts`
            </Accordion>

## Next steps

The Microsoft Agent Framework runs your agent, with its tools and threads, in Python or .NET. CopilotKit puts that agent in your app, where your users can see the run, step in and steer it.

Add a capability:

- [Generative UI](/microsoft-agent-framework/generative-ui/tool-rendering): show the agent's tool calls and state as components that update while it runs.
- [Human-in-the-loop](/microsoft-agent-framework/human-in-the-loop): the agent pauses for a decision, or calls a tool in the browser, and resumes with the user's answer.
- [Shared state](/microsoft-agent-framework/shared-state): keep the agent's thread state and your app's state in sync, in both directions.
- [Frontend tools](/microsoft-agent-framework/frontend-tools): let the agent call tools that update your app directly.
- [And more](/microsoft-agent-framework/build-with-agents): chat surfaces, headless UI and multi-agent flows work with the Microsoft Agent Framework too. Give your AI coding agent current CopilotKit knowledge, so it can help you build them.

Go further:

- Live demos: try each capability with a Microsoft Agent Framework agent in [Python](/examples?framework=ms-agent-python), [.NET](/examples?framework=ms-agent-dotnet) or [Agent Harness for .NET](/examples?framework=ms-agent-harness-dotnet).
- Using Vue, Angular, or React Native? Pick it in the sidebar's **Frontend** menu. Its quickstart connects this agent.
