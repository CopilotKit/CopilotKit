title: Documentation Contributions
---

Fix a docs page: run the docs site locally, edit the page, and open a pull request.

## Prerequisites

- [Node.js](https://nodejs.org/en/) 20.x or later
- [pnpm](https://pnpm.io/) v10.x installed globally (`npm i -g pnpm@^10`)

## How To Contribute

<Steps>
  <Step>
  ### Fork The Repository

  First, head over to the [CopilotKit GitHub repository](https://github.com/CopilotKit/CopilotKit) and create a fork.

  Then, clone the forked repository to your local machine:

  ```shell
  git clone https://github.com/<your-username>/CopilotKit
  cd CopilotKit
  ```
  </Step>
  <Step>
  ### Run the Documentation Site Locally

  The docs site is a standalone npm app in `showcase/shell-docs`. Install its dependencies and the dependencies of `showcase/scripts`, then start the docs in development mode:

  ```shell
  cd showcase/scripts && npm install
  cd ../shell-docs && npm install
  npm run dev
  ```

  The docs site runs at [http://localhost:3003](http://localhost:3003).
  </Step>
  <Step>
  ### Make Your Changes

  Now, you can make your changes to the documentation website.

  - Documentation pages are under `showcase/shell-docs/src/content/` in this monorepo.
  - The docs site is built with [Fumadocs](https://fumadocs.dev/), and the pages are MDX files.

  <Callout type="info">
    Please review your changes for grammar, spelling and formatting errors. Also, make sure that links and images are working.
  </Callout>
  </Step>
  <Step>
  ### Review Changes & Submit Pull Request

  Once you are happy with your changes, you can commit and push them. Then, head over to the [Pull Requests page](https://github.com/CopilotKit/CopilotKit/pulls) and create a pull request. Thank you for your contribution.
  </Step>
</Steps>
