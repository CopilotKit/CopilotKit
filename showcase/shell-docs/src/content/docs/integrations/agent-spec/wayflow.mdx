## What is this?

Wire an Agent Spec agent backed by WayFlow to CopilotKit's UI via the AG-UI event protocol. You'll run a FastAPI endpoint that emits AG-UI events and point your Next.js app at it.

Key pieces:

- Backend endpoint: `ag-ui/integrations/agent-spec/python/ag_ui_agentspec/endpoint.py`
- Example server: `ag-ui/integrations/agent-spec/python/examples/server`
- Template UI: the [Agent Spec starter](https://github.com/CopilotKit/CopilotKit/tree/main/examples/integrations/agent-spec)

## When should I use this?

Use this integration when you already have a WayFlow-based agent described by an Agent Spec and want a turnkey UI that streams assistant text, tool calls/results, and run lifecycle with minimal wiring.

## Prerequisites

- Python 3.10 to 3.13
- Node.js 20+
- [uv](https://docs.astral.sh/uv/) (the starter UI's `npm install` runs `uv sync`)
- An OpenAI API key, or a key for another OpenAI-compatible endpoint

## Install runtime adapter

Install the published package with the `wayflow` extra, plus `uvicorn` to serve it:

```bash
pip install "ag-ui-agent-spec[wayflow]" uvicorn
```

This installs the Agent Spec AG-UI integration (`ag_ui_agentspec`). To install it from source instead, use the AG-UI repository:

```bash
git clone https://github.com/ag-ui-protocol/ag-ui.git
cd ag-ui/integrations/agent-spec/python
uv pip install -e .[wayflow]
```

## Steps

<Steps>

<Step>
### 1. Write your Agent Spec

Skip this step if you already have an Agent Spec file. Otherwise, create a minimal one with `pyagentspec`, which the package above installs:

```python title="make_agent.py"
import os

from pyagentspec.agent import Agent
from pyagentspec.llms import OpenAiCompatibleConfig
from pyagentspec.serialization import AgentSpecSerializer

agent = Agent(
    name="assistant",
    system_prompt="You are a helpful assistant.",
    llm_config=OpenAiCompatibleConfig(
        name="openai",
        model_id="gpt-6-luna",
        url=os.getenv("OPENAI_BASE_URL", "https://api.openai.com/v1"),
    ),
)

with open("agent.json", "w") as f:
    f.write(AgentSpecSerializer().to_json(agent))
```

```bash
python make_agent.py
```

This writes `agent.json` to the current folder. The agent reads your key from `OPENAI_API_KEY` when it runs.

</Step>

<Step>
### 2. Start a FastAPI endpoint

Use the WayFlow runtime to execute your Agent Spec and stream AG-UI events. For runtime options, see the [Agent Spec WayFlow adapter docs](https://oracle.github.io/agent-spec/26.1.0/adapters/wayflow/index.html).

```python title="backend/app.py"
from pathlib import Path

from fastapi import FastAPI
from ag_ui_agentspec.agent import AgentSpecAgent
from ag_ui_agentspec.endpoint import add_agentspec_fastapi_endpoint

# Your Agent Spec config, as a JSON or YAML string
agentspec_json = Path("agent.json").read_text()

app = FastAPI()
agent = AgentSpecAgent(agentspec_json, runtime="wayflow")
add_agentspec_fastapi_endpoint(app, agentspec_agent=agent, path="/")
```

Run the server from the folder that holds `agent.json` and `backend/`. `Path("agent.json")` is relative to that folder.

```bash
export OPENAI_API_KEY=sk-...
uvicorn backend.app:app --reload --port 8000
```

</Step>

<Step>
### 3. Run the starter UI

Copy the [Agent Spec starter](https://github.com/CopilotKit/CopilotKit/tree/main/examples/integrations/agent-spec) for the UI. The CopilotKit CLI has no Agent Spec template. In a second terminal:

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/CopilotKit/CopilotKit.git
cd CopilotKit
git sparse-checkout set examples/integrations/agent-spec
cp -r examples/integrations/agent-spec ../agent-spec-ui
cd ../agent-spec-ui
npm install
npm run dev:ui
```

<Callout type="warn">
Run `npm run dev:ui`, not `npm run dev`. `npm run dev` also starts the starter's own agent on port 8000. That agent collides with your server from step 2, and the UI stops.
</Callout>

The starter's Copilot Runtime sends chat requests to `AGENT_URL`, which defaults to `http://localhost:8000/`. Set `AGENT_URL` in `.env` only if your agent runs somewhere else.

Open `http://localhost:3000` and type a message in the chat. The agent's reply streams into the chat. The starter's suggestion chips (calendar, inbox) call tools that only the starter's own agent has, so type your own message.

</Step>

</Steps>

## Bind backend tools

If your Agent Spec declares server-side tools, map each tool name to a Python function in `tool_registry`:

```python title="backend/app.py"
from pathlib import Path
from typing import Any, Dict

from fastapi import FastAPI
from ag_ui_agentspec.agent import AgentSpecAgent
from ag_ui_agentspec.endpoint import add_agentspec_fastapi_endpoint

def get_weather(city: str) -> Dict[str, Any]:
    return {"city": city, "temp_c": 22}

agentspec_json = Path("agent.json").read_text()

app = FastAPI()
agent = AgentSpecAgent(
    agent_spec_config=agentspec_json,
    runtime="wayflow",
    tool_registry={"get_weather": get_weather},
)
add_agentspec_fastapi_endpoint(app, agentspec_agent=agent, path="/")
```

Frontend tools (Agent Spec `ClientTool`) run in the browser, so they do not go in `tool_registry`. See [Frontend Tools](/frontend-tools).

## How it works

- `AgentSpecAgent(runtime="wayflow")` executes your Agent Spec agent with the WayFlow framework.
- `AgUiSpanProcessor` maps Agent Spec tracing spans to AG-UI events on a per-request queue (`EVENT_QUEUE`).
- The FastAPI endpoint streams those events as SSE for CopilotKit to render. The event types come from the [AG-UI protocol](https://docs.ag-ui.com/introduction):
  - assistant text: `TEXT_MESSAGE_CHUNK`
  - tool calls: `TOOL_CALL_CHUNK` and `TOOL_CALL_RESULT`
  - lifecycle: `RUN_STARTED` and `RUN_FINISHED`

## Troubleshooting

- If the chat gets no reply, make sure that the runtime can reach the agent. In the starter, set `AGENT_URL` to the agent URL. The default is `http://localhost:8000/`.
- If you see `RuntimeError: AG-UI event queue is not set`, send requests through the route that `add_agentspec_fastapi_endpoint` registers. That route sets up the event queue for each request.
- If you are not receiving any events, make sure the agent is running and did not crash.
