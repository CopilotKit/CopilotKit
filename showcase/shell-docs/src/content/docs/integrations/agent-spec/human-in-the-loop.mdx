## What is this?

Some agent steps need a person's choice before the agent continues. A human-in-the-loop tool shows buttons in the chat and sends the user's pick back to the agent.

A human-in-the-loop tool is a frontend tool: the agent declares it, and the browser runs it. Frontend tools can also let [your agent control the UI](/frontend-tools) or show [generative UI](/generative-ui).

## When should I use this?

Use a human-in-the-loop tool when the agent must wait for a decision from the user. For tools that act in the browser without a person, see [Frontend Tools](/frontend-tools).

## Implementation

<Steps>
    <Step>
      ### Run and connect your agent
      <RunAndConnect />
    </Step>

    <Step>
        ### Create a frontend human-in-the-loop tool

        Register the tool with `useHumanInTheLoop`. Its `render` shows two buttons, and the user's click becomes the tool result.

        In this example, the agent offers two options and waits for the user to pick one.

        ```tsx title="page.tsx"
        import { useHumanInTheLoop } from "@copilotkit/react-core/v2" // [!code highlight]
        import { z } from "zod"

        export function Page() {
          // ...

          useHumanInTheLoop({
            name: "offerOptions",
            description: "Give the user a choice between two options and have them select one.",
            parameters: z.object({
              option_1: z.string().describe("The first option"),
              option_2: z.string().describe("The second option"),
            }),
            render: ({ args, respond }) => {
              if (!respond) return <></>;
              return (
                <div>
                  {/* [!code highlight:2] */}
                  <button onClick={() => respond(`${args.option_1} was selected`)}>{args.option_1}</button>
                  <button onClick={() => respond(`${args.option_2} was selected`)}>{args.option_2}</button>
                </div>
              );
            },
          });

          // ...
        }
        ```
    </Step>
    <Step>
        ### Set up your agent

        Declare the same tool as a `ClientTool` in your Agent Spec config. The name must match the `name` in `useHumanInTheLoop`:

        ```python title="agent.py"
        from pyagentspec.property import Property
        from pyagentspec.tools import ClientTool

        offer_options_tool = ClientTool(
            name="offerOptions",
            description="Give the user a choice between two options and have them select one.",
            inputs=[
                Property(title="option_1", json_schema={"title": "option_1", "type": "string"}),
                Property(title="option_2", json_schema={"title": "option_2", "type": "string"}),
            ],
        )
        ```

        Add `offer_options_tool` to the `tools` list of your `Agent`. The agent declares the tool, and the browser runs it.
    </Step>
    <Step>
        ### Try it out

        You've now given your agent the ability to show the user two options and have them select one. The agent will then be aware of the user's choice and can use it in subsequent steps.

        ```
        Can you show me two good options for a restaurant name?
        ```
    </Step>

</Steps>
