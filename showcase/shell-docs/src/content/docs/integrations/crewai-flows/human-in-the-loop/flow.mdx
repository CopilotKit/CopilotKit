## What this example does

The `crewai-flows` documentation route is backed by the `crewai-crews`
Showcase integration. In this demo, the model asks the browser to book a call.
The browser presents candidate time slots, returns the selected slot as a tool
result, and the next request resumes the flow with that result.

Start with the [CrewAI Flows quickstart](/crewai-flows/quickstart) to run the
agent and frontend together.

## Register the browser decision

Register a human-in-the-loop tool in the chat surface with
[`useHumanInTheLoop`](/reference/hooks/useHumanInTheLoop). The agent can call
`book_call`; the rendered time picker calls `respond` with the user's choice.

<Snippet framework="crewai-crews" cell="hitl-in-chat" region="hitl-hook" />

The fixed slots are demo data. Replace them with availability from your own
calendar or scheduling service before using this pattern in production.

## Let the flow resume from the tool result

The CrewAI flow passes CopilotKit's advertised browser actions to the model as
tools. When the model emits a frontend tool call, the flow records that message
and ends the request. CopilotKit executes the tool in the browser; its result
is included in the next request, which the flow streams normally.

## Try it

Ask the demo to schedule a call. Select a time in the card, then send the
choice. The agent receives the selection as the `book_call` tool result and
continues with a short confirmation.
