## What is this?

A Flow method can run for many seconds before its reply streams to the chat. During that time, the user sees nothing. Write a status to the Flow state and emit it with `copilotkit_emit_state`. Your UI shows the status while the method runs.

## When should I use this?

Use this when a method does slow work before it answers and you want to:

- Show that the agent is still working
- Show which step the method is on
- Show a warning before the reply arrives

        ### Run and Connect Your Agent to CopilotKit

    <Step>
        ### Install the packages
        ```bash
        pip install ag-ui-crewai litellm
        ```
    </Step>
    <Step>
        ### Emit a status from your Flow
        Add a `status` field to the state. Set it, then call `copilotkit_emit_state` to send the state to the UI at once.

        <Tabs groupId="language_crewai-flows_agent" items={['Python']} default="Python" persist>
            <Tab value="Python">
                ```python title="agent.py"
                import asyncio

                from crewai.flow.flow import Flow, start
                from litellm import acompletion
                from ag_ui_crewai import CopilotKitState, copilotkit_emit_state, copilotkit_stream # [!code highlight]


                class AgentState(CopilotKitState):
                    status: str = "" # [!code highlight]


                class StatusFlow(Flow[AgentState]):
                    @start()
                    async def chat(self) -> None:
                        # [!code highlight:2]
                        self.state.status = "Thinking really hard..."
                        await copilotkit_emit_state(self.state)

                        # simulate a long running task
                        await asyncio.sleep(2)

                        response = await copilotkit_stream(
                            await acompletion(
                                model="openai/gpt-5.4",
                                messages=[
                                    {"role": "system", "content": "You are a helpful assistant."},
                                    *self.state.messages,
                                ],
                                stream=True,
                            )
                        )
                        self.state.messages.append(response.choices[0].message)
                        self.state.status = ""
                ```
            </Tab>
        </Tabs>
    </Step>
    <Step>
        ### Show the status in your UI
        Read `status` from the agent state with `useAgent`. Use the agent ID that you registered in your runtime.

        ```tsx title="app/page.tsx"
        import { useAgent } from "@copilotkit/react-core/v2";

        export function AgentStatus() {
          const { agent } = useAgent({ agentId: "sample_agent" });
          const status = (agent.state as { status?: string } | undefined)?.status;

          if (!status) return null;
          return <p>{status}</p>;
        }
        ```
    </Step>
    <Step>
        ### Give it a try
        Send the agent a message. "Thinking really hard..." shows at once. About 2 seconds later, the reply streams into the chat and the status line goes away.
    </Step>

</Steps>
