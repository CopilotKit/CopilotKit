---
title: "Message Persistence"
icon: "lucide/Database"
---

To keep a Flow's conversation after a restart, store its state with CrewAI's `@persist` decorator. For example, use the default `SQLiteFlowPersistence` or your own persistence class.

<Callout>
  To learn about how to load previous messages and agent states, check out the
  [Loading Message History](/crewai-flows/persistence/loading-message-history)
  and [Loading Agent State](/crewai-flows/persistence/loading-agent-state)
  pages.
</Callout>

<Callout type="info" title="Conversational Flow sessions">
  CopilotKit's `threadId` becomes the CrewAI `session_id`, so CrewAI's
  `@persist` support stores and restores the corresponding conversational
  session. The chat history in the UI comes from the runtime's agent runner.
  For history that survives a server restart, use a durable runner (see
  [Agent runner](/backend/agent-runner)).
</Callout>

Read more about persistence in the [CrewAI Flows documentation](https://docs.crewai.com/concepts/flows#class-level-persistence).
