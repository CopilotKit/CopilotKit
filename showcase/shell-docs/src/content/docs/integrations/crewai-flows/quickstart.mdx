## Start with your coding agent

Use this prompt to connect your CrewAI agent to CopilotKit and verify a working conversation. Your coding agent will follow this guide in your project, or you can work through the manual steps below.

<PageAgentPrompt />

## Prerequisites

You need a [CrewAI Flow](https://docs.crewai.com/guides/flows/first-flow), or you can use the minimal Flow that the code-along path shows. The Flow runs locally. A CrewAI Enterprise deployment or a Copilot Cloud account is optional. If you use the CopilotKit CLI path below, the starter creates the Flow integration for you.

Both paths also need:

- Node.js 20.9+
- Python 3.10 to 3.13
- [uv](https://docs.astral.sh/uv/) (CLI path only; the code-along path uses `pip`)
- An OpenAI API key

            ### Create a Flow that replies in chat

            A Flow replies in the chat only through CopilotKit's helpers. A plain CrewAI Flow (an `@start` method that returns `LLM.call(...)`) runs without errors, but the chat shows nothing. Use `copilotkit_stream` to stream the reply, then append the reply to `self.state.messages` so it stays after the run ends:

            ```python title="flow.py"
            from crewai.flow.flow import Flow, start
            from litellm import acompletion
            from ag_ui_crewai import CopilotKitState, copilotkit_stream


            class YourFlow(Flow[CopilotKitState]):
                @start()
                async def chat(self) -> None:
                    response = await copilotkit_stream(
                        await acompletion(
                            model="openai/gpt-6-luna",
                            messages=[
                                {"role": "system", "content": "You are a helpful assistant."},
                                *self.state.messages,
                            ],
                            tools=[*self.state.copilotkit.actions],
                            stream=True,
                        )
                    )
                    self.state.messages.append(response.choices[0].message)
            ```

            `self.state.copilotkit.actions` holds the frontend tools that your app registers, so the model can call them.
        </Step>

        <Step>
            ### Expose your Flow as an AG-UI endpoint

            CopilotKit connects to agents over [AG-UI](https://docs.ag-ui.com), an open protocol that streams agent events to the frontend. A CrewAI Enterprise Live Automation URL or another plain CrewAI endpoint is not automatically AG-UI-compatible, even if it returns HTTP 200. Add the official CrewAI adapter to the service that hosts your Flow:

            ```bash title="Terminal"
            pip install -U "crewai>=1.15.11,<2" ag-ui-crewai fastapi uvicorn
            ```

            ```python title="server.py"
            from fastapi import FastAPI
            from ag_ui_crewai import add_crewai_flow_fastapi_endpoint

            from flow import YourFlow

            app = FastAPI()

            add_crewai_flow_fastapi_endpoint(app, YourFlow(), "/")
            ```

            Start the server in the folder that holds `flow.py` and `server.py`. The Flow reads `OPENAI_API_KEY` from the environment:

            ```bash title="Terminal"
            export OPENAI_API_KEY=your_openai_api_key
            uvicorn server:app --host 0.0.0.0 --port 8000
            ```
        </Step>

        <Step>
            ### Verify the AG-UI stream

            Before connecting the frontend, send one run directly to the endpoint from a second terminal:

            ```bash title="Terminal"
            export AG_UI_URL="http://127.0.0.1:8000/"

            curl --fail-with-body --no-buffer --include \
              --request POST "$AG_UI_URL" \
              --header "Content-Type: application/json" \
              --header "Accept: text/event-stream" \
              --data '{
                "threadId": "preflight-thread",
                "runId": "preflight-run",
                "messages": [
                  {
                    "id": "preflight-message",
                    "role": "user",
                    "content": "Say hello"
                  }
                ],
                "state": {},
                "tools": [],
                "context": [],
                "forwardedProps": {}
              }'
            ```

            A compatible response has a `Content-Type: text/event-stream` header and emits `RUN_STARTED`, at least one `TEXT_MESSAGE_CONTENT`, then `RUN_FINISHED`. If it returns a normal JSON response, emits `RUN_ERROR`, or has no `TEXT_MESSAGE_CONTENT`, fix the Flow first.
        </Step>

        <Step>
            ### Create your frontend

            CopilotKit works with any React app. This example uses Next.js App Router. In a new terminal:

            ```bash
            npx create-next-app@latest my-copilot-app --yes
            cd my-copilot-app
            npm install @copilotkit/react-core @copilotkit/runtime @ag-ui/client zod
            ```

            `--yes` uses the recommended defaults (TypeScript, Tailwind, App Router) and skips the prompts.

            `@ag-ui/client` must be the same version that `@copilotkit/runtime` uses. Two versions make TypeScript report that `HttpAgent` is not assignable to `AbstractAgent`. Run `npm ls @ag-ui/client`: the top-level copy must be the version that `@copilotkit/runtime` lists as `deduped`.
        </Step>

        <Step>
            ### Add the Copilot Runtime route

            The Copilot Runtime route registers your Flow as an AG-UI `HttpAgent` named `my_flow`:

            ```ts title="app/api/copilotkit/[[...slug]]/route.ts"
            import {
              CopilotRuntime,
              createCopilotRuntimeHandler,
            } from "@copilotkit/runtime/v2";
            import { HttpAgent } from "@ag-ui/client";

            const runtime = new CopilotRuntime({
              agents: {
                my_flow: new HttpAgent({
                  url: process.env.AGENT_URL ?? "http://127.0.0.1:8000/",
                }),
              },
            });

            const handler = createCopilotRuntimeHandler({
              runtime,
              basePath: "/api/copilotkit",
            });

            export const GET = handler;
            export const POST = handler;
            ```

            `AGENT_URL` is optional. Set it in `.env.local` when your Flow runs at another address. Use the path that you passed to `add_crewai_flow_fastapi_endpoint`.
        </Step>

        <Step>
            ### Set up the CopilotKit provider

            Replace `app/layout.tsx`. The provider points at the runtime route and selects the `my_flow` agent:

            ```tsx title="app/layout.tsx"
            import { Suspense } from "react";
            import { CopilotKit } from "@copilotkit/react-core/v2";
            import "@copilotkit/react-core/v2/styles.css";
            import "./globals.css";

            export default function RootLayout({ children }: { children: React.ReactNode }) {
              return (
                <html lang="en">
                  <body>
                    <Suspense>
                      <CopilotKit runtimeUrl="/api/copilotkit" agent="my_flow">
                        {children}
                      </CopilotKit>
                    </Suspense>
                  </body>
                </html>
              );
            }
            ```

            `<Suspense>` keeps `npm run build` working when `next.config.ts` sets `cacheComponents: true`, the `create-next-app` default in Next.js 16. Without it, the build fails with `encountered the unstable value require('node:crypto').randomUUID()`.
        </Step>

        <Step>
            ### Create a CrewAI Flow component

            Replace `app/page.tsx` with a chat that can also change the page background:

            ```tsx title="app/page.tsx"
            "use client";

            import { useState } from "react";
            import { z } from "zod";
            import { CopilotChat, useFrontendTool } from "@copilotkit/react-core/v2";

            export default function Page() {
              const [background, setBackground] = useState(
                "linear-gradient(135deg, #667eea 0%, #764ba2 100%)"
              );

              // Action: Allow AI to change background color dynamically
              useFrontendTool({
                name: "change_background",
                description:
                  "Change the background color of the chat. Can be anything that the CSS background attribute accepts. Regular colors, linear of radial gradients etc.",
                parameters: z.object({
                  background: z.string().describe("The background. Prefer gradients."),
                }),
                handler: async ({ background }) => {
                  setBackground(background);
                  return `Background changed to ${background}`;
                },
                followUp: false,
              });

              return (
                <div
                  className="h-screen w-full flex items-center justify-center"
                  style={{ background }}
                >
                  <div className="w-full max-w-3xl h-[80vh] px-4">
                    <div className="h-full bg-white/10 backdrop-blur-lg rounded-2xl shadow-2xl overflow-hidden">
                      <CopilotChat
                        className="h-full"
                        labels={{
                          welcomeMessageText: "Hi, I'm an agent. Want to chat?",
                          chatInputPlaceholder: "Type a message...",
                        }}
                      />
                    </div>
                  </div>
                </div>
              );
            }
            ```

            Start the app:

            ```bash
            npm run dev
            ```
        </Step>
        <Step>
            ### Talk to your agent

            Open `http://localhost:3000`. Your CrewAI Flow now answers in the chat. Try these:

            - Can you tell me a joke?
            - Can you help me understand AI?
            - Please change the background to blue.

            The last one calls the `change_background` frontend tool, and the page background changes.

            <Accordions className="mb-4">
                <Accordion title="Having trouble?">
                    - If the chat stays empty, run the **Verify the AG-UI stream** check again. A Flow that does not call `copilotkit_stream` emits no `TEXT_MESSAGE_CONTENT`.
                    - In the `HttpAgent` URL (or `AGENT_URL`), use `127.0.0.1` instead of `localhost`.
                </Accordion>
            </Accordions>
        </Step>

## Optional: Connect through Copilot Cloud

Copilot Cloud can host the runtime for you instead of the route above. It needs a Copilot Cloud sign-in and your Flow at a public HTTPS URL.

1. Deploy `server.py` to a public HTTPS URL. Run the **Verify the AG-UI stream** check against that URL.
2. Go to [Copilot Cloud](https://dashboard.operations.copilotkit.ai), sign in and click **Get Started**.
3. Click **Add Remote Endpoint** and enter the public AG-UI URL. If the agent name has more than one word, separate the words with underscores (`_`).
4. Click **Save Endpoint**, then copy the Copilot Cloud Public API Key.
5. Add both values to `.env.local`:

   ```plaintext title=".env.local"
   NEXT_PUBLIC_COPILOT_API_KEY=ck_pub_...
   NEXT_PUBLIC_COPILOTKIT_AGENT_NAME=my_flow
   ```

6. In `app/layout.tsx`, replace `runtimeUrl="/api/copilotkit" agent="my_flow"` with `publicApiKey={process.env.NEXT_PUBLIC_COPILOT_API_KEY} agent={process.env.NEXT_PUBLIC_COPILOTKIT_AGENT_NAME}`. Set the agent name to the one you entered in Copilot Cloud. You can then delete the runtime route.
