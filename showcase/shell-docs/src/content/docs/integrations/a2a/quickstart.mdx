## Start with your coding agent

Use this prompt to run the A2A starter with CopilotKit and verify a working conversation. The starter includes its own A2A agent. Your coding agent will follow this guide in your project, or you can work through the manual steps below.

<PageAgentPrompt />

## Prerequisites

Before you begin, you'll need the following:

- A Google Gemini API key
- Node.js 20+
- Python 3.13+
- [uv](https://docs.astral.sh/uv/)
- Your favorite package manager

## Getting started

<Steps>
    <Step>
        ### Set up CopilotKit Intelligence

        <SignupLink surface="docs_a2a_quickstart_step1">Sign in to cloud-hosted Intelligence</SignupLink>. Cloud-hosted setup uses a server-side project API key and does not issue `COPILOTKIT_LICENSE_TOKEN`. You will connect the app after you clone it below.
    </Step>

    <Step>
        ### Clone the A2A starter template

        The starter lives in the CopilotKit repository at `examples/integrations/a2a-a2ui`. Copy only that folder, then connect it to Intelligence:

        ```bash
        git clone --depth 1 --filter=blob:none --sparse https://github.com/CopilotKit/CopilotKit.git
        cd CopilotKit
        git sparse-checkout set examples/integrations/a2a-a2ui
        cp -r examples/integrations/a2a-a2ui ../my-a2a-app
        cd ../my-a2a-app
        npx copilotkit@latest project select
        ```

        `project select` creates or selects an Intelligence project and writes its server-side API key to `.env` as `CPK_INTELLIGENCE_API_KEY`. The runtime route reads it from there. Without the key, the starter runs with an in-memory runner instead.
    </Step>
    <Step>
        ### Install dependencies

        ```bash
        npm install
        ```

        `npm install` also runs `uv sync` in `agent/`, so `uv` must be on your `PATH`.
    </Step>
    <Step>
        ### Configure your environment

        Create a `.env` file in the `agent` directory and add your Gemini API key:

        ```plaintext title="agent/.env"
        GEMINI_API_KEY=your_gemini_api_key
        ```

        <Callout type="info" title="What about other models?">
          The starter template is configured to use Google's Gemini by default, but you can modify it to use any language model supported by ADK.
        </Callout>
    </Step>
    <Step>
        ### Start the development server

        <Tabs groupId="package-manager" items={['npm', 'pnpm', 'yarn', 'bun']}>
            <Tab value="npm">
                ```bash
                npm run dev
                ```
            </Tab>
            <Tab value="pnpm">
                ```bash
                pnpm dev
                ```
            </Tab>
            <Tab value="yarn">
                ```bash
                yarn dev
                ```
            </Tab>
            <Tab value="bun">
                ```bash
                bun dev
                ```
            </Tab>
        </Tabs>

        This starts the UI and the agent server together.
    </Step>
    <Step>
        ### Start chatting

        Your AI agent is now ready to use. Navigate to `localhost:3000` and start prompting it:

        ```
        Show me chinese restaurants in NYC
        ```

        <Accordions className="mb-4">
            <Accordion title="Troubleshooting">
                - If you're having connection issues, use `127.0.0.1` instead of `localhost` in the agent URL
                - Make sure your agent is running on port 10002
                - Check that `GEMINI_API_KEY` is set in `agent/.env`
            </Accordion>
        </Accordions>

    </Step>

    <Step>
        <OpenInspectorStep components={props.components} />
    </Step>


</Steps>
