One of the most common use cases for CopilotKit is to register app state and context using `useAgentContext`.
This way, you can notify CopilotKit of what is going in your app in real time.
Some examples might be: the current user, the current page, etc.

This context can then be shared with your AG2 backend. With AG2 1.1.2 or newer, `AGUIStream` already hands every `useAgentContext` entry to the model, so a plain AG-UI endpoint needs no extra code. On AG2 1.0.x the entries never reach the model, so upgrade first.

## Implementation
<Callout>
    Check out the [Frontend Data documentation](/langgraph/agent-app-context) to understand what this is and how to use it.
</Callout>

<Callout type="info">
  CopilotKit consumes AG-UI protocol events streamed by AG2 over <code>/chat</code>. See the <a href="https://docs.ag2.ai/docs/user-guide/ag-ui/" target="_blank">AG2 AG-UI integration docs</a>.
</Callout>

            <Step>
                ### Add the data to the Copilot

                The [`useAgentContext` hook](/reference/v2/hooks/useAgentContext) is used to add data as context to the Copilot.

                ```tsx title="YourComponent.tsx" showLineNumbers {1, 7-10}
                "use client" // only necessary if you are using Next.js with the App Router. // [!code highlight]
                import { useAgentContext } from "@copilotkit/react-core/v2"; // [!code highlight]
                import { useState } from 'react';

                export function YourComponent() {
                  const [colleagues, setColleagues] = useState([
                    { id: 1, name: "John Doe", role: "Developer" },
                    { id: 2, name: "Jane Smith", role: "Designer" },
                    { id: 3, name: "Bob Wilson", role: "Product Manager" }
                  ]);

                  // [!code highlight:4]
                  useAgentContext({
                    description: "The current user's colleagues",
                    value: colleagues,
                  });
                  return (
                    <>...</>
                  );
                }
                ```
            </Step>

            <Step>
                ### Serve your agent as usual
                Entries sent in `RunAgentInput.context` are added to the run's system prompt, after the agent's own prompt, as one block:

                ```text
                ## Context from the application

                - The current user's colleagues: [{"id":1,"name":"John Doe","role":"Developer"}, ...]
                ```

                Each line is the entry's `description`, then its `value` exactly as the client sent it. The block is prose for the model, not variables: tool code does not see it. Your endpoint stays the plain one from the [quickstart](/ag2/quickstart):

                ```python title="agent.py"
                from fastapi import FastAPI, Header
                from fastapi.responses import StreamingResponse

                from ag2 import Agent
                from ag2.ag_ui import AGUIStream, RunAgentInput
                from ag2.config import OpenAIResponsesConfig

                agent = Agent(
                    name="assistant",
                    prompt="You are a helpful assistant that can help emailing colleagues.",
                    config=OpenAIResponsesConfig(model="gpt-5.5"),
                )

                stream = AGUIStream(agent)
                app = FastAPI()

                @app.post("/chat")
                async def run_agent(
                    message: RunAgentInput,
                    accept: str | None = Header(None),
                ) -> StreamingResponse:
                    return StreamingResponse(
                        stream.dispatch(message, accept=accept),
                        media_type=accept or "text/event-stream",
                    )
                ```

                Don't add the readables to `dispatch(prompt=...)` yourself: that would repeat them, and `prompt=` replaces the agent's own prompt rather than adding to it.
            </Step>

            <Step>
                ### Customize the block (optional)
                Pass `context_prompt=` to `dispatch` to render the entries differently. It receives the entries and returns the block, or `None` to leave them out:

                ```python title="agent.py"
                def colleagues_only(entries):
                    lines = [f"- {e.value}" for e in entries if "colleagues" in e.description]
                    return "## Colleagues\n\n" + "\n".join(lines) if lines else None

                stream.dispatch(message, accept=accept, context_prompt=colleagues_only)
                ```
            </Step>

            <Step>
                ### Give it a try
                Ask your agent a question about the context. It should be able to answer.
            </Step>
        </Steps>

            <Step>
                ### Pass the readable into the run as a variable
                The prompt block is only prose. To give a tool the value itself, decode the entry from `RunAgentInput.context` and pass it as a conversation variable. The `Variable()` annotation injects it into the tool without the LLM having to pass it around.

                ```python title="agent.py"
                import json
                from typing import Annotated

                from fastapi import FastAPI, Header
                from fastapi.responses import StreamingResponse

                from ag2 import Agent, Variable, tool
                from ag2.ag_ui import AGUIStream, RunAgentInput
                from ag2.config import OpenAIResponsesConfig

                def get_readable(message: RunAgentInput, description: str):
                    raw = next(
                        (item.value for item in message.context if item.description == description),
                        None,
                    )
                    if raw is None:
                        return None
                    # `useAgentContext` JSON-encodes objects and arrays, but passes a
                    # plain string through untouched — so decoding is best-effort.
                    try:
                        return json.loads(raw)
                    except json.JSONDecodeError:
                        return raw

                @tool
                def get_colleagues(
                    colleagues: Annotated[list, Variable(default_factory=list)],
                ) -> list:
                    """Return the current user's colleagues from CopilotKit readables."""
                    return colleagues

                agent = Agent(
                    name="assistant",
                    prompt="You are a helpful assistant that can help emailing colleagues.",
                    config=OpenAIResponsesConfig(model="gpt-5.5"),
                    tools=[get_colleagues],
                )

                stream = AGUIStream(agent)
                app = FastAPI()

                @app.post("/chat")
                async def run_agent(
                    message: RunAgentInput,
                    accept: str | None = Header(None),
                ) -> StreamingResponse:
                    colleagues = get_readable(message, "The current user's colleagues") or []
                    return StreamingResponse(
                        stream.dispatch(message, variables={"colleagues": colleagues}, accept=accept),
                        media_type=accept or "text/event-stream",
                    )
                ```

                <Callout type="warn">
                    Everything in `dispatch(variables=...)` is sent back to the browser in `STATE_SNAPSHOT`. Don't put secrets there; pass them through `dispatch(dependencies=...)`, which never leaves the server.
                </Callout>
            </Step>

            <Step>
                ### Give it a try
                Ask your agent to suggest recipients. It should call `get_colleagues`.
            </Step>
