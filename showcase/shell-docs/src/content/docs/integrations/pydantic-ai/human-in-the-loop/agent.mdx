## What is this?

The agent drafts an essay, then calls a frontend tool to show that draft to the user. The tool waits for the user's decision before the agent continues.

## Why should I use this?

Human-in-the-loop is a powerful way to implement complex workflows that are production ready. By having a human in the loop,
you can ensure that the agent is always making the right decisions and ultimately is being steered in the right direction.

Use this pattern when the agent must wait for approval before continuing with a draft.

## Implementation

<Steps>
    <Step>
        ### Run and connect your agent

        You'll need to run your agent and connect it to CopilotKit before proceeding. If you haven't done so already,
        you can follow the instructions in the [Getting Started](/pydantic-ai/quickstart) guide.

        If you don't already have an agent, you can use the [Pydantic AI starter](https://github.com/CopilotKit/CopilotKit/tree/main/examples/integrations/pydantic-ai) as a starting point
        as this guide uses it as a starting point.
    </Step>

    <Step>
        ### Add a human-in-the-loop tool to your frontend
        Mount this component inside your `CopilotKit` provider alongside your chat UI. The agent passes the complete essay as `draft`. The tool does not return a result until the user chooses a button.

        ```tsx title="ui/app/essay-approval.tsx"
        "use client";

        import { useHumanInTheLoop } from "@copilotkit/react-core/v2";
        import { z } from "zod";

        export function EssayApproval() {
          useHumanInTheLoop({
            name: "write_essay",
            description: "Show an essay draft to the user and wait for approval or a request to revise it.",
            parameters: z.object({
              draft: z.string().describe("The complete essay draft for the user to review"),
            }),
            render: ({ args, respond }) => (
              <div>
                <p className="whitespace-pre-wrap">{args.draft || "Preparing your draft..."}</p>
                {respond && (
                  <div className="flex gap-4 pt-4">
                    <button onClick={() => respond("CANCEL")} className="border p-2 rounded-xl w-full">
                      Try Again
                    </button>
                    <button onClick={() => respond("SEND")} className="bg-blue-500 text-white p-2 rounded-xl w-full">
                      Approve Draft
                    </button>
                  </div>
                )}
              </div>
            ),
          });

          return null;
        }
        ```
    </Step>

    <Step>
    ### Setup the Pydantic AI Agent
    Pydantic AI receives frontend tools through the AG-UI request. Do not declare a backend tool named `write_essay`: the frontend owns that name and waits for the user's response. The agent should draft the essay itself, then call the frontend tool with the draft.

    <Tabs groupId="language" items={["Python"]}>
      <Tab value="Python">
        ```python title="agent/sample_agent/agent.py"
        from pydantic_ai import Agent
        from pydantic_ai.ui.ag_ui import AGUIAdapter
        from starlette.applications import Starlette
        from starlette.requests import Request
        from starlette.responses import Response
        from starlette.routing import Route

        agent = Agent(
            'openai:gpt-5.4-mini',
            instructions=(
                "When asked for an essay, write the complete draft and call the frontend "
                "write_essay tool with that draft. Wait for its result. If it returns "
                "CANCEL, revise the draft and ask again. If it returns SEND, confirm "
                "that the draft was approved."
            ),
        )


        async def run_agent(request: Request) -> Response:
            return await AGUIAdapter.dispatch_request(request, agent=agent)


        app = Starlette(routes=[Route("/", run_agent, methods=["POST"])])
        ```
      </Tab>
    </Tabs>
    </Step>
    <Step>
        ### Give it a try!
        Try asking your agent to write an essay about the benefits of AI. The draft appears in the approval card. Approve Draft returns `SEND`; Try Again returns `CANCEL` so the agent can revise it.
    </Step>

</Steps>
