---
title: "Step 1: Run the example"
---

<Steps>
<Step>
### Clone the current repository

```shell
git clone https://github.com/CopilotKit/CopilotKit.git
cd CopilotKit
pnpm install
```

The completed v2 example lives at `examples/showcases/travel`. Its main parts
are:

- `app/`: the Next.js page and v2 runtime route
- `components/`: the map, chat UI, and approval cards
- `lib/`: shared agent state, types, and React hooks
- `agent/`: the Python LangGraph agent and AG-UI server

</Step>
<Step>
### Install the agent

From the repository root, install the Python dependencies with the example's
script:

```shell
cd examples/showcases/travel
pnpm install:agent
```

The script runs `uv sync` in the `agent/` directory.

</Step>
<Step>
### Add the API keys

Create `agent/.env` inside the travel example:

```txt title="examples/showcases/travel/agent/.env"
OPENAI_API_KEY=<your-openai-api-key>
GOOGLE_MAPS_API_KEY=<your-google-maps-api-key>
```

You can get an OpenAI key from the [OpenAI API dashboard](https://platform.openai.com/api-keys)
and a Google Maps key from the [Google Maps Platform guide](https://developers.google.com/maps/documentation/places/web-service/get-api-key#creating-api-keys).

</Step>
<Step>
### Start the app and agent

Run this command from `examples/showcases/travel`:

```shell
pnpm dev
```

This starts the Next.js app on [http://localhost:3000](http://localhost:3000)
and the agent on port `8000`. Open the app and ask it to plan a trip.

</Step>
</Steps>

Next, tour the LangGraph agent that powers the example.
