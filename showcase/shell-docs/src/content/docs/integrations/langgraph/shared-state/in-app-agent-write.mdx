## What you'll build

A two-way shared-state loop between your UI and a LangGraph agent:

- The UI writes a `preferences` object into agent state with `agent.setState`. The agent reads those preferences on every turn and adapts its replies.
- The agent writes a `notes` list into agent state with its `set_notes` tool. The UI re-renders the notes as soon as they change.

## Prerequisites

- A LangGraph agent served through the CopilotKit runtime. If you don't have one yet, start with the [quickstart](/quickstart).
- `@copilotkit/react-core` in your frontend. The hooks on this page come from `@copilotkit/react-core/v2`.
- The CopilotKit SDK for your agent's language: `copilotkit` for Python or `@copilotkit/sdk-js` for TypeScript.

## Implementation

<Steps>
  <Step>
    ### Declare the shared state

    Give the agent state a `preferences` field for the UI to write and a `notes` field for the agent to write. Register the notes tool and the preference reader from the next two steps with your agent. In a custom graph, bind the tool to your model and route its calls through a `ToolNode`.

    <Snippet region="shared-state-setup" />
  </Step>
  <Step>
    ### Let the agent write notes

    `set_notes` returns a LangGraph `Command`. The command replaces `notes` in agent state and answers the tool call with a `ToolMessage`. The tool replaces the previous value, so the model must pass the full list every time.

    <Snippet region="set-notes-tool" />
  </Step>
  <Step>
    ### Pass UI-written preferences to the model

    Read `preferences` from agent state before each model call and put a system message that describes them in front of the conversation. A `create_agent` agent does this in middleware. A custom graph does it in its chat node.

    <Snippet region="preferences-injector" />
  </Step>
  <Step>
    ### Subscribe to agent state in the UI

    Call [useAgent](/reference/hooks/useAgent) with `UseAgentUpdate.OnStateChanged`. The component re-renders whenever the agent changes its state, for example after a `set_notes` call. Read the values from `agent.state`.

    <Snippet region="use-agent-read" />
  </Step>
  <Step>
    ### Write preferences from the UI

    Call `agent.setState` from an event handler. Spread the current state into the new value so that the write keeps the agent's `notes`. The agent reads the new preferences on its next run. To start a run right after the write, call `agent.runAgent()`.

    <Snippet region="use-agent-write" />
  </Step>
  <Step>
    ### Test it

    Set a name and a tone in **Your preferences**. Then pick the **Remember something** suggestion, or ask the agent to remember a detail about you. The reply should use your name and tone, and the new note should appear in the notes card.
  </Step>
</Steps>
