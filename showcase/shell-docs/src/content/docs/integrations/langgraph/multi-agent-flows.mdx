## What are Multi-Agent Flows?

When building agentic applications, you often want to orchestrate complex flows together that require the coordination of multiple
agents. This is traditionally called multi-agent orchestration.

## When should I use this?

Multi-agent flows are useful when you want to orchestrate complex flows together that require the coordination of multiple agents. As
your agentic application grows, delegation of sub-tasks to other agents can help you scale key pieces of your application.

- Divide context into smaller chunks
- Delegate sub-tasks to other agents
- Use a single agent to orchestrate the flow

## How does CopilotKit support this?

Register each agent on your `CopilotRuntime` under its own name. Each chat and each `useAgent` call then talks to one agent, chosen by `agentId`.

### Default agent

If you omit `agentId`, CopilotKit uses the agent registered as `default`:

```tsx
import { CopilotKitProvider } from "@copilotkit/react-core";

export function Providers({ children }: { children: React.ReactNode }) {
  return (
    <CopilotKitProvider runtimeUrl="/api/copilotkit">
      {children}
    </CopilotKitProvider>
  );
}
```

### Choosing an agent

To work with a specific agent, set the `agentId` prop on the `CopilotKitProvider` component:

```tsx
import { CopilotKitProvider } from "@copilotkit/react-core";

export function Providers({ children }: { children: React.ReactNode }) {
  return (
    // [!code word:agentId]
    <CopilotKitProvider runtimeUrl="/api/copilotkit" agentId="the-name-of-the-agent">
      {children}
    </CopilotKitProvider>
  );
}
```

In this mode, CopilotKit is configured to work exclusively with a specific agent. All requests stay within a single workflow graph, ensuring precise control over the workflow.

You can also use different agents in different areas of your app. A `<CopilotChat agentId="...">` or a `useAgent({ agentId: "..." })` call overrides the provider's agent for that part of the UI. For example, you may want a general chatbot in one place and one specific agent elsewhere for a more focused workflow.
