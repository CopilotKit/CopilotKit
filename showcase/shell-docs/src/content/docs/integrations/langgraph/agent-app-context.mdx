## What you'll build

A LangGraph agent that answers with values your UI owns, such as the current user's name, timezone, and recent activity. The UI publishes the values with `useAgentContext`. The agent reads them on every run, but it has no setter or tool that can change them.

Use this for inputs that belong to the UI. When the agent also needs to write a value back, use [shared state](/shared-state/in-app-agent-write) instead.

## Prerequisites

- A LangGraph agent served through the CopilotKit runtime. If you don't have one yet, start with the [quickstart](/quickstart).
- `@copilotkit/react-core` in your frontend. The hooks on this page come from `@copilotkit/react-core/v2`.
- The CopilotKit SDK for your agent's language: `copilotkit` for Python or `@copilotkit/sdk-js` for TypeScript.

## Implementation

<Steps>
  <Step>
    ### Keep the values in your UI

    The values stay in ordinary React state under the `CopilotKit` provider. In your app they can come from an auth provider, a router hook, or a store.

    <Snippet region="context-provider-sketch" />
  </Step>
  <Step>
    ### Publish each value with useAgentContext

    Call [useAgentContext](/reference/hooks/useAgentContext) once for each value. The `description` tells the model what the value means. The entry updates when the value changes and is removed when the component unmounts.

    <Snippet region="use-agent-context-call" />

    <AgentContextJsonString />
  </Step>
  <Step>
    ### Read the context in your LangGraph agent

    CopilotKit sends the registered entries with every run. Each entry has a `description` and a `value`. A `create_agent` agent gets the entries through `CopilotKitMiddleware`, which adds them to the model call. A custom graph reads them from `state.copilotkit.context` and adds them to the prompt itself.

    The CopilotKit state key is lowercase `copilotkit` in both Python and TypeScript. In TypeScript, read `state.copilotkit.context`. The SDK's state schema doesn't define a `copilotKit` field.

    <Snippet region="agent-context-setup" />

    <WhenFrameworkHas flag="language" equals="python">
      If you build a custom `StateGraph` instead, extend `CopilotKitState` and read the entries from `state["copilotkit"]["context"]`. Parse each entry's `value` with `json.loads` before you read its fields. Use `create_agent` for the middleware approach. The deprecated `create_react_agent` doesn't accept `middleware=`.
    </WhenFrameworkHas>

    <WhenFrameworkHas flag="language" equals="typescript">
      If you use `createAgent` from `langchain` instead of a custom graph, add `copilotkitMiddleware` from `@copilotkit/sdk-js/langgraph` to its `middleware` list. The middleware adds the entries to the model call for you.
    </WhenFrameworkHas>
  </Step>
  <Step>
    ### Test it

    Change the name or the timezone in the demo, then pick the **Who am I?** suggestion. The answer should use the current values. Then ask the agent to change your name. The value in the UI should stay the same, because the agent has no way to write it.
  </Step>
</Steps>
