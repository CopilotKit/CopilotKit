<Callout type="info">
  A Mastra tool can pause with `suspend()`. The `@ag-ui/mastra` bridge sends the pause to your frontend as an AG-UI interrupt, and `useInterrupt` renders it.

  If the work can run in the browser, use the [tool-based approach](/mastra/human-in-the-loop/tool-based) with `useHumanInTheLoop` instead.
</Callout>

## What are interrupts?

In LangGraph and Mastra, a tool can pause with `interrupt()` or `suspend()`. The agent then sends an AG-UI interrupt event to the frontend. The run waits for the answer of the user, then continues. CopilotKit's `useInterrupt` hook receives these events and renders your UI.

## How does Mastra raise an interrupt?

Return `suspend()` from the tool's `execute` function. The `@ag-ui/mastra` bridge sends the pause as an AG-UI interrupt. When the user answers, Mastra runs `execute` again with the answer in `resumeData`. Resume needs `storage` on your `Mastra` instance.

```ts title="src/mastra/tools/schedule-meeting.ts"
import { createTool } from "@mastra/core/tools";
import { z } from "zod";

export const scheduleMeeting = createTool({
  id: "schedule_meeting",
  description: "Ask the user to pick a meeting time.",
  inputSchema: z.object({ topic: z.string() }),
  suspendSchema: z.object({ topic: z.string() }),
  resumeSchema: z.object({
    chosen_time: z.string().optional(),
    cancelled: z.boolean().optional(),
  }),
  execute: async (inputData, context) => {
    const { suspend, resumeData } = context?.agent ?? {};
    if (resumeData) {
      return resumeData.cancelled
        ? "The user cancelled."
        : `Scheduled "${inputData.topic}" for ${resumeData.chosen_time}.`;
    }
    // Return suspend() directly, so the agent pauses here.
    return suspend?.({ topic: inputData.topic });
  },
});
```

In the frontend, `useInterrupt` renders the pause. The bridge puts your `suspend()` payload in `interrupt.metadata.mastra.suspendPayload`. `resolve()` resumes the tool:

```tsx title="ui/app/page.tsx"
import { useInterrupt } from "@copilotkit/react-core/v2";

function YourMainContent() {
  useInterrupt({
    render: ({ interrupt, event, resolve }) => {
      // With emitInterruptOutcome: false, only the legacy event arrives, as a JSON string.
      const payload = interrupt
        ? interrupt.metadata?.mastra?.suspendPayload
        : JSON.parse(event.value).suspendPayload;
      return (
        <div>
          <p>Pick a time for {payload?.topic}</p>
          <button onClick={() => resolve({ chosen_time: "Tomorrow 10:00 AM" })}>
            Tomorrow 10:00 AM
          </button>
          <button onClick={() => resolve({ cancelled: true })}>Cancel</button>
        </div>
      );
    },
  });

  return <div>{/* Your UI */}</div>;
}
```

Register `scheduleMeeting` in the `tools` of your agent. Then ask the agent to schedule a meeting about the roadmap. The chat shows your time picker. Click **Tomorrow 10:00 AM**, and the agent replies that the meeting is scheduled.

## What should I use instead?

If the work can run in the browser, use the [tool-based approach](/mastra/human-in-the-loop/tool-based) with `useHumanInTheLoop`. The agent calls a frontend tool, so you need no backend tool and no `suspend()`.

## Comparison: Interrupts vs. Tool-based

| Feature | Interrupts | Tool-based |
|---------|------------|------------|
| **Backend** | The tool returns `suspend()` | No backend tool |
| **Frontend hook** | `useInterrupt` | `useHumanInTheLoop` |
| **Execution model** | Tool pauses mid-execution | Agent calls frontend tool |
| **When to use** | The tool runs on the server | The work runs in the browser |
