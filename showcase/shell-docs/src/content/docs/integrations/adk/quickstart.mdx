## Start with your coding agent

Use this prompt to connect your Google ADK agent to CopilotKit and verify a working conversation. Your coding agent will follow this guide in your project, or you can work through the manual steps below.

<PageAgentPrompt />

## Prerequisites

Before you begin, you'll need the following:

- A Google Gemini API key
- Node.js 20+
- Python 3.12+
- [uv](https://docs.astral.sh/uv/)
- Your favorite package manager

            <Step>
                ### Initialize your agent project

                If you don't already have a Python project set up, create one using `uv`:

                ```bash
                uv init my-agent
                cd my-agent
                ```
            </Step>
            <Step>
                ### Install ADK with AG-UI

                Add ADK with AG-UI support and uvicorn to your project:

                ```bash
                uv add ag-ui-adk google-adk uvicorn fastapi
                ```

                <Callout type="info" title="What is AG-UI?">
                  AG-UI is an open protocol for frontend-agent communication. The `ag-ui-adk` package provides ADK integration that CopilotKit can connect to.
                </Callout>
            </Step>
            <Step>
                ### Configure your environment

                Set your Google API key as an environment variable:

                ```bash
                export GOOGLE_API_KEY=your_google_api_key
                ```

                <Callout type="info" title="What about other models?">
                  This example uses Gemini 3.8 Flash, but you can modify it to use any language model supported by ADK.
                </Callout>
            </Step>
            <Step>
                ### Expose your agent via AG-UI

                Update your agent file to expose it as an AG-UI ASGI application:

                ```python title="main.py"
                from fastapi import FastAPI
                from ag_ui_adk import ADKAgent, add_adk_fastapi_endpoint
                from google.adk.agents import LlmAgent

                agent = LlmAgent(
                    name="assistant",
                    model="gemini-3.8-flash",
                    instruction="Be helpful and fun!"
                )

                adk_agent = ADKAgent(
                    adk_agent=agent,
                    app_name="demo_app",
                    user_id="demo_user",
                    session_timeout_seconds=3600,
                    use_in_memory_services=True
                )

                app = FastAPI()
                add_adk_fastapi_endpoint(app, adk_agent, path="/")

                if __name__ == "__main__":
                    import uvicorn
                    uvicorn.run(app, host="localhost", port=8000)
                ```
            </Step>
            <Step>
                ### Create your frontend

                CopilotKit works with any React-based frontend. This example uses Next.js.

                Run this from the folder that contains `my-agent`, not from inside it:

                ```bash
                cd ..
                npx create-next-app@latest my-copilot-app
                cd my-copilot-app
                ```
            </Step>
            <Step>
                ### Install CopilotKit packages

                ```npm
                npm install @copilotkit/react-core @copilotkit/runtime @ag-ui/client
                ```

                `@ag-ui/client` must be the same version that `@copilotkit/runtime` uses. Two versions make TypeScript report that `HttpAgent` is not assignable to `AbstractAgent`. Run `npm ls @ag-ui/client` to check that only one version is installed.
            </Step>
            <Step>
                ### Setup Copilot Runtime

                Create an API route to connect CopilotKit to your ADK agent:

                ```tsx title="app/api/copilotkit/[[...slug]]/route.ts" doctest="component"
                import {
                  CopilotRuntime,
                  createCopilotRuntimeHandler,
                } from "@copilotkit/runtime/v2";
                import { HttpAgent } from "@ag-ui/client";

                const runtime = new CopilotRuntime({
                  agents: {
                    my_agent: new HttpAgent({ url: "http://localhost:8000/" }),
                  },
                });

                const handler = createCopilotRuntimeHandler({
                  runtime,
                  basePath: "/api/copilotkit",
                });

                export const GET = handler;
                export const POST = handler;
                export const PATCH = handler;
                export const DELETE = handler;
                ```

                This route runs with an in-memory runner. Chat and the Inspector work without any key.

                <Accordions className="mb-4">
                    <Accordion title="Optional: connect CopilotKit Intelligence">
                        From this frontend app directory, sign in and select an Intelligence project:

                        ```bash title="Terminal"
                        npx copilotkit@latest login
                        npx copilotkit@latest project select
                        ```

                        `login` opens a browser sign-in. `project select` writes the server-side project API key to `.env`:

                        ```plaintext title=".env"
                        CPK_INTELLIGENCE_API_KEY=cpk-...
                        ```

                        Then add `CopilotKitIntelligence` to the imports and these two options to `new CopilotRuntime({ ... })`:

                        ```ts
                        intelligence: new CopilotKitIntelligence({
                          apiKey: process.env.CPK_INTELLIGENCE_API_KEY!,
                        }),
                        // Threads are per-user. Without this, every visitor shares one history.
                        identifyUser: (request) => ({
                          id: request.headers.get("x-user-id") ?? "anonymous",
                          name: request.headers.get("x-user-name") ?? "Anonymous",
                        }),
                        ```

                        Without the key, the route fails when it loads, with an error that the `CopilotKitIntelligence` `apiKey` is required. See [Connect your runtime to Intelligence](/intelligence/quickstart) to confirm the key is in use.
                    </Accordion>
                </Accordions>
            </Step>
            <Step>
                ### Configure CopilotKit Provider

                Wrap your application with the CopilotKit provider:

                ```tsx title="app/providers.tsx"
                "use client";

                import { CopilotKit } from "@copilotkit/react-core/v2";

                export function Providers({ children }: { children: React.ReactNode }) {
                  return (
                    <CopilotKit runtimeUrl="/api/copilotkit" agent="my_agent" useSingleEndpoint={false}>
                      {children}
                    </CopilotKit>
                  );
                }
                ```

                Render `Providers` in `app/layout.tsx`:

                ```tsx title="app/layout.tsx"
                import { Providers } from "./providers"; // [!code highlight]
                import "@copilotkit/react-core/v2/styles.css";
                import './globals.css';

                // ...

                export default function RootLayout({ children }: {children: React.ReactNode}) {
                  return (
                    <html lang="en">
                      <body>
                        {/* [!code highlight:3] */}
                        <Providers>
                          {children}
                        </Providers>
                      </body>
                    </html>
                  );
                }
                ```

                <Callout type="warn" title="Next.js 16 with Cache Components">
                  If `next.config.ts` sets `cacheComponents: true` (the `create-next-app` default in Next.js 16),
                  `npm run build` fails with `encountered the unstable value require('node:crypto').randomUUID()`.
                  Wrap `<Providers>` in `<Suspense>` from `react` in `app/layout.tsx`:
                  `<Suspense><Providers>{children}</Providers></Suspense>`.
                </Callout>

                Not using Next.js? See [React SPA](/react-spa), [Vue](/vue), [Angular](/angular), or [React Native](/react-native).
            </Step>
            <Step>
              ### Add the chat interface

              Add the CopilotSidebar component to your page:

              ```tsx title="app/page.tsx"
              "use client"; // [!code highlight]

              import { CopilotSidebar } from "@copilotkit/react-core/v2"; // [!code highlight:1]

              export default function Page() {
                return (
                  <main>
                    <h1>Your App</h1>
                    {/* [!code highlight:1] */}
                    <CopilotSidebar />
                  </main>
                );
              }
              ```
            </Step>
            <Step>
                ### Start your agent

                From your agent directory, start the agent server:

                ```bash

                ```

                Your agent will be available at `http://localhost:8000`.


## Next steps

ADK runs your agent, with its tools and sessions. CopilotKit puts that agent in your app, where your users can see the run, step in and steer it.

Add a capability:

- [Generative UI](/adk/generative-ui/tool-rendering): show the agent's tool calls and state as components that update while it runs.
- [Human-in-the-loop](/adk/human-in-the-loop): with `AGUIToolset()`, the agent asks the user for a decision and waits for the answer.
- [Shared state](/adk/shared-state): keep ADK session state and your app's state in sync, in both directions.
- [Frontend tools](/adk/frontend-tools): let the agent call tools that update your app directly.
- [And more](/adk/build-with-agents): chat surfaces, headless UI and multi-agent flows.

Go further:

- [Live demos](https://feature-viewer.copilotkit.ai/adk/feature/agentic_chat): try each capability with an ADK agent.
- [Import ADK sessions](/google-adk/threads-import): bring sessions from an ADK database or Vertex AI Agent Engine into [CopilotKit Intelligence](/intelligence/overview) as threads.
- Using Vue, Angular, or React Native? Pick it in the sidebar's **Frontend** menu. Its quickstart connects this agent.
