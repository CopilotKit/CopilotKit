To change the model, import a different provider adapter and pass it to the agent. With TanStack AI, the provider package gives you a text adapter. With the AI SDK, it gives you a model.

## Pick a provider

<Tabs groupId="agent-sdk" items={['TanStack AI', 'AI SDK']}>
<Tab value="TanStack AI">

| Provider | Package | Adapter | API key variable |
| --- | --- | --- | --- |
| OpenAI | `@tanstack/ai-openai` | `openaiText` | `OPENAI_API_KEY` |
| Anthropic | `@tanstack/ai-anthropic` | `anthropicText` | `ANTHROPIC_API_KEY` |
| Google Gemini | `@tanstack/ai-gemini` | `geminiText` | `GOOGLE_API_KEY` or `GEMINI_API_KEY` |

1. Install the package of the provider:

   ```npm
   npm install @tanstack/ai-anthropic
   ```

2. Set the API key in `.env`:

   ```bash
   ANTHROPIC_API_KEY=sk-ant-...
   ```

3. Pass the adapter to the agent:

   ```typescript title="src/copilotkit.ts"
   import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
   import { anthropicText } from "@tanstack/ai-anthropic"; // [!code highlight]

   const agent = tanstackAIAgent({
     adapter: () => anthropicText("claude-sonnet-4-6"), // [!code highlight]
   });
   ```

The other providers use the same shape:

```typescript
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { openaiText } from "@tanstack/ai-openai";
import { geminiText } from "@tanstack/ai-gemini";

const openaiAgent = tanstackAIAgent({
  adapter: () => openaiText("gpt-5.5"),
});

const geminiAgent = tanstackAIAgent({
  adapter: () => geminiText("gemini-3.8-flash"),
});
```

<Callout type="info" title="Why the adapter is a function">
  An adapter reads its API key when you create it. The agent calls the function on its first run, so imports and builds work without the key.
</Callout>

Each adapter package types the model id against its own list of models. A model id that is not in the list is a type error. For a model outside the list, see [OpenAI-compatible endpoints](#openai-compatible-endpoints).

</Tab>
<Tab value="AI SDK">

| Provider | Package | Model function | API key variable |
| --- | --- | --- | --- |
| OpenAI | `@ai-sdk/openai` | `openai` | `OPENAI_API_KEY` |
| Anthropic | `@ai-sdk/anthropic` | `anthropic` | `ANTHROPIC_API_KEY` |
| Google | `@ai-sdk/google` | `google` | `GOOGLE_GENERATIVE_AI_API_KEY` |

1. Install the package of the provider. Use the major version that matches your `ai` package:

   ```npm
   npm install @ai-sdk/anthropic
   ```

2. Set the API key in `.env`:

   ```bash
   ANTHROPIC_API_KEY=sk-ant-...
   ```

3. Pass the model to the agent:

   ```typescript title="src/copilotkit.ts"
   import { aiSdkAgent } from "@copilotkit/runtime/ai-sdk";
   import { anthropic } from "@ai-sdk/anthropic"; // [!code highlight]

   const agent = aiSdkAgent({
     model: anthropic("claude-sonnet-4-6"), // [!code highlight]
   });
   ```

Any AI SDK `LanguageModel` works, including Azure OpenAI, Amazon Bedrock, and Ollama providers.

</Tab>
</Tabs>

## Pass the API key in code

If the key is not in the default environment variable, give it to the provider yourself:

<Tabs groupId="agent-sdk" items={['TanStack AI', 'AI SDK']}>
<Tab value="TanStack AI">
```typescript
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { createOpenaiChat } from "@tanstack/ai-openai";

const agent = tanstackAIAgent({
  adapter: () => createOpenaiChat("gpt-5.5", process.env.MY_OPENAI_KEY!), // [!code highlight]
});
```

`createAnthropicChat` and `createGeminiChat` take the same arguments.
</Tab>
<Tab value="AI SDK">
```typescript
import { aiSdkAgent } from "@copilotkit/runtime/ai-sdk";
import { createOpenAI } from "@ai-sdk/openai";

const openai = createOpenAI({
  apiKey: process.env.MY_OPENAI_KEY, // [!code highlight]
});

const agent = aiSdkAgent({
  model: openai("gpt-5.5"),
});
```
</Tab>
</Tabs>

## OpenAI-compatible endpoints

OpenRouter, Groq, Together, a self-hosted gateway, and many other hosts serve an OpenAI-compatible API. Point the OpenAI provider at the host and give it the key.

<Tabs groupId="agent-sdk" items={['TanStack AI', 'AI SDK']}>
<Tab value="TanStack AI">
```typescript
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { openaiCompatibleText } from "@tanstack/ai-openai/compatible"; // [!code highlight]

const agent = tanstackAIAgent({
  adapter: () =>
    openaiCompatibleText("anthropic/claude-sonnet-4-6", { // [!code highlight:5]
      name: "openrouter",
      baseURL: "https://openrouter.ai/api/v1",
      apiKey: process.env.OPENROUTER_API_KEY!,
      api: "chat-completions",
    }),
});
```

`openaiCompatibleText` takes any model id. Set `api` to `"chat-completions"` or `"responses"`, to match the API that the host serves.
</Tab>
<Tab value="AI SDK">
```typescript
import { aiSdkAgent } from "@copilotkit/runtime/ai-sdk";
import { createOpenAI } from "@ai-sdk/openai";

const openrouter = createOpenAI({
  baseURL: "https://openrouter.ai/api/v1",
  apiKey: process.env.OPENROUTER_API_KEY,
});

const agent = aiSdkAgent({
  model: openrouter.chat("anthropic/claude-sonnet-4-6"), // [!code highlight]
});
```

<Callout type="warn" title="Call provider.chat(model)">
  A bare `provider(model)` call sends the request to the OpenAI **Responses** API (`POST {baseURL}/responses`). Most OpenAI-compatible hosts serve only the Chat Completions API, so the run fails, for example with a 404. `provider.chat(model)` sends the request to `POST {baseURL}/chat/completions`.
</Callout>
</Tab>
</Tabs>

## Let the client pick the model

You can let the frontend choose a model for each request, from a list that you control.

<Steps>
<Step>
### Name the models a client can pick

Add `"model"` to `overridableProperties`, then list the models by name:

<Tabs groupId="agent-sdk" items={['TanStack AI', 'AI SDK']}>
<Tab value="TanStack AI">
```typescript title="src/copilotkit.ts"
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { openaiText } from "@tanstack/ai-openai";
import { anthropicText } from "@tanstack/ai-anthropic";

const agent = tanstackAIAgent({
  adapter: () => openaiText("gpt-5.5"),
  overridableProperties: ["model"], // [!code highlight:5]
  adapters: {
    fast: () => openaiText("gpt-5-mini"),
    claude: () => anthropicText("claude-sonnet-4-6"),
  },
});
```

The agent creates each adapter the first time a client picks it.
</Tab>
<Tab value="AI SDK">
```typescript title="src/copilotkit.ts"
import { aiSdkAgent } from "@copilotkit/runtime/ai-sdk";
import { openai } from "@ai-sdk/openai";
import { anthropic } from "@ai-sdk/anthropic";

const agent = aiSdkAgent({
  model: openai("gpt-5.5"),
  overridableProperties: ["model"], // [!code highlight:5]
  models: {
    fast: openai("gpt-5-mini"),
    claude: anthropic("claude-sonnet-4-6"),
  },
});
```
</Tab>
</Tabs>
</Step>
<Step>
### Send the name from the frontend

Put the name in `properties`:

```tsx title="app/page.tsx"
import { CopilotChat, CopilotKitProvider } from "@copilotkit/react-core";

export default function Page() {
  return (
    <CopilotKitProvider runtimeUrl="/api/copilotkit" properties={{ model: "fast" }}>
      <CopilotChat />
    </CopilotKitProvider>
  );
}
```
</Step>
</Steps>

The run now uses the `fast` model. If the name is not in the list, the run uses the default model. A client cannot send a model of its own.

<Callout type="info" title="Need full control of the model call?">
  With a [Custom Agent](/backend/custom-agent), you write the `chat()` or `streamText()` call yourself, and CopilotKit does the rest.
</Callout>
