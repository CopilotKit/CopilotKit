## The backend tools

These renderers draw tools that run on your server. The Built-in Agent
streams each call, its arguments, and its result to the chat, so the tools
need no rendering-specific setup. To define them, see
[Server Tools](/integrations/built-in-agent/server-tools).

## Try it

Ask the demo for the weather in San Francisco. A `WeatherCard` for the
`get_weather` call appears in the chat, shows its running state, and fills
in when the tool returns. Ask it to find flights from SFO to JFK to see the
`FlightListCard`, or for a stock price to see the catch-all card.
