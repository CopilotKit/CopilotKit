## Read the notes the agent writes

The Showcase agent returns its `set_notes` tool result. The factory translates
that result into a `STATE_DELTA` at `/notes`, and the UI subscriber renders the
updated list.

## Send UI-owned preferences

The preferences card uses `agent.setState` to place a new `preferences` value
in the client-side agent state.

<Snippet region="use-agent-write" title="frontend/src/app/demos/shared-state-read-write/page.tsx — publish preferences" />

The selected runtime agent opts into a small state-to-prompt bridge. It reads
only the `preferences` object, formats the known fields, and adds that text to
the model request for this agent. Other Built-in Agent demos do not receive
this state automatically.

<Snippet region="shared-state-preferences-prompt" title="src/lib/factory/tanstack-factory.ts — format selected preferences for this run" />

## Try it

With the default **casual** tone, **English** language, and no selected
interests, choose **Remember something**. The new note should appear in the
agent-written list, and the agent receives those preferences on that run.

For the general two-way state model and streaming variants, see
[Shared State](/shared-state).
