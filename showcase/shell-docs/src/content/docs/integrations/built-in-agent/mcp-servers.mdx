The tools your agent needs already run on an MCP (Model Context Protocol) server: yours, or one from a third party. Add the server to `mcpServers`, and the agent gets its tools on every run.

Use MCP servers when:

- You already have MCP-compatible tool servers.
- You want tools from a third-party MCP provider.
- You share one set of tools across several agents or apps.

## Connect a server

Pass the server in `mcpServers`. The HTTP (Streamable HTTP) transport is `type: "http"`:

<Tabs groupId="agent-sdk" items={['TanStack AI', 'AI SDK']}>
<Tab value="TanStack AI">
```typescript title="src/copilotkit.ts"
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { openaiText } from "@tanstack/ai-openai";

const agent = tanstackAIAgent({
  adapter: () => openaiText("gpt-5.5"),
  mcpServers: [ // [!code highlight:3]
    { type: "http", url: "https://my-mcp-server.example.com/mcp" },
  ],
});
```
</Tab>
<Tab value="AI SDK">
```typescript title="src/copilotkit.ts"
import { aiSdkAgent } from "@copilotkit/runtime/ai-sdk";
import { openai } from "@ai-sdk/openai";

const agent = aiSdkAgent({
  model: openai("gpt-5.5"),
  maxSteps: 5,
  mcpServers: [ // [!code highlight:3]
    { type: "http", url: "https://my-mcp-server.example.com/mcp" },
  ],
});
```
</Tab>
</Tabs>

On each run, the agent connects to the server, adds its tools, and closes the connection when the run ends. If a server does not connect, the agent skips it and the run continues.

The rest of this page uses TanStack AI. `mcpServers` is the same on `aiSdkAgent`.

## SSE transport and headers

For an SSE server, use `type: "sse"`. Pass authentication in `headers`:

```typescript title="src/copilotkit.ts"
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { openaiText } from "@tanstack/ai-openai";

const agent = tanstackAIAgent({
  adapter: () => openaiText("gpt-5.5"),
  mcpServers: [
    {
      type: "sse", // [!code highlight]
      url: "https://my-mcp-server.example.com/sse",
      headers: { // [!code highlight:3]
        Authorization: `Bearer ${process.env.MCP_API_KEY}`,
      },
    },
  ],
});
```

The HTTP transport does not take `headers`. It takes `options` for the `StreamableHTTPClientTransport` of the MCP SDK. To add headers, pass a `fetch` that adds them in `options.fetch`.

## Several servers

List all of them. The agent gets the tools of every server:

```typescript title="src/copilotkit.ts"
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { openaiText } from "@tanstack/ai-openai";

const agent = tanstackAIAgent({
  adapter: () => openaiText("gpt-5.5"),
  mcpServers: [
    { type: "sse", url: "https://search-mcp.example.com/sse" },
    {
      type: "sse",
      url: "https://db-mcp.example.com/sse",
      headers: { Authorization: `Bearer ${process.env.DB_MCP_KEY}` },
    },
    { type: "http", url: "https://analytics-mcp.example.com/mcp" },
  ],
});
```

### Tool name collisions

Two servers can have tools with the same name, for example a staging server and a production server. The agent keeps every copy. When a name collides, each MCP copy gets a prefix, and the agent logs a warning:

```typescript title="src/copilotkit.ts"
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { openaiText } from "@tanstack/ai-openai";

const agent = tanstackAIAgent({
  adapter: () => openaiText("gpt-5.5"),
  mcpServers: [
    { type: "http", url: "https://staging.example.com/mcp", name: "staging" }, // [!code highlight]
    { type: "http", url: "https://prod.example.com/mcp", name: "production" }, // [!code highlight]
  ],
});
// Both servers have `search`, so the model sees `staging_search` and `production_search`.
```

How the prefix works:

- Only names that collide get a prefix. Other tools keep their names.
- If an MCP tool has the name of one of your own tools, your tool keeps the name. The MCP tool gets the prefix.
- If a server has no `name`, the prefix is `mcp<N>`. N is the position of the server in `mcpServers`, from 1.
- If a prefixed name is already in use, the agent adds a number, for example `production_search_2`. Give each server a different `name` to prevent this.
- A frontend tool renderer matches only the exposed name. If `search` becomes `production_search`, register the renderer for `production_search`.

## Use MCP tools with your own tools

`mcpServers` and `tools` work together. The agent sees the tools from both:

```typescript title="src/copilotkit.ts"
import { defineTool } from "@copilotkit/runtime";
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { openaiText } from "@tanstack/ai-openai";
import { z } from "zod";

const getUser = defineTool({
  name: "getUser",
  description: "Get the current user",
  parameters: z.object({}),
  execute: async () => ({ name: "Jane", role: "Admin" }),
});

const agent = tanstackAIAgent({
  adapter: () => openaiText("gpt-5.5"),
  tools: [getUser], // [!code highlight:4]
  mcpServers: [
    { type: "sse", url: "https://search-mcp.example.com/sse" },
  ],
});
```

## Keep a client open between runs

`mcpServers` connects again on every run. To keep one connection open, create the MCP client yourself and give its tools to the agent:

<Tabs groupId="agent-sdk" items={['TanStack AI', 'AI SDK']}>
<Tab value="TanStack AI">
`tanstackAIAgent` passes the `mcp` option to TanStack AI's `chat()`. Give it your clients with `connection: "keep-alive"`, so that `chat()` does not close them when a run ends. See the TanStack AI docs for how to create the clients.
</Tab>
<Tab value="AI SDK">
Pass a `tools` function that reads the tools of a client you created at startup:

```typescript title="src/copilotkit.ts"
import { aiSdkAgent } from "@copilotkit/runtime/ai-sdk";
import { openai } from "@ai-sdk/openai";
import { createMCPClient } from "@ai-sdk/mcp";
import { StreamableHTTPClientTransport } from "@modelcontextprotocol/sdk/client/streamableHttp.js";

const client = await createMCPClient({
  transport: new StreamableHTTPClientTransport(
    new URL("https://my-mcp-server.example.com/mcp"),
  ),
});
const mcpTools = client.tools(); // [!code highlight]

const agent = aiSdkAgent({
  model: openai("gpt-5.5"),
  maxSteps: 5,
  tools: () => mcpTools, // [!code highlight]
});
```

The agent reads the tool list once at startup and uses it on every run. You own the client. When your server stops, close the client.
</Tab>
</Tabs>

## Transport reference

| Property | SSE | HTTP | Description |
|----------|-----|------|-------------|
| `type` | `"sse"` | `"http"` | Transport type |
| `url` | string | string | MCP server URL |
| `name` | string | string | Prefix for tool names that collide |
| `headers` | `Record<string, string>` | not available | Custom HTTP headers |
| `options` | not available | `StreamableHTTPClientTransportOptions` | Transport options |
