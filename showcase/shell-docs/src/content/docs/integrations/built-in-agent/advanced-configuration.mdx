Set these options on `tanstackAIAgent` or `aiSdkAgent` to change how the agent calls the model: the prompt, the tool-calling limit, model settings, and what a client can change per request.

## System prompt

Give the agent its instructions in `prompt`:

<Tabs groupId="agent-sdk" items={['TanStack AI', 'AI SDK']}>
<Tab value="TanStack AI">
```typescript title="src/copilotkit.ts"
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { openaiText } from "@tanstack/ai-openai";

const agent = tanstackAIAgent({
  adapter: () => openaiText("gpt-5.5"),
  prompt: "You are a customer support agent for Acme Corp. Be concise.", // [!code highlight]
});
```
</Tab>
<Tab value="AI SDK">
```typescript title="src/copilotkit.ts"
import { aiSdkAgent } from "@copilotkit/runtime/ai-sdk";
import { openai } from "@ai-sdk/openai";

const agent = aiSdkAgent({
  model: openai("gpt-5.5"),
  prompt: "You are a customer support agent for Acme Corp. Be concise.", // [!code highlight]
});
```
</Tab>
</Tabs>

The agent adds the context and the application state from the frontend after your prompt.

## Tool-calling limit

One run can have several model turns: call a tool, read the result, call another tool, then answer. The limit sets the largest number of turns in one run.

<Tabs groupId="agent-sdk" items={['TanStack AI', 'AI SDK']}>
<Tab value="TanStack AI">
```typescript title="src/copilotkit.ts"
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { openaiText } from "@tanstack/ai-openai";
import { createTicket, searchDocs } from "./tools";

const agent = tanstackAIAgent({
  adapter: () => openaiText("gpt-5.5"),
  tools: [searchDocs, createTicket],
  maxIterations: 8, // [!code highlight]
});
```

Default: 5 turns, or 10 when [learned skills](#learned-skills) are available.
</Tab>
<Tab value="AI SDK">
```typescript title="src/copilotkit.ts"
import { aiSdkAgent } from "@copilotkit/runtime/ai-sdk";
import { openai } from "@ai-sdk/openai";
import { createTicket, searchDocs } from "./tools";

const agent = aiSdkAgent({
  model: openai("gpt-5.5"),
  tools: [searchDocs, createTicket],
  maxSteps: 8, // [!code highlight]
});
```

Default: 1 step, or 10 when [learned skills](#learned-skills) are available. With 1 step, the model can call a tool but cannot answer after the result. Set `maxSteps` when the agent has tools.
</Tab>
</Tabs>

## Model settings

<Tabs groupId="agent-sdk" items={['TanStack AI', 'AI SDK']}>
<Tab value="TanStack AI">
Put sampling settings in `modelOptions`. The adapter types them, so your editor shows the options of your provider:

```typescript title="src/copilotkit.ts"
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { openaiText } from "@tanstack/ai-openai";

const agent = tanstackAIAgent({
  adapter: () => openaiText("gpt-5.5"),
  modelOptions: { temperature: 0.3 }, // [!code highlight]
  reasoning: "high", // [!code highlight]
});
```

Other `chat()` options, such as `reasoning`, `toolChoice`, `metadata`, and `middleware`, pass through to every `chat()` call.
</Tab>
<Tab value="AI SDK">
Set `streamText()` settings on the agent. They pass through to every call:

```typescript title="src/copilotkit.ts"
import { aiSdkAgent } from "@copilotkit/runtime/ai-sdk";
import { openai } from "@ai-sdk/openai";

const agent = aiSdkAgent({
  model: openai("gpt-5.5"),
  temperature: 0.3, // [!code highlight:4]
  maxOutputTokens: 4096,
  toolChoice: "auto",
  maxRetries: 3,
});
```

Other `streamText()` settings work the same way, for example `topP`, `stopSequences`, `seed`, and `headers`. A provider ignores a setting that it does not support.
</Tab>
</Tabs>

## Provider-specific options

<Tabs groupId="agent-sdk" items={['TanStack AI', 'AI SDK']}>
<Tab value="TanStack AI">
Provider-specific settings also go in `modelOptions`. Its type comes from the adapter and the model, so your editor lists the settings of your provider. For thinking, set `reasoning`:

```typescript title="src/copilotkit.ts"
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { anthropicText } from "@tanstack/ai-anthropic";

const agent = tanstackAIAgent({
  adapter: () => anthropicText("claude-sonnet-4-6"),
  reasoning: "high", // [!code highlight]
});
```

`reasoning` sets how hard the model thinks. TanStack AI maps the level to the setting of each provider.
</Tab>
<Tab value="AI SDK">
Pass them in `providerOptions`, keyed by provider:

```typescript title="src/copilotkit.ts"
import { aiSdkAgent } from "@copilotkit/runtime/ai-sdk";
import { anthropic } from "@ai-sdk/anthropic";

const agent = aiSdkAgent({
  model: anthropic("claude-sonnet-4-6"),
  providerOptions: { // [!code highlight:3]
    anthropic: { thinking: { type: "adaptive" }, effort: "high" },
  },
});
```
</Tab>
</Tabs>

## Overridable properties

A client can change some settings for one request through `forwardedProps`. List the settings that it can change in `overridableProperties`. The agent ignores a value of the wrong type.

<Tabs groupId="agent-sdk" items={['TanStack AI', 'AI SDK']}>
<Tab value="TanStack AI">
```typescript title="src/copilotkit.ts"
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { openaiText } from "@tanstack/ai-openai";

const agent = tanstackAIAgent({
  adapter: () => openaiText("gpt-5.5"),
  modelOptions: { temperature: 0.5 },
  overridableProperties: ["modelOptions"], // [!code highlight]
});
```

You can list:

- `modelOptions`: an object. The agent merges it over the configured `modelOptions`.
- `model`: a name from `adapters`.
</Tab>
<Tab value="AI SDK">
```typescript title="src/copilotkit.ts"
import { aiSdkAgent } from "@copilotkit/runtime/ai-sdk";
import { openai } from "@ai-sdk/openai";

const agent = aiSdkAgent({
  model: openai("gpt-5.5"),
  temperature: 0.5,
  overridableProperties: ["temperature", "maxOutputTokens"], // [!code highlight]
});
```

You can list `model` (a name from `models`), `toolChoice`, `maxOutputTokens`, `temperature`, `topP`, `topK`, `presencePenalty`, `frequencyPenalty`, `stopSequences`, `seed`, `maxRetries`, and `providerOptions`.
</Tab>
</Tabs>

The frontend sends the values in `properties`, for example `properties={{ temperature: 0.2 }}`. To let a client pick the model, see [Let the client pick the model](/model-selection#let-the-client-pick-the-model).

<Callout type="warn" title="forwardedProps comes from the browser">
  Allow only settings that are safe for any user to change. Do not use them for credentials, tenant identity, or authorization.
</Callout>

## Learned skills

To give the agent skills from a CopilotKit Intelligence learning container, set `learnedSkills`:

```typescript title="src/copilotkit.ts"
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { openaiText } from "@tanstack/ai-openai";

const agent = tanstackAIAgent({
  adapter: () => openaiText("gpt-5.5"),
  learnedSkills: { containerId: "support-learning" }, // [!code highlight]
});
```

`aiSdkAgent` takes the same option. When skills are available, the default tool-calling limit is 10, so the model can load a skill and use it. See [Learned skills](/intelligence/learned-skills) for the full setup.

## Capabilities

The agent tells the frontend what it supports: tools, streaming, and interrupts. To change that, set `capabilities` to a `Partial<AgentCapabilities>` from AG-UI. Both one-liners take it.

The agent merges your value over its defaults one category at a time. A category that you set replaces the full default category. For example, `{ tools: { supported: true } }` removes the default `clientProvided: true`, so include every field of a category that you set.

## Message forwarding

By default, the agent does not send system and developer messages from the conversation to the model. A client could otherwise change the agent's instructions. To send them, set:

```typescript title="src/copilotkit.ts"
import { tanstackAIAgent } from "@copilotkit/runtime/tanstack-ai";
import { openaiText } from "@tanstack/ai-openai";

const agent = tanstackAIAgent({
  adapter: () => openaiText("gpt-5.5"),
  forwardSystemMessages: true, // [!code highlight:2]
  forwardDeveloperMessages: true,
});
```

`aiSdkAgent` takes the same two options.

## URL attachments (AI SDK)

A message can have an image or a file given by URL. If the model cannot take that URL directly, the server downloads the file and sends its content to the model. The URL comes from the request, so `urlDownload` controls what the server can fetch:

```typescript title="src/copilotkit.ts"
import { aiSdkAgent } from "@copilotkit/runtime/ai-sdk";
import { openai } from "@ai-sdk/openai";

const agent = aiSdkAgent({
  model: openai("gpt-5.5"),
  urlDownload: { // [!code highlight:4]
    allowedHosts: ["cdn.example.com", "*.example-uploads.com"],
    maxBytes: 10 * 1024 * 1024,
  },
});
```

The values of `urlDownload`:

- **`"safe"` (default)**: download only from public internet addresses. The server resolves the hostname and refuses loopback, private, link-local (including cloud metadata), and other addresses that are not public. It connects only to the addresses it examined, examines each redirect again, and refuses a redirect from https to http.
- **An options object**: the safe downloader with your limits. `allowedHosts` limits downloads to the hostnames you list (see below).
- **`false`**: never download. An attachment URL other than `data:` that the model cannot take directly fails the run.
- **A function**: your own AI SDK download function (`Experimental_DownloadFunction` from `ai`). Use this only to fetch from a private network, and examine each URL yourself.

The safe downloader has these limits:

| Option | Default | Limit |
| --- | --- | --- |
| `maxBytes` | 20 MiB | Size of one download |
| `timeoutMs` | 30 seconds | Time for one download |
| `maxDownloads` | 20 | Different URLs in one model call |
| `maxTotalBytes` | 50 MiB | Total size in one model call |

The AI SDK downloads the attachments again for each step of a run, so each step counts on its own.

Rules for `allowedHosts`:

- The addresses must still be public, and each redirect target must also be in the list.
- `cdn.example.com` matches only that host. `*.example-uploads.com` matches its subdomains, but not `example-uploads.com`. If you need both, list both.
- Matching ignores case and a trailing dot.
- Give hostnames only. The agent rejects an entry with a scheme, port, or path, and a wildcard over an IP address (`*.1.2.3.4`).
- An empty list refuses every download.

Invalid options, including an unknown option name, throw when you create the agent, not when a request arrives.

URLs that the model takes directly go to the model provider unchanged. The AI SDK decodes `data:` URLs without a network request, in every mode. When a download fails, the client gets a short message without the query of the URL. The server logs the cause with a `[BuiltInAgent]` prefix.

The safe downloader needs Node.js networking modules. On a runtime without them, such as an edge runtime, every download fails. There, set `urlDownload` to `false` or to your own download function.

In a [Custom Agent](/backend/custom-agent) factory, `aiSdk(ctx)` adds the safe downloader for you, and `aiSdk(ctx, { urlDownload })` takes the same values.

## Configuration reference

<Tabs groupId="agent-sdk" items={['TanStack AI', 'AI SDK']}>
<Tab value="TanStack AI">
| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `adapter` | adapter, or `() => adapter` | required | The text adapter, for example `() => openaiText("gpt-5.5")` |
| `prompt` | `string` | none | System prompt |
| `tools` | `(Tool \| ToolDefinition)[]`, or `(ctx) => tools` | none | Server tools |
| `mcpServers` | `MCPClientConfig[]` | none | MCP servers to connect to on each run |
| `maxIterations` | `number` | `5` (`10` with learned skills) | Largest number of model turns in one run |
| `modelOptions` | provider options of the adapter | none | Sampling and provider settings |
| `overridableProperties` | `("model" \| "modelOptions")[]` | none | Settings a client can change per request |
| `adapters` | `Record<string, adapter \| () => adapter>` | none | Adapters a client can pick by name |
| `learnedSkills` | learned-skills options | none | Skills from a learning container |
| `forwardSystemMessages` | `boolean` | `false` | Send system messages from the conversation |
| `forwardDeveloperMessages` | `boolean` | `false` | Send developer messages from the conversation |
| `capabilities` | `Partial<AgentCapabilities>` | inferred | What the agent tells the frontend it supports |

Other `chat()` options pass through.
</Tab>
<Tab value="AI SDK">
| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `model` | `LanguageModel` | required | The AI SDK model, for example `openai("gpt-5.5")` |
| `prompt` | `string` | none | System prompt |
| `tools` | `ToolSet \| ToolDefinition[]`, or `(ctx) => tools` | none | Server tools |
| `mcpServers` | `MCPClientConfig[]` | none | MCP servers to connect to on each run |
| `maxSteps` | `number` | `1` (`10` with learned skills) | Largest number of model steps in one run |
| `overridableProperties` | `string[]` | none | Settings a client can change per request |
| `models` | `Record<string, LanguageModel>` | none | Models a client can pick by name |
| `forwardSystemMessages` | `boolean` | `false` | Send system messages from the conversation |
| `forwardDeveloperMessages` | `boolean` | `false` | Send developer messages as system messages |
| `urlDownload` | `"safe" \| false \| SafeUrlDownloadOptions \| function` | `"safe"` | Server-side download of URL attachments |
| `learnedSkills` | learned-skills options | none | Skills from a learning container |
| `capabilities` | `Partial<AgentCapabilities>` | inferred | What the agent tells the frontend it supports |

Other `streamText()` settings pass through.
</Tab>
</Tabs>
