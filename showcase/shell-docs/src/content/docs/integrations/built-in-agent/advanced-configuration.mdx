The `BuiltInAgent` takes options that control model behavior, tool calls, and
what the frontend can change at run time.

## Multi-step tool calling

By default, the agent makes one model call. Then it runs the tools that the call
asks for and stops. Set `maxSteps` to let the agent read the tool results and
continue:

```typescript title="src/copilotkit.ts"
import { BuiltInAgent, defineTool } from "@copilotkit/runtime/agent";
import { openaiText } from "@tanstack/ai-openai";
import { z } from "zod";

const searchDocs = defineTool({
  name: "searchDocs",
  description: "Search the documentation",
  parameters: z.object({ query: z.string() }),
  execute: async ({ query }) => ({ results: [`Article about ${query}`] }),
});

const createTicket = defineTool({
  name: "createTicket",
  description: "Create a support ticket",
  parameters: z.object({ title: z.string() }),
  execute: async ({ title }) => ({ ticketId: "T-1", title }),
});

const agent = new BuiltInAgent({
  model: openaiText("gpt-5.4-mini"),
  maxSteps: 5, // [!code highlight]
  tools: [searchDocs, createTicket],
});
```

With `maxSteps: 5`, the agent can make up to 5 model calls in one run. Use this
when the agent must chain several tool calls.

## Tool choice

Control how the agent selects tools:

```typescript
import { BuiltInAgent } from "@copilotkit/runtime/agent";
import { openaiText } from "@tanstack/ai-openai";

const agent = new BuiltInAgent({
  model: openaiText("gpt-5.4-mini"),
  toolChoice: "auto",       // Let the model decide
  // toolChoice: "required", // Force the model to call a tool
  // toolChoice: "none",     // Disable tool calling
  // toolChoice: { type: "tool", name: "searchDocs" }, // Force a specific tool
});
```

If you do not set `toolChoice`, the provider default applies.

## System prompt

Customize the agent's system prompt:

```typescript
import { BuiltInAgent } from "@copilotkit/runtime/agent";
import { openaiText } from "@tanstack/ai-openai";

const agent = new BuiltInAgent({
  model: openaiText("gpt-5.4-mini"),
  prompt: "You are a customer support agent for Acme Corp. Be concise and helpful. Always check the knowledge base before answering.", // [!code highlight]
});
```

## Provider options

Put temperature, token limits, reasoning effort, and other provider settings in
`modelOptions`. The agent sends them to the provider unchanged, so use the names
from your provider's API.

For OpenAI:

```typescript
import { BuiltInAgent } from "@copilotkit/runtime/agent";
import { openaiText } from "@tanstack/ai-openai";

const agent = new BuiltInAgent({
  model: openaiText("gpt-5.4-mini"),
  modelOptions: { // [!code highlight:4]
    reasoning: { effort: "low" },
    max_output_tokens: 1000,
  },
});
```

For Anthropic:

```typescript
import { BuiltInAgent } from "@copilotkit/runtime/agent";
import { anthropicText } from "@tanstack/ai-anthropic";

const agent = new BuiltInAgent({
  model: anthropicText("claude-sonnet-4-6"),
  modelOptions: { // [!code highlight:4]
    max_tokens: 4096,
    temperature: 0.5,
  },
});
```

<Callout type="info">
  OpenAI reasoning models, such as GPT-5 and the o-series, do not accept
  `temperature` or `top_p`. The OpenAI adapter removes them unless reasoning
  effort is `none`.
</Callout>

## Overridable properties

Let the frontend change some options for one run, without a redeploy. List them
in `overridableProperties`:

```typescript
import { BuiltInAgent } from "@copilotkit/runtime/agent";
import { openaiText } from "@tanstack/ai-openai";

const agent = new BuiltInAgent({
  model: openaiText("gpt-5.4-mini"),
  overridableProperties: ["prompt", "modelOptions"], // [!code highlight]
});
```

The frontend sends the values as `forwardedProps`. You can list these properties:

- `model`: a model name, such as `"smart"`. Your `resolveModel` function turns
  it into an adapter. See
  [Switch models from the frontend](/model-selection#switch-models-from-the-frontend).
- `toolChoice`: `"auto"`, `"none"`, `"required"`, or `{ type: "tool", name }`.
- `prompt`: a string that replaces the agent's prompt.
- `modelOptions`: an object that replaces the configured `modelOptions`.

The agent ignores a value with the wrong type.

## Message forwarding

By default, the agent ignores `system` and `developer` messages from the
conversation. To send them to the model, turn on forwarding:

```typescript
import { BuiltInAgent } from "@copilotkit/runtime/agent";
import { openaiText } from "@tanstack/ai-openai";

const agent = new BuiltInAgent({
  model: openaiText("gpt-5.4-mini"),
  forwardSystemMessages: true,    // Forward system-role messages
  forwardDeveloperMessages: true, // Forward developer-role messages
});
```

The forwarded messages become system prompts after the agent's `prompt`.

## URL attachments

When a message has an image or file given by URL, the agent sends the URL to
the provider. The server does not download the file.

In an AI SDK factory, you write the `streamText()` call. To let the AI SDK
download URLs safely there, pass `createSafeUrlDownload` from
`@copilotkit/runtime/agent/ai-sdk` as `experimental_download`. See
[Use any model router](/backend/custom-agent).

## Full configuration reference

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `model` | `AnyTextAdapter` | none | TanStack AI text adapter, such as `openaiText("gpt-5.4-mini")` |
| `resolveModel` | `(name: string) => AnyTextAdapter \| undefined` | none | Turns a model name from the frontend into an adapter |
| `maxSteps` | `number` | `1` (`10` with skills) | Max model calls in one run |
| `toolChoice` | `"auto" \| "required" \| "none" \| { type: "tool", name: string }` | provider default | How tools are selected |
| `modelOptions` | `Record<string, unknown>` | none | Provider options, sent unchanged |
| `prompt` | `string` | none | System prompt |
| `tools` | `ToolDefinition[]` | `[]` | Server-side tools |
| `mcpClients` | `MCPClientProvider[]` | `[]` | MCP clients that you create and close. See [MCP Servers](/mcp-servers) |
| `overridableProperties` | `OverridableProperty[]` | `[]` | Properties the frontend can override |
| `forwardSystemMessages` | `boolean` | `false` | Forward system messages |
| `forwardDeveloperMessages` | `boolean` | `false` | Forward developer messages |

<Callout type="info" title="Need even more control?">
  To write the model call yourself, for example with the AI SDK, TanStack AI
  `chat()`, or a custom LLM backend, see [Custom Agent](/backend/custom-agent).
</Callout>
