## Start with your coding agent

Use this prompt to connect your Claude Agent SDK for TypeScript agent to CopilotKit and verify a working conversation. Your coding agent will follow this guide in your project, or you can work through the manual steps below.

<PageAgentPrompt />

This quickstart gives you two working paths:

- **Start from scratch** to scaffold the full Claude Agent SDK TypeScript showcase.
- **Use an existing agent** to expose your own Claude Agent SDK process over AG-UI and connect it to a React app.

## Prerequisites

Before you begin, you'll need the following:

- An Anthropic API key
- Node.js 20.9+
- Your favorite package manager

          - `agent/src/server.ts`: the AG-UI server for the agent. It listens on port 8000.

        <Step>
          ### Install the required packages

          The agent and the Next.js app are two separate projects. Run these commands in your agent project (the folder with its `package.json`). To start a new one, run `mkdir agent && cd agent && npm init -y` first.

          Install the Claude Agent SDK adapter, AG-UI event packages, and Express server dependencies for the agent process:

          ```bash
          npm install @anthropic-ai/claude-agent-sdk@0.3.306 @anthropic-ai/sdk @ag-ui/claude-agent-sdk@0.0.9 @ag-ui/core @ag-ui/encoder express dotenv zod
          npm install -D typescript tsx @types/node @types/express
          ```

          Keep the two Claude packages pinned together. `@ag-ui/claude-agent-sdk@0.0.9` requires exactly `@anthropic-ai/claude-agent-sdk@0.3.306`, and npm stops with `ERESOLVE` on any other version.
        </Step>

        <Step>
          ### Configure your agent environment

          Create a `.env` file for the process that runs your Claude agent:

          ```plaintext title=".env"
          ANTHROPIC_API_KEY=your_anthropic_api_key
          CLAUDE_MODEL=claude-opus-4-8
          AGENT_PORT=8000
          ```
        </Step>

        <Step>
          ### Expose Claude Agent SDK over AG-UI

          CopilotKit talks to agents over AG-UI. The small server below receives AG-UI run input, passes it to `ClaudeAgentAdapter`, and streams AG-UI events back to the runtime.

          ```ts title="src/agent-server.ts"
          import express from "express";
          import { randomUUID } from "node:crypto";
          import { EventType, type RunAgentInput } from "@ag-ui/core";
          import { EventEncoder } from "@ag-ui/encoder";
          import { ClaudeAgentAdapter } from "@ag-ui/claude-agent-sdk";
          import dotenv from "dotenv";

          dotenv.config();

          const app = express();
          app.use(express.json({ limit: "10mb" }));

          const agent = new ClaudeAgentAdapter({
            agentId: "claude-sdk-typescript",
            model: process.env.CLAUDE_MODEL ?? "claude-opus-4-8",
            systemPrompt: "You are a helpful assistant embedded in a CopilotKit app.",
            tools: [],
            permissionMode: "dontAsk",
            maxTurns: 10,
          });

          app.post("/", (req, res) => {
            const input = req.body as RunAgentInput;
            const runId = input.runId ?? randomUUID();
            const threadId = input.threadId ?? randomUUID();
            const encoder = new EventEncoder();

            res.setHeader("Content-Type", "text/event-stream");
            res.setHeader("Cache-Control", "no-cache");
            res.setHeader("Connection", "keep-alive");

            agent.run({ ...input, runId, threadId }).subscribe({
              next: (event) => res.write(encoder.encodeSSE(event)),
              error: (error) => {
                const message = error instanceof Error ? error.message : String(error);
                res.write(
                  encoder.encodeSSE({
                    type: EventType.RUN_ERROR,
                    runId,
                    threadId,
                    message,
                  }),
                );
                res.end();
              },
              complete: () => res.end(),
            });
          });

          app.get("/health", (_req, res) => {
            res.json({ status: "ok" });
          });

          const port = Number(process.env.AGENT_PORT ?? 8000);
          app.listen(port, () => {
            console.log(`Claude Agent SDK listening on http://localhost:${port}`);
          });
          ```

          Start the agent server:

          ```bash
          npx tsx src/agent-server.ts
          ```

          In a second terminal, check it. The response is `{"status":"ok"}`:

          ```bash
          curl http://localhost:8000/health
          ```
        </Step>

        <Step>
          ### Create your frontend

          CopilotKit works with any React app. This example uses Next.js App Router. Run this from the folder that holds your agent project, not inside it:

          ```bash
          npx create-next-app@latest frontend --yes
          cd frontend
          npm install @copilotkit/runtime @copilotkit/react-core @ag-ui/client
          ```

          `--yes` uses the recommended defaults (TypeScript, Tailwind, App Router) and skips the prompts.

          `@ag-ui/client` must be the same version that `@copilotkit/runtime` uses. Two versions make TypeScript report that `HttpAgent` is not assignable to `AbstractAgent`. Run `npm ls @ag-ui/client`: the top-level copy must be the version that `@copilotkit/runtime` lists as `deduped`.
        </Step>

        <Step>
          ### Add the Copilot Runtime route

          Create `app/api/copilotkit/route.ts` in your Next.js app. It registers the Claude agent server as an AG-UI `HttpAgent` under the name `default`, the same name the starter uses.

          ```ts title="app/api/copilotkit/route.ts"
          import { HttpAgent } from "@ag-ui/client";
          import {
            CopilotRuntime,
            createCopilotRuntimeHandler,
          } from "@copilotkit/runtime/v2";
          import type { NextRequest } from "next/server";

          const runtime = new CopilotRuntime({
            agents: {
              default: new HttpAgent({
                url: process.env.AGENT_URL ?? "http://localhost:8000",
              }),
            },
          });

          const handler = createCopilotRuntimeHandler({
            runtime,
            basePath: "/api/copilotkit",
            mode: "single-route",
          });

          export const POST = (req: NextRequest) => handler(req);
          ```
        </Step>

        <Step>
          ### Mount CopilotKit in React

          Wrap your app with `CopilotKit` and target the agent name you registered in the runtime route.

          ```tsx title="app/providers.tsx"
          "use client";

          import { CopilotKit } from "@copilotkit/react-core/v2";

          export function Providers({ children }: { children: React.ReactNode }) {
            return (
              <CopilotKit runtimeUrl="/api/copilotkit" agent="default" useSingleEndpoint>
                {children}
              </CopilotKit>
            );
          }
          ```

          `useSingleEndpoint` matches the route's `mode: "single-route"`. The client then sends every request as a `POST` to `/api/copilotkit`.

          Render `Providers` in `app/layout.tsx`:

          ```tsx title="app/layout.tsx"
          import { Suspense } from "react";
          import { Providers } from "./providers";
          import "@copilotkit/react-core/v2/styles.css";
          import "./globals.css";

          export default function RootLayout({ children }: { children: React.ReactNode }) {
            return (
              <html lang="en">
                <body>
                  <Suspense>
                    <Providers>
                      {children}
                    </Providers>
                  </Suspense>
                </body>
              </html>
            );
          }
          ```

          `<Suspense>` keeps `npm run build` working when `next.config.ts` sets `cacheComponents: true`, the `create-next-app` default in Next.js 16. Without it, the build fails with `encountered the unstable value require('node:crypto').randomUUID()`.

          Not using Next.js? See [React SPA](/react-spa), [Vue](/vue), [Angular](/angular), or [React Native](/react-native).

          Add a chat surface:

          ```tsx title="app/page.tsx"
          "use client";

          import { CopilotSidebar } from "@copilotkit/react-core/v2";

          export default function Page() {
            return (
              <main>
                <CopilotSidebar />
              </main>
            );
          }
          ```
        </Step>

        <Step>
          ### Start the UI

          Keep the agent server running, then start the frontend in a second terminal:

          ```bash
          npm run dev
          ```
        </Step>

## Backend tools and state

The minimal server above is enough for text chat. To support backend tools and shared state snapshots, expose your tool schemas through the Claude SDK MCP bridge and emit AG-UI state events.

The steps below show two excerpts from [`claude-agent-sdk-adapter.ts`](https://github.com/CopilotKit/CopilotKit/blob/main/showcase/integrations/claude-sdk-typescript/src/claude-agent-sdk-adapter.ts). The excerpts do not run alone. The full file defines the helpers they call (`buildBackendToolServer`, `normalizeClaudeAgentSdkModel`) and the `Emit` and `ExecuteTool` types.

1. Copy the whole file to `src/claude-agent-sdk-adapter.ts` in your agent project.
2. Install the Zod alias that the file imports:

   ```bash
   npm install zod4@npm:zod@^4.3.6
   ```

3. Skip the install command in the first step below. You already installed those packages, and its `@^0.2.58` pin conflicts with `@ag-ui/claude-agent-sdk@0.0.9`.

<FrameworkSetup concept="agent-setup" />

Then replace the `app.post("/")` handler in `src/agent-server.ts`. `runWithClaudeAgentSdk` builds the adapter for each run, so you can remove the `ClaudeAgentAdapter` instance and its import. `toolSchemas` lists your backend tools, and `executeTool` runs them:

```ts title="src/agent-server.ts"
import type { BaseEvent } from "@ag-ui/core";
import { runWithClaudeAgentSdk } from "./claude-agent-sdk-adapter";

app.post("/", async (req, res) => {
  const input = req.body as RunAgentInput;
  const runId = input.runId ?? randomUUID();
  const threadId = input.threadId ?? randomUUID();
  const encoder = new EventEncoder();

  res.setHeader("Content-Type", "text/event-stream");
  res.setHeader("Cache-Control", "no-cache");
  res.setHeader("Connection", "keep-alive");

  await runWithClaudeAgentSdk({
    input,
    runId,
    threadId,
    emit: (event) => res.write(encoder.encodeSSE(event as BaseEvent)),
    model: process.env.CLAUDE_MODEL ?? "claude-opus-4-8",
    systemPrompt: "You are a helpful assistant embedded in a CopilotKit app.",
    initialState: {},
    toolSchemas: [
      {
        name: "get_weather",
        description: "Get the current weather for a city.",
        input_schema: {
          type: "object",
          properties: { city: { type: "string" } },
          required: ["city"],
        },
      },
    ],
    executeTool: async (toolName, toolInput) => ({
      resultText: `It is sunny in ${String(toolInput.city)}.`,
      state: null,
    }),
  });
  res.end();
});
```

Restart the agent server and ask `What is the weather in Rome?`. The agent calls the tool as `mcp__copilotkit__get_weather` (the MCP bridge adds the prefix), then replies with the tool result. To update shared state from a tool, return the new state as `state` instead of `null`. The adapter emits it as a `STATE_SNAPSHOT` event.
