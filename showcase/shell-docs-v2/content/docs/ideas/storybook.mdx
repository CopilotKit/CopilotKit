  React, Vue, Angular, Web Components, and More, right under the title.

- The choice is remembered across pages.
- Markdown for agents takes the same choice: `writing-stories.md?renderer=vue`.

## For CopilotKit

<StorybookMock />

The agent framework stays in the URL; only the frontend switches here.

## Why it fits

- Matches the decision that the frontend switches inside the page.
- React, Vue, Angular, and React Native fit in one row.
- Agents can fetch `?frontend=vue` and get one clean version.

## Watch out

- Hide the chips on pages where the frontend makes no difference.
