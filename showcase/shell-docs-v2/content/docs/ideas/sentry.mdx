## Why it fits

- Every framework gets real URLs, like `/docs/mastra/human-in-the-loop`, which
  is what co-marketing needs.
- Titles such as "Human in the loop for Mastra" tell readers and search
  engines exactly where they are.

## Watch out

- It covers the agent framework only. Pair it with a frontend switch.
- Shared pages appear under every framework, so each needs a canonical URL.
