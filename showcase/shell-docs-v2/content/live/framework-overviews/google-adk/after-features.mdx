## Already have Google ADK sessions?

When you add a user-facing app to an existing ADK agent, your users may need to open and continue sessions they started elsewhere. [CopilotKit Intelligence](/intelligence/overview) can import persisted ADK sessions as threads, bringing that history into your CopilotKit app.

The importer supports ADK database session stores and Vertex/Agent Engine session history. In-memory sessions cannot be exported; legacy pickle stores need migration first.

Import the history once. After that, runs that go through CopilotKit sync to Intelligence. If your agent uses a durable session service with enough retention, ADK also keeps saving those runs. This is not a continuous mirror of runs made outside CopilotKit.

[Import and synchronize Google ADK sessions](/google-adk/threads-import) for source setup, agent mapping, and thread continuity.
