## **Generative UI Specifications**

These specifications let an agent return UI components as well as text. CopilotKit renders A2UI and MCP Apps.

| **Specification** | **Origin / Maintainer** | **Purpose**                                                                                                          |
| ----------------- | ----------------------- | -------------------------------------------------------------------------------------------------------------------- |
| [**A2UI**](/generative-ui/a2ui) | Google                  | A declarative, LLM-friendly Generative UI spec. JSONL-based and streaming, designed for platform-agnostic rendering. |
| **Open-JSON-UI**  | OpenAI                  | An open standardization of OpenAI's internal declarative Generative UI schema.                                       |
| [**MCP Apps**](/generative-ui/mcp-apps) | MCP Ecosystem           | Iframe-based Generative UI extending MCP, enabling servers to return interactive UI components.                      |

## **AG-UI vs Generative UI Specs**

[AG-UI](/agentic-protocols/ag-ui) is the protocol that connects your agent to your app, in both directions. It carries the UI from any of these specs. You can also define your own generative UI format on AG-UI.

Pick your agent framework in the sidebar to get started.
