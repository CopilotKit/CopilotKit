## What is shared state?

Your agent and your UI share one state object. With this shared state system, you can:

- [Display the agent's current progress](/shared-state/in-app-agent-read) and intermediate results
- [Update the agent's state](/shared-state/in-app-agent-write) through UI interactions
- [React to state changes](/shared-state/predictive-state-updates) in real-time across your application

The foundation of this system is built on CrewAI's stateful architecture.

<Callout type="info" title="Conversational Flow state">
  If you promoted the Flow to conversational mode, inherit custom Pydantic
  state from `ag_ui_crewai.CopilotKitState`. It includes the conversation
  fields CrewAI needs in addition to CopilotKit messages, actions, and shared
  state.
</Callout>

## When should I use this?

Use shared state when the agent and the user work on the same data. Any state that your CrewAI Flow
persists will be automatically shared by the UI. When the user changes the state in the UI, the agent receives the new state on its next run.

This allows for a consistent experience where both the agent and the user are on the same page.
