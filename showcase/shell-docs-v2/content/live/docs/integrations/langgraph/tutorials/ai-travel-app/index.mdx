## What you'll learn

This tutorial is a code tour of the completed CopilotKit v2 travel example. You
will run the app, inspect each integration point, and learn:

- How `useAgent` shares state between the UI and the agent
- How `useRenderTool` renders streamed search progress
- How `useHumanInTheLoop` pauses trip changes for user approval
- How the v2 runtime connects the React app to a LangGraph agent

The snippets match the current source under `examples/v1/travel`. You do
not need a separate starter branch or apply each snippet as a patch. If you are
updating an older app, use the [v1 to v2 migration guide](/migrate/v2) alongside
this tour.
