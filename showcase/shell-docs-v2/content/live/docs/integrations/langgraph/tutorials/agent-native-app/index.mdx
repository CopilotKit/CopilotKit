## What you'll learn

You build a Research Agent Native Application (ANA) using CopilotKit. You start with a basic application and add agent capabilities step by step.

This tutorial pins CopilotKit 1.5.20 and uses v1 APIs. For the same app on CopilotKit v2, see [`examples/v1/research-canvas`](https://github.com/CopilotKit/CopilotKit/tree/main/examples/v1/research-canvas) and the [v1 to v2 migration guide](/migrate/v2).

You'll learn:

- Core principles of agent native applications
- How LangGraph helps structure LLM behavior
- Building blocks of a Copilot Agent (CoAgent)
- Creating interactive agent experiences with CopilotKit
