## What is this?

Some agent steps need a person's choice before the agent continues. A human-in-the-loop tool shows buttons in the chat and sends the user's pick back to the agent.

The tool is a frontend tool, so it runs in the user's browser. Frontend tools can also let [your agent control the UI](/adk/frontend-tools) or render [generative UI](/adk/generative-ui).

## When should I use this?

Use a human-in-the-loop tool when the agent needs the user to pick an option or approve an action before it continues.
For other browser-side work, such as reading React state or calling browser APIs, see [Frontend Tools](/adk/frontend-tools).

## Implementation

<Steps>
    <Step>
      ### Run and connect your agent
      <RunAndConnect />
    </Step>

    <Step>
        ### Create a frontend human-in-the-loop tool

        Register the tool with `useHumanInTheLoop`. Its `render` shows two buttons, and the user's click becomes the tool result.

        In this example, the agent offers two options and waits for the user to pick one.

        ```tsx title="page.tsx"
        import { useHumanInTheLoop } from "@copilotkit/react-core/v2" // [!code highlight]
        import { z } from "zod"

        export function Page() {
          // ...

          useHumanInTheLoop({
            name: "offerOptions",
            description: "Give the user a choice between two options and have them select one.",
            parameters: z.object({
              option_1: z.string().describe("The first option"),
              option_2: z.string().describe("The second option"),
            }),
            render: ({ args, respond }) => {
              if (!respond) return <></>;
              return (
                <div>
                  {/* [!code highlight:2] */}
                  <button onClick={() => respond(`${args.option_1} was selected`)}>{args.option_1}</button>
                  <button onClick={() => respond(`${args.option_2} was selected`)}>{args.option_2}</button>
                </div>
              );
            },
          });

          // ...
        }
        ```

        Then add `AGUIToolset()` to the tools of your ADK agent. Without it, the agent does not see the tools that you register with `useHumanInTheLoop`.

        ```python title="agent.py"
        from ag_ui_adk import AGUIToolset
        from google.adk.agents import LlmAgent

        agent = LlmAgent(
            name="assistant",
            model="gemini-3.8-flash",
            instruction="When the user must choose between two options, call offerOptions.",
            tools=[AGUIToolset()], # [!code highlight]
        )
        ```

        <Callout type="info">
          On each run, the adapter replaces `AGUIToolset()` with the tools that your React components registered.
        </Callout>
    </Step>
    <Step>
        ### Try it out

        You've now given your agent the ability to show the user two options and have them select one. The agent will then be aware of the user's choice and can use it in subsequent steps.

        ```
        Can you show me two good options for a restaurant name?
        ```
    </Step>

</Steps>
