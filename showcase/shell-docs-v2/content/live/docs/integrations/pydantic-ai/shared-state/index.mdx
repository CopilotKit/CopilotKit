## What is shared state?

Your agent and your UI share one state object. With this shared state system, you can:

- [Display the agent's current progress](/shared-state/in-app-agent-read) and intermediate results
- [Update the agent's state](/shared-state/in-app-agent-write) through UI interactions
- [React to state changes](/shared-state/predictive-state-updates) in real-time across your application

The foundation of this system is built on Pydantic AI's stateful architecture via AG-UI.

## When should I use this?

Use shared state when the agent and the user work on the same data. Any state that your Pydantic AI agent
persists will be automatically shared by the UI. Similarly, any state that the user updates in the UI will be automatically reflected.

This allows for a consistent experience where both the agent and the user are on the same page.
