# A2A and MCP Handshake

AG-UI now includes **handshakes** with both **MCP** and **A2A** protocols, ensuring smooth interoperability across the full agentic stack.

## What Are Protocol Handshakes?

Protocol handshakes allow AG-UI to communicate with agents using different interaction protocols. This means you can connect your frontend to agents that use MCP or A2A internally. To set up each protocol, see [MCP](/agentic-protocols/mcp) and [A2A](/agentic-protocols/a2a).

## Benefits

### Full Interoperability

If your host agent connects to subagents using **MCP** or **A2A**, their UI properties can be propagated all the way through to the user-facing application.

### Simplified Architecture

One application can use AG-UI, MCP, and A2A together.

## How It Works

1. **Frontend connects via AG-UI** - Your application uses [AG-UI](/agentic-protocols/ag-ui) to connect to the host agent
2. **Host agent uses MCP/A2A** - The host agent can communicate with subagents using [MCP](/agentic-protocols/mcp) or [A2A](/agentic-protocols/a2a)
3. **UI properties propagate** - Generative UI and other properties flow back to your frontend automatically
