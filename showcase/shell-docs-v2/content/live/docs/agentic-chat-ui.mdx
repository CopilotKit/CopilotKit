## Pre-built components for agentic chat

`<CopilotChat>` renders a chat panel that streams your agent's replies.
It also renders generative UI from tool calls, and you can change its look and its parts.

## What it looks like in code

The live `agentic-chat` cell above is built from a single, small page. Wrap your UI in `<CopilotKit>` once (it wires the runtime, session, and agent registry) and drop `<CopilotChat>` wherever the chat should go:

`<Chat />` is a component in your app that renders `<CopilotChat>`:

<Snippet region="render-chat" title="frontend/src/app/page.tsx" />

Set `agent` and `agentId` to the name of the agent in your runtime. Without them, CopilotKit uses the agent named `default`.

For a floating or side-panel chat, see [Popup](/prebuilt-components/popup) and [Sidebar](/prebuilt-components/sidebar). To change the parts of the chat, see [Slots](/custom-look-and-feel/slots).

Inside the chat, the `useConfigureSuggestions` hook lets you show contextual
starter prompts. Import it from `@copilotkit/react-core/v2`:

```tsx
import { useConfigureSuggestions } from "@copilotkit/react-core/v2";
```
