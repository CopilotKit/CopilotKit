## What is this?

Some agent steps need a person to decide before the run continues, such as picking one of two options. A human-in-the-loop tool shows the choice in the chat and sends the answer back to the agent.

A human-in-the-loop tool is a frontend tool. Your Agent Spec agent can call a frontend tool, and the tool runs in the user's browser. You can also use frontend tools to let [your agent control the UI](/frontend-tools), or for [generative UI](/generative-ui).

## When should I use this?

Use a human-in-the-loop tool when the agent must wait for the user:

- Approve or reject an action, such as running a command
- Pick one of several options

## Implementation

<Steps>
    <Step>
      ### Run and connect your agent
      <RunAndConnect />
    </Step>

    <Step>
        ### Create a frontend human-in-the-loop tool

        Use `useHumanInTheLoop` to register a tool that waits for the user's choice. This example asks the user to pick one of two options:

        ```tsx title="page.tsx"
        import { useHumanInTheLoop } from "@copilotkit/react-core/v2";
        import { z } from "zod";

        export function Page() {
          // ...

          useHumanInTheLoop({
            name: "offerOptions",
            description: "Give the user a choice between two options and have them select one.",
            parameters: z.object({
              option_1: z.string().describe("The first option"),
              option_2: z.string().describe("The second option"),
            }),
            render: ({ args, respond }) => {
              if (!respond) return <></>;
              return (
                <div>
                  {/* [!code highlight:2] */}
                  <button onClick={() => respond(`${args.option_1} was selected`)}>{args.option_1}</button>
                  <button onClick={() => respond(`${args.option_2} was selected`)}>{args.option_2}</button>
                </div>
              );
            },
          });

          // ...
        }
        ```
    </Step>
    <Step>
        ### Set up your agent

        Human-in-the-loop tools are enabled through the concept of `ClientTool` in Agent Spec. Your Agent Spec config declares the tool, and the tool runs in your frontend. The agent only calls tools that the config declares, so declare a `ClientTool` with the same name and inputs as the frontend tool:

        ```python title="agent.py"
        from pyagentspec.agent import Agent
        from pyagentspec.property import Property
        from pyagentspec.tools import ClientTool

        offer_options_tool = ClientTool(
            name="offerOptions",
            description="Give the user a choice between two options and have them select one.",
            inputs=[
                Property(
                    title="option_1",
                    json_schema={"title": "option_1", "type": "string", "description": "The first option"},
                ),
                Property(
                    title="option_2",
                    json_schema={"title": "option_2", "type": "string", "description": "The second option"},
                ),
            ],
        )

        agent = Agent(
            # ... name, system_prompt, and llm_config for your agent
            tools=[offer_options_tool],
        )
        ```
    </Step>
    <Step>
        ### Try it out

        You've now given your agent the ability to show the user two options and have them select one. The agent will then be aware of the user's choice and can use it in subsequent steps.

        ```
        Can you show me two good options for a restaurant name?
        ```
    </Step>

</Steps>
