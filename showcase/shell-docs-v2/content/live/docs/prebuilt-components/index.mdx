## Pre-built components for agentic chat

CopilotKit ships three prebuilt chat surfaces that connect directly to your
agent. They all handle streaming, generative UI, and deep customization.
[Pick a surface](#pick-a-surface) below.

## The customization ladder

One of CopilotKit's design principles is that **you should never have to throw the prebuilt UI away** to get the look you want. Start at the top of this ladder and step down only when you need more control.

<Cards>
  <Card title="Level 1: Drop in as-is" href="/prebuilt-components/chat">
    Render `<CopilotChat>`, `<CopilotSidebar>`, or `<CopilotPopup>` and ship.
    Streaming, tool calls, generative UI, and suggestions, all wired up.
  </Card>
  <Card title="Level 2: Customize with CSS" href="/custom-look-and-feel/css">
    Override the design tokens (`--primary`, `--background`, and more) or
    target `.copilotKit...` classes. Keep every feature, change every color.
  </Card>
  <Card title="Level 3: Customize via slots (subcomponents)" href="/custom-look-and-feel/slots">
    Swap the welcome screen, message bubble, composer, disclaimer, header,
    or toggle button with your own React component. Slots can contain slots,
    so you can replace a part at any depth.
  </Card>
  <Card title="Level 4: Go fully headless" href="/custom-look-and-feel/headless-ui">
    Compose your own chat from the low-level hooks (`useAgent`,
    `useCopilotKit`, `useRenderToolCall`). Any layout, any design system, or
    even non-chat surfaces.
  </Card>
</Cards>

Everything below Level 1 is incremental: you can freely mix CSS variables, a custom welcome slot, and headless tool-call renderers in the same app.

## Pick a surface

Each surface is a drop-in component with the same underlying primitives, differing only in layout.

- [`<CopilotChat>`](/prebuilt-components/chat): inline chat pane you can place anywhere and size to fit.
- [`<CopilotSidebar>`](/prebuilt-components/sidebar): collapsible sidebar docked to the edge of your app.
- [`<CopilotPopup>`](/prebuilt-components/popup): floating bubble that overlays your page content.

Add a conversation-history sidebar next to any of these with
[Threads Drawer](/prebuilt-components/copilot-threads-drawer), a
drop-in thread switcher with no active-thread wiring. To build your own
switcher, use [Headless Threads](/headless-threads).

Need to open/close the chat from your own button, or capture thumbs-up/down
feedback? See [Open, close, and feedback](/prebuilt-components/chat-controls).
